# 子项目 A 实施计划 3/4：写入、引擎与 S3 spike（record-mux、record-engine、录制命令）

> **给执行者：** REQUIRED SUB-SKILL: 用 superpowers:executing-plans 在当前会话内逐任务执行本计划（**不派子代理**）。步骤用复选框（`- [ ]`）跟踪。

**目标：** 补齐 `record-mux`（ffmpeg 子进程封装、写入器、收尾与修复、编码器探测）和 `record-engine`（一场录制的启动 / 运行 / 保存、健康监测、崩溃恢复），加上命令行的 `record`、`recover`、`s2 bench`、`s3` 命令；在真机上完成 S2 的 CPU 压力测试和 S3（音画同步、故障注入、崩溃恢复）两个 spike，并核对设计文档里已经写好的结论。

**架构：** 三轨各自独立：每轨一个 ffmpeg 子进程加一个写入线程，采集线程只往队列里放数据、不做磁盘 I/O（音频队列溢出才丢新数据，视频队列满了丢最旧帧）。`record-engine` 把采集源、写入器和健康监测线程组装成一场录制，`start` / `stop` 是仅有的两个入口；保存时先让三轨文件可用，再生成 `meeting.mp4`；崩溃后由 `recovery` 修复。故障在引擎里是可注入的，所以探测器能在真机上被验证，而不是只在单元测试里。

**技术栈：** Rust；ffmpeg（LGPL 构建，`vendor/ffmpeg/`）；crossbeam-channel、parking_lot、chrono、serde_json；PowerShell 脚本做真机验证。

**本计划的位置：** 共四份计划：A1 地基 → A2 采集与 S1/S2 → A3 写入、引擎与 S3（本份）→ A4 外壳与 S5、验收。需要先完成 A2。

## 全局约束

以下条目来自设计文档 `docs/superpowers/specs/2026-10-13-meeting-recorder-design.md`，数值与措辞不要擅自改动；与它冲突时以设计文档为准，并先回头改文档。

- **平台与工具链**：Windows 11 x64（开发机为 Windows 11 build 26200）；v1 不做其他平台。Rust 1.95 以上、edition 2024；Tauri v2；前端 TypeScript + Vite + React（§2、§12）。
- **统一时钟**：所有数据用 QPC（`QueryPerformanceCounter`）打时间戳，换算为 **100 ns** 单位。`t0_session` = 热键按下时的 QPC；每轨 `t0_stream` = 该轨第一份数据的 QPC；收尾时每轨偏移 = `t0_stream` − 所有轨 `t0_stream` 的最小值（§5.1）。
- **只存原始音频**：采集阶段不降噪、不做回声消除、不做自动增益（§5.1）。
- **画面**：Desktop Duplication；恒定 **15 fps**（可设 10 / 15 / 30）；输出长边 ≤ 1920、短边 ≤ 1080，保持宽高比，宽高取偶数；缩放与 BGRA → NV12 在 GPU 上做；中途显示模式变化时按比例缩放加黑边，输出尺寸不变（§5.2）。
- **声音**：系统音走 WASAPI 回环，麦克风走 WASAPI 采集；都是 **48 kHz / float32**，系统音立体声，麦克风下混为单声道；事件驱动共享模式；采集线程是普通线程 + 事件句柄 + MMCSS（任务名 `Audio`），不用 RTWQ（§5.3、§5.4、§6.6）。
- **落盘**：每轨一个 ffmpeg 子进程，stdin 喂原始数据；`video.mkv`（H.264，无声）、`mic.mka`（FLAC）、`system.mka`（FLAC）；ffmpeg 用 LGPL 构建，开发时放在 `vendor/ffmpeg/`，不入库（§5.6）。
- **编码器**：启动时按 NVENC → QSV → AMF 探测；都没有就明确报错；软件编码只能由用户显式选择，**不悄悄降级**（§5.2、§9）。
- **时间线修复**：补静音阈值初值 40 ms、带滞回；回环空闲时每 10 ms 检查一次并补静音；单次补静音超过 5 秒记 `large_gap` 并告警；音频绝不丢，视频队列满时丢最旧帧（§5.5、§5.9）。
- **成品**：`meeting.mp4` = 画面直接拷贝 + 两轨按偏移对齐后等增益相加并限幅、编码为 AAC（1 路画面 + 1 路混音）；三轨文件在保存后几秒内即可用，`meeting.mp4` 稍后生成（§5.7）。
- **崩溃恢复**：启动时扫描 `state=recording` 的会话，对每个 MKV / MKA 做拷贝式修复，`state=recovered`，补做 `meeting.mp4`，通知用户；`state=finalized` 但缺 `meeting.mp4` 的会话补做收尾（§5.8）。
- **不静默失败**：回环“通但全是静音”、设备挂起、补静音过长、持续低帧率都要探测；告警动作是托盘变琥珀、写日志、弹提示、`session.json` 计数加一；**不自动切换采集方案**（§5.10、§9）。
- **状态机与热键**：待命 → 启动中 → 录制中 → 收尾中 → 待命；所有命令进入同一个控制器串行处理，500 ms 内的重复触发被忽略；热键默认 `Ctrl+Alt+R`（开始）、`Ctrl+Alt+S`（保存并结束本场）、`Ctrl+Alt+Q`（保存并退出程序），均可改、均幂等；三个热键常驻注册（§6.1、§6.2）。
- **静默程度**：安静模式为默认——没有弹窗和提示音，只有托盘图标变化（灰 = 待命、红点 = 录制中、琥珀 = 告警）；标准模式另加开始 / 保存的气泡；出错一定弹提示；**不提供“完全隐形”模式**（§6.3）。
- **自动保护**：单场上限 6 小时、磁盘剩余空间低于 5 GB 时自动保存并结束；睡眠 = 先保存，唤醒后提示“因睡眠已保存”；关机、注销先保存再退出（§6.5）。
- **位置**：配置 `%APPDATA%\record\config.toml`；日志 `%LOCALAPPDATA%\record\logs\`（按天滚动）；保存目录默认 `<视频库>\Record`（§4.3、§4.4）。
- **公开仓库与合规**：不提交密钥、录音录像、转写稿、模型文件和研究产物；测试产物只放 `%TEMP%\record-*` 并在结束时删除；验证画面与声音靠合成信号和统计量，不去看、不去听用户的真实录制；对第三方软件不拷贝代码（OBS GPLv2、Cap AGPLv3、Sokuji AGPL-3.0、Screenpipe 源码可见许可的项目只借鉴思路）；录制需取得与会者同意（§14）。
- **工程约定**：每个任务先写失败的测试、再实现；`rustfmt.toml` 与 `clippy -D warnings` 是质量门；提交信息用 `类型(范围): 中文说明`；不改系统环境变量。

```rust
//! 对 `std::process::Child` 的薄封装：不弹控制台窗口、stderr 只留最后几十行、带超时的等待与强杀。

use std::collections::VecDeque;
use std::ffi::OsString;
use std::io::{self, BufRead, BufReader};
use std::path::Path;
use std::process::{Child, ChildStdin, Command, ExitStatus, Stdio};
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex};
use std::thread::{self, JoinHandle};
use std::time::{Duration, Instant};

#[cfg(windows)]
const CREATE_NO_WINDOW: u32 = 0x0800_0000;
#[cfg(windows)]
const BELOW_NORMAL_PRIORITY_CLASS: u32 = 0x0000_4000;

const TAIL_LINES: usize = 40;

pub struct FfmpegProc {
    child: Child,
    tail: Arc<Mutex<VecDeque<String>>>,
    stderr_thread: Option<JoinHandle<()>>,
    stderr_done: Arc<AtomicBool>,
}

impl FfmpegProc {
    /// `stdin_piped` 为真时可用 [`FfmpegProc::take_stdin`] 取走标准输入。
    /// `low_priority` 用于收尾与修复这类后台任务，不去抢正在进行的录制的 CPU。
    pub fn spawn(program: &Path, args: &[OsString], stdin_piped: bool, low_priority: bool) -> io::Result<Self> {
        let mut cmd = Command::new(program);
        cmd.args(args).stdin(if stdin_piped { Stdio::piped() } else { Stdio::null() }).stdout(Stdio::null()).stderr(Stdio::piped());
        #[cfg(windows)]
        {
            use std::os::windows::process::CommandExt;
            cmd.creation_flags(CREATE_NO_WINDOW | if low_priority { BELOW_NORMAL_PRIORITY_CLASS } else { 0 });
        }
        #[cfg(not(windows))]
        let _ = low_priority;
        let mut child = cmd.spawn()?;
        let tail = Arc::new(Mutex::new(VecDeque::with_capacity(TAIL_LINES)));
        let stderr = child.stderr.take().expect("stderr 已设置为管道");
        let t = Arc::clone(&tail);
        let stderr_done = Arc::new(AtomicBool::new(false));
        let done = Arc::clone(&stderr_done);
        let stderr_thread = thread::Builder::new().name("ffmpeg-stderr".into()).spawn(move || {
            let mut reader = BufReader::new(stderr);
            let mut buf = Vec::new();
            loop {
                buf.clear();
                match reader.read_until(b'\n', &mut buf) {
                    Ok(0) | Err(_) => break,
                    Ok(_) => {
                        // 错误信息里的路径可能是系统代码页编码，按有损方式解码，不因此丢日志
                        let line = String::from_utf8_lossy(&buf).trim_end().to_string();
                        if line.is_empty() {
                            continue;
                        }
                        let mut q = t.lock().unwrap();
                        if q.len() == TAIL_LINES {
                            q.pop_front();
                        }
                        q.push_back(line);
                    }
                }
            }
            done.store(true, Ordering::Release);
        })?;
        Ok(Self { child, tail, stderr_thread: Some(stderr_thread), stderr_done })
    }

    pub fn id(&self) -> u32 {
        self.child.id()
    }

    pub fn take_stdin(&mut self) -> Option<ChildStdin> {
        self.child.stdin.take()
    }

    /// stderr 最后若干行，用于错误提示与日志。
    pub fn stderr_tail(&self) -> String {
        self.tail.lock().unwrap().iter().cloned().collect::<Vec<_>>().join("\n")
    }

    pub fn try_wait(&mut self) -> io::Result<Option<ExitStatus>> {
        self.child.try_wait()
    }

    /// 在 `timeout` 内等待退出；超时返回 `Ok(None)`，进程仍在运行。
    pub fn wait_timeout(&mut self, timeout: Duration) -> io::Result<Option<ExitStatus>> {
        let deadline = Instant::now() + timeout;
        loop {
            if let Some(status) = self.child.try_wait()? {
                self.join_stderr();
                return Ok(Some(status));
            }
            if Instant::now() >= deadline {
                return Ok(None);
            }
            thread::sleep(Duration::from_millis(10));
        }
    }

    pub fn kill(&mut self) {
        let _ = self.child.kill();
        let _ = self.child.wait();
        self.join_stderr();
    }

    /// 进程已结束，等 stderr 读完最后几行；最多等 1 秒。
    /// 管道的写端可能被孙进程继承而一直不关闭，不能无限等下去，超时就放手，线程在管道关闭时自行退出。
    fn join_stderr(&mut self) {
        let Some(h) = self.stderr_thread.take() else { return };
        let deadline = Instant::now() + Duration::from_secs(1);
        while !self.stderr_done.load(Ordering::Acquire) && Instant::now() < deadline {
            thread::sleep(Duration::from_millis(5));
        }
        if self.stderr_done.load(Ordering::Acquire) {
            let _ = h.join();
        }
    }
}

impl Drop for FfmpegProc {
    fn drop(&mut self) {
        // 正常路径由 finish / wait 收尾；走到这里仍在运行，说明调用方提前丢弃了它，强杀以免留下孤儿进程
        if matches!(self.child.try_wait(), Ok(None)) {
            let _ = self.child.kill();
            let _ = self.child.wait();
        }
    }
}
```

```rust
//! 视频帧队列：容量满时丢最旧的一帧（设计文档 5.9：音频绝不丢，视频队列满时丢最旧帧）。

use crossbeam_channel::{Receiver, Sender, TrySendError, bounded};
use std::sync::atomic::{AtomicU64, Ordering};

pub struct DropOldest<T> {
    tx: Option<Sender<T>>,
    rx: Receiver<T>,
    dropped: AtomicU64,
}

impl<T> DropOldest<T> {
    pub fn new(capacity: usize) -> Self {
        let (tx, rx) = bounded(capacity.max(1));
        Self { tx: Some(tx), rx, dropped: AtomicU64::new(0) }
    }

    /// 入队；队列已满时先丢掉最旧的，返回本次丢弃的条数。关闭后入队的数据被丢弃，返回 0。
    pub fn push(&self, item: T) -> u64 {
        let Some(tx) = &self.tx else { return 0 };
        let mut item = item;
        let mut dropped = 0;
        loop {
            match tx.try_send(item) {
                Ok(()) => break,
                Err(TrySendError::Full(back)) => {
                    item = back;
                    if self.rx.try_recv().is_ok() {
                        dropped += 1;
                    }
                }
                Err(TrySendError::Disconnected(_)) => break,
            }
        }
        self.dropped.fetch_add(dropped, Ordering::Relaxed);
        dropped
    }

    pub fn receiver(&self) -> Receiver<T> {
        self.rx.clone()
    }

    pub fn total_dropped(&self) -> u64 {
        self.dropped.load(Ordering::Relaxed)
    }

    /// 关闭发送端：消费线程取完队列里剩余的数据后收到“断开”。
    pub fn close(&mut self) {
        self.tx = None;
    }
}
```

/// 交错的正弦波，`freq` Hz，`seconds` 秒。
pub fn sine(freq: f64, channels: usize, seconds: f64, amplitude: f32) -> Vec<f32> {
    let frames = (seconds * f64::from(RATE)) as usize;
    let mut out = Vec::with_capacity(frames * channels);
    for n in 0..frames {
        let v = (2.0 * std::f64::consts::PI * freq * n as f64 / f64::from(RATE)).sin() as f32 * amplitude;
        for _ in 0..channels {
            out.push(v);
        }
    }
    out
}

/// 一帧 NV12：亮度是随帧号移动的斜纹，色度恒为 128。
pub fn nv12_frame(w: usize, h: usize, n: usize) -> Vec<u8> {
    let mut f = vec![128u8; w * h * 3 / 2];
    for y in 0..h {
        for x in 0..w {
            f[y * w + x] = ((x + y + n * 7) % 220 + 16) as u8;
        }
    }
    f
}

/// 解码音频为交错 f32（立体声，48 kHz）。
pub fn decode_stereo(path: &Path) -> Vec<f32> {
    let out = Command::new(ffmpeg()).args(["-v", "error", "-i"]).arg(path).args(["-map", "0:a:0", "-f", "f32le", "-ac", "2", "-ar", "48000", "-"]).output().expect("启动 ffmpeg");
    assert!(out.status.success(), "解码失败：{}", String::from_utf8_lossy(&out.stderr));
    assert!(out.stderr.is_empty(), "解码有告警：{}", String::from_utf8_lossy(&out.stderr));
    out.stdout.chunks_exact(4).map(|b| f32::from_le_bytes([b[0], b[1], b[2], b[3]])).collect()
}

/// 加汉宁窗的 Goertzel：返回 `freq` 处的幅度估计（纯正弦时约等于振幅）。
pub fn tone_level(window: &[f32], freq: f64) -> f64 {
    let n = window.len();
    let (mut re, mut im, mut wsum) = (0.0f64, 0.0f64, 0.0f64);
    for (i, &s) in window.iter().enumerate() {
        let w = 0.5 - 0.5 * (2.0 * std::f64::consts::PI * i as f64 / (n - 1) as f64).cos();
        let phase = 2.0 * std::f64::consts::PI * freq * i as f64 / f64::from(RATE);
        re += f64::from(s) * w * phase.cos();
        im -= f64::from(s) * w * phase.sin();
        wsum += w;
    }
    2.0 * (re * re + im * im).sqrt() / wsum
}

/// 取左声道，逐 20 ms 窗口找 `freq` 的音量首次超过 `threshold` 的时刻（秒）。
pub fn tone_onset(stereo: &[f32], freq: f64, threshold: f64) -> Option<f64> {
    let left: Vec<f32> = stereo.chunks_exact(2).map(|f| f[0]).collect();
    let win = (RATE / 50) as usize;
    (0..left.len().saturating_sub(win)).step_by(win / 4).find(|&i| tone_level(&left[i..i + win], freq) > threshold).map(|i| i as f64 / f64::from(RATE))
}

//! 编码器探测（设计文档 5.2）：启动时探测，顺序 NVENC → QSV → AMF；都没有时明确报错，
//! 软件编码只能由用户在设置里显式选择，这里不会悄悄选它。

use crate::MuxError;
use crate::process::FfmpegProc;
use record_core::config::Encoder;
use record_core::ffmpeg_args::{count_frames_args, parse_progress_frames, probe_args};
use std::path::Path;
use std::time::Duration;

const AUTO_ORDER: [Encoder; 3] = [Encoder::Nvenc, Encoder::Qsv, Encoder::Amf];

/// 实际编一帧，成功才算可用（ffmpeg 里编进了编码器，不等于这台机器的硬件能用）。
pub fn probe_encoder(ffmpeg: &Path, enc: Encoder) -> Result<(), String> {
    let args = probe_args(enc).map_err(|e| e.to_string())?;
    let mut proc = FfmpegProc::spawn(ffmpeg, &args, false, false).map_err(|e| format!("无法启动 ffmpeg：{e}"))?;
    match proc.wait_timeout(Duration::from_secs(20)) {
        Ok(Some(status)) if status.success() => Ok(()),
        Ok(Some(_)) => Err(last_line(&proc.stderr_tail())),
        Ok(None) => {
            proc.kill();
            Err("探测超过 20 秒没有结束".into())
        }
        Err(e) => Err(e.to_string()),
    }
}

/// 画面文件里的帧数。编码器重启时用它确定下一段从第几帧接着写。
pub fn count_video_frames(ffmpeg: &Path, file: &Path, timeout: Duration) -> Result<u64, MuxError> {
    let mut proc = FfmpegProc::spawn(ffmpeg, &count_frames_args(file), false, true).map_err(MuxError::Spawn)?;
    match proc.wait_timeout(timeout)? {
        Some(status) if status.success() => parse_progress_frames(&proc.stderr_tail()).ok_or_else(|| MuxError::Failed { code: Some(0), tail: format!("没有读到帧数：{}", proc.stderr_tail()) }),
        Some(status) => Err(MuxError::Failed { code: status.code(), tail: proc.stderr_tail() }),
        None => {
            proc.kill();
            Err(MuxError::Timeout(timeout))
        }
    }
}

fn last_line(tail: &str) -> String {
    tail.lines().rev().find(|l| !l.trim().is_empty()).unwrap_or("没有输出").trim().to_string()
}

/// `Encoder::Auto` 时按顺序探测；其他值只验证它能用。
pub fn resolve_encoder(ffmpeg: &Path, wanted: Encoder) -> Result<Encoder, MuxError> {
    if wanted != Encoder::Auto {
        return probe_encoder(ffmpeg, wanted).map(|()| wanted).map_err(|why| MuxError::NoEncoder(format!("{wanted:?}：{why}")));
    }
    let mut reasons = Vec::new();
    for enc in AUTO_ORDER {
        match probe_encoder(ffmpeg, enc) {
            Ok(()) => return Ok(enc),
            Err(why) => reasons.push(format!("{enc:?}：{why}")),
        }
    }
    Err(MuxError::NoEncoder(format!("{}。可以在设置里显式选择软件编码", reasons.join("；"))))
}

```rust
//! 每轨一个 ffmpeg 子进程加一个写入线程（设计文档 5.6、5.9）。
//!
//! - 音频：队列按“采样帧数预算”限界（约 10 秒）；放不下就丢弃并计数，**不阻塞采集线程**。
//! - 视频：队列按帧数限界（约 1 秒），满了丢最旧的；每帧带序号，写入线程在序号出现空缺时重复上一帧，
//!   保证输出时间线与 QPC 一致；序号倒退（迟到）的帧丢弃并计为重同步。
//! - ffmpeg 退出或写入出错：写入线程记下原因，之后收到的数据只计数、不再写，由引擎决定是否重启。

use crate::MuxError;
use crate::process::FfmpegProc;
use crate::queue::DropOldest;
use crossbeam_channel::{Receiver, Sender, unbounded};
use record_core::ffmpeg_args::{AudioSpec, VideoSpec, audio_writer_args, video_writer_args};
use std::io::Write;
use std::path::Path;
use std::sync::atomic::{AtomicU64, AtomicUsize, Ordering};
use std::sync::{Arc, Mutex};
use std::thread::{self, JoinHandle};
use std::time::Duration;

#[derive(Debug, Default)]
struct Shared {
    failed: Mutex<Option<String>>,
    bytes_written: AtomicU64,
    dropped_failed: AtomicU64,
    gap_repeats: AtomicU64,
    late_discarded: AtomicU64,
}

impl Shared {
    fn fail(&self, why: String) {
        let mut f = self.failed.lock().unwrap();
        if f.is_none() {
            *f = Some(why);
        }
    }

    fn failure(&self) -> Option<String> {
        self.failed.lock().unwrap().clone()
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Health {
    Running,
    /// 写入线程记下的原因（含 ffmpeg 最后的错误输出）。
    Failed(String),
}

/// 一次 `push` / `submit` 的去向。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Pushed {
    Queued,
    /// 队列放不下：音频是新数据被丢弃；视频是丢掉了最旧的 n 帧。
    Overflow(u64),
    /// 写入器已失败，数据未写入。
    WriterFailed,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct WriterReport {
    pub exit_code: Option<i32>,
    /// 超时后被强杀。
    pub killed: bool,
    pub failed: Option<String>,
    pub bytes_written: u64,
    /// 因队列满而丢弃（音频：采样帧数；视频：帧数）。
    pub dropped_queue: u64,
    /// 写入器失败后收到并丢弃的数据（单位同上）。
    pub dropped_failed: u64,
    /// 视频：序号出现空缺时重复上一帧的次数。
    pub gap_repeats: u64,
    /// 视频：序号倒退而被丢弃的迟到帧。
    pub late_discarded: u64,
    pub stderr_tail: String,
}

fn finish_process(mut proc: FfmpegProc, timeout: Duration) -> (Option<i32>, bool, String) {
    let (code, killed) = match proc.wait_timeout(timeout) {
        Ok(Some(status)) => (status.code(), false),
        _ => {
            proc.kill();
            (None, true)
        }
    };
    (code, killed, proc.stderr_tail())
}

// ---------------------------------------------------------------------------
// 音频
// ---------------------------------------------------------------------------

pub struct AudioWriter {
    tx: Option<Sender<Vec<f32>>>,
    shared: Arc<Shared>,
    queued_frames: Arc<AtomicUsize>,
    cap_frames: usize,
    channels: usize,
    dropped_queue: AtomicU64,
    proc: Mutex<Option<FfmpegProc>>,
    thread: Option<JoinHandle<()>>,
}

impl AudioWriter {
    pub fn spawn(ffmpeg: &Path, spec: &AudioSpec, out: &Path, queue_seconds: u32) -> Result<Self, MuxError> {
        let args = audio_writer_args(spec, out);
        let mut proc = FfmpegProc::spawn(ffmpeg, &args, true, false).map_err(MuxError::Spawn)?;
        let mut stdin = proc.take_stdin().expect("stdin 已设置为管道");
        let (tx, rx): (Sender<Vec<f32>>, Receiver<Vec<f32>>) = unbounded();
        let shared = Arc::new(Shared::default());
        let queued = Arc::new(AtomicUsize::new(0));
        let channels = usize::from(spec.channels);
        let (sh, q) = (Arc::clone(&shared), Arc::clone(&queued));
        let thread = thread::Builder::new().name("audio-writer".into()).spawn(move || {
            let mut bytes: Vec<u8> = Vec::new();
            for chunk in rx {
                q.fetch_sub(chunk.len() / channels, Ordering::Relaxed);
                if sh.failure().is_some() {
                    sh.dropped_failed.fetch_add((chunk.len() / channels) as u64, Ordering::Relaxed);
                    continue;
                }
                bytes.clear();
                bytes.reserve(chunk.len() * 4);
                for s in &chunk {
                    bytes.extend_from_slice(&s.to_le_bytes());
                }
                match stdin.write_all(&bytes) {
                    Ok(()) => {
                        sh.bytes_written.fetch_add(bytes.len() as u64, Ordering::Relaxed);
                    }
                    Err(e) => sh.fail(format!("写入 ffmpeg 失败：{e}")),
                }
            }
            drop(stdin); // 关闭标准输入，ffmpeg 读到结尾后写完文件并退出
        })?;
        Ok(Self {
            tx: Some(tx),
            shared,
            queued_frames: queued,
            cap_frames: spec.rate as usize * queue_seconds as usize,
            channels,
            dropped_queue: AtomicU64::new(0),
            proc: Mutex::new(Some(proc)),
            thread: Some(thread),
        })
    }

    /// 交付一块交错 f32 采样。放不下时丢弃这块并计数，不阻塞调用线程。
    pub fn push(&self, samples: &[f32]) -> Pushed {
        if self.shared.failure().is_some() {
            self.shared.dropped_failed.fetch_add((samples.len() / self.channels) as u64, Ordering::Relaxed);
            return Pushed::WriterFailed;
        }
        let frames = samples.len() / self.channels;
        if self.queued_frames.load(Ordering::Relaxed) + frames > self.cap_frames {
            self.dropped_queue.fetch_add(frames as u64, Ordering::Relaxed);
            return Pushed::Overflow(frames as u64);
        }
        self.queued_frames.fetch_add(frames, Ordering::Relaxed);
        if let Some(tx) = &self.tx {
            let _ = tx.send(samples.to_vec());
        }
        Pushed::Queued
    }

    pub fn health(&self) -> Health {
        match self.shared.failure() {
            Some(why) => Health::Failed(why),
            None => Health::Running,
        }
    }

    pub fn bytes_written(&self) -> u64 {
        self.shared.bytes_written.load(Ordering::Relaxed)
    }

    pub fn queued_frames(&self) -> usize {
        self.queued_frames.load(Ordering::Relaxed)
    }

    /// 故障注入与测试用：强杀 ffmpeg 进程。
    pub fn kill_process(&self) {
        if let Some(p) = self.proc.lock().unwrap().as_mut() {
            p.kill();
        }
    }

    /// ffmpeg 子进程的 pid（用于计量它的 CPU）。`finish` 之后没有。
    pub fn process_id(&self) -> Option<u32> {
        self.proc.lock().unwrap().as_ref().map(FfmpegProc::id)
    }

    /// 冲刷队列、关闭标准输入、等待 ffmpeg 退出；超过 `timeout` 强杀。
    pub fn finish(mut self, timeout: Duration) -> WriterReport {
        self.tx = None;
        if let Some(t) = self.thread.take() {
            // 写入线程可能卡在写一个不再读取的管道上：先等进程，超时强杀后线程自然出错退出
            let proc = self.proc.get_mut().unwrap().take().expect("进程仍在");
            let (code, killed, tail) = finish_process(proc, timeout);
            let _ = t.join();
            return self.report(code, killed, tail);
        }
        self.report(None, false, String::new())
    }

    fn report(&self, exit_code: Option<i32>, killed: bool, stderr_tail: String) -> WriterReport {
        WriterReport {
            exit_code,
            killed,
            failed: self.shared.failure(),
            bytes_written: self.shared.bytes_written.load(Ordering::Relaxed),
            dropped_queue: self.dropped_queue.load(Ordering::Relaxed),
            dropped_failed: self.shared.dropped_failed.load(Ordering::Relaxed),
            stderr_tail,
            ..Default::default()
        }
    }
}

    }

    /// 从全局帧序号 `first_index` 开始写：编码器重启后的新一段接着上一段的最后一帧。
    /// 收到的第一帧序号大于 `first_index` 时，中间空出来的序号用这第一帧补齐（画面冻结到恢复为止），
    /// 前后各段首尾相接，时间线不错位。
    pub fn spawn_from(ffmpeg: &Path, spec: &VideoSpec, out: &Path, queue_frames: usize, first_index: u64) -> Result<Self, MuxError> {
        let args = video_writer_args(spec, out)?;
        let mut proc = FfmpegProc::spawn(ffmpeg, &args, true, false).map_err(MuxError::Spawn)?;
        let mut stdin = proc.take_stdin().expect("stdin 已设置为管道");
        let queue: DropOldest<Frame> = DropOldest::new(queue_frames);
        let rx = queue.receiver();
        let shared = Arc::new(Shared::default());
        let sh = Arc::clone(&shared);
        let frame_bytes = (spec.width as usize * spec.height as usize * 3) / 2;
        let thread = thread::Builder::new().name("video-writer".into()).spawn(move || {
            let mut next: u64 = first_index;
            let mut last: Option<Arc<[u8]>> = None;
            for frame in rx {
                if sh.failure().is_some() {
                    sh.dropped_failed.fetch_add(1, Ordering::Relaxed);
                    continue;
                }
                if frame.index < next {
                    sh.late_discarded.fetch_add(1, Ordering::Relaxed);
                    continue;
                }
                let filler = last.clone().unwrap_or_else(|| Arc::clone(&frame.data));
                let mut write = |data: &Arc<[u8]>| -> bool {
                    match stdin.write_all(data) {
                        Ok(()) => {
                            sh.bytes_written.fetch_add(data.len() as u64, Ordering::Relaxed);
                            true
                        }
                        Err(e) => {
                            sh.fail(format!("写入 ffmpeg 失败：{e}"));
                            false
                        }
                    }
                };
                let mut ok = true;
                while ok && next < frame.index {
                    ok = write(&filler);
                    if ok {
                        sh.gap_repeats.fetch_add(1, Ordering::Relaxed);
                        next += 1;
                    }
                }
                if ok && write(&frame.data) {
                    next = frame.index + 1;
                    last = Some(frame.data);
                }
            }
            drop(stdin);
        })?;
        Ok(Self { queue, shared, frame_bytes, proc: Mutex::new(Some(proc)), thread: Some(thread) })
    }

    pub fn frame_bytes(&self) -> usize {
        self.frame_bytes
    }

    /// ffmpeg 子进程的 pid（用于计量它的 CPU）。`finish` 之前才有。
    pub fn process_id(&self) -> Option<u32> {
        self.proc.lock().unwrap().as_ref().map(FfmpegProc::id)
    }

    /// 交付第 `index` 帧（NV12）。重复帧共享同一份 `Arc`，不复制数据。
    pub fn submit(&self, index: u64, data: Arc<[u8]>) -> Pushed {
        assert_eq!(data.len(), self.frame_bytes, "帧大小与编码器设置不符");
        if self.shared.failure().is_some() {
            self.shared.dropped_failed.fetch_add(1, Ordering::Relaxed);
            return Pushed::WriterFailed;
        }
        match self.queue.push(Frame { index, data }) {
            0 => Pushed::Queued,
            n => Pushed::Overflow(n),
        }
    }

    pub fn health(&self) -> Health {
        match self.shared.failure() {
            Some(why) => Health::Failed(why),
            None => Health::Running,
        }
    }

    pub fn bytes_written(&self) -> u64 {
        self.shared.bytes_written.load(Ordering::Relaxed)
    }

    /// 故障注入与测试用：强杀 ffmpeg 进程。
    pub fn kill_process(&self) {
        if let Some(p) = self.proc.lock().unwrap().as_mut() {
            p.kill();
        }
    }

    pub fn finish(mut self, timeout: Duration) -> WriterReport {
        self.queue.close();
        let proc = self.proc.get_mut().unwrap().take().expect("进程仍在");
        let (code, killed, tail) = finish_process(proc, timeout);
        if let Some(t) = self.thread.take() {
            let _ = t.join();
        }
        WriterReport {
            exit_code: code,
            killed,
            failed: self.shared.failure(),
            bytes_written: self.shared.bytes_written.load(Ordering::Relaxed),
            dropped_queue: self.queue.total_dropped(),
            dropped_failed: self.shared.dropped_failed.load(Ordering::Relaxed),
            gap_repeats: self.shared.gap_repeats.load(Ordering::Relaxed),
            late_discarded: self.shared.late_discarded.load(Ordering::Relaxed),
            stderr_tail: tail,
        }
    }
}

//! 收尾与修复（设计文档 5.7、5.8）：生成 `meeting.mp4`、拷贝式修复 MKV / MKA。

use crate::MuxError;
use crate::process::FfmpegProc;
use record_core::ffmpeg_args::{FinalizePlan, display, finalize_args, meeting_part_path, repair_args};
use record_core::session::MEETING_FILE;

use std::time::Duration;

/// 运行一条 ffmpeg 命令直到结束。超时强杀；失败时带上 stderr 末尾的内容。
pub fn run(ffmpeg: &Path, args: &[OsString], timeout: Duration, low_priority: bool) -> Result<(), MuxError> {
    let cmdline = display(args);
    tracing::debug!("ffmpeg {cmdline}");
    let mut proc = FfmpegProc::spawn(ffmpeg, args, false, low_priority).map_err(MuxError::Spawn)?;
    match proc.wait_timeout(timeout)? {
        Some(status) if status.success() => Ok(()),
        Some(status) => Err(MuxError::Failed { code: status.code(), tail: proc.stderr_tail() }),
        None => {
            proc.kill();
            Err(MuxError::Timeout(timeout))
        }
    }
}

/// 生成 `meeting.mp4`：先写 `.part`，成功后改名，半成品不会被当成成品。
pub fn finalize_meeting(ffmpeg: &Path, dir: &Path, plan: &FinalizePlan, audio_rate: u32, timeout: Duration) -> Result<PathBuf, MuxError> {
    let args = finalize_args(dir, plan, audio_rate)?;
    let part = meeting_part_path(dir);
    let _ = fs::remove_file(&part);
    if let Err(e) = run(ffmpeg, &args, timeout, true) {
        let _ = fs::remove_file(&part);
        return Err(e);
    }
    let out = dir.join(MEETING_FILE);
    fs::rename(&part, &out)?;
    Ok(out)
}

/// 拷贝式修复一个轨道文件，成功后替换原文件；失败时原文件原样保留。
pub fn repair_track(ffmpeg: &Path, file: &Path, timeout: Duration) -> Result<(), MuxError> {
    let mut dst = file.as_os_str().to_owned();
    dst.push(".repair");
    let dst = PathBuf::from(dst);
    let _ = fs::remove_file(&dst);
    let result = run(ffmpeg, &repair_args(file, &dst), timeout, true).and_then(|()| {
        if fs::metadata(&dst)?.len() == 0 {
            return Err(MuxError::Failed { code: Some(0), tail: "修复结果为空文件，保留原文件".into() });
        }
        Ok(())
    });
    match result {
        Ok(()) => {
            fs::rename(&dst, file)?;
            Ok(())
        }
        Err(e) => {
            let _ = fs::remove_file(&dst);
            Err(e)
        }
    }
}

//! 磁盘剩余空间（设计文档 6.5 自动保护、9 磁盘写满）。

use std::os::windows::ffi::OsStrExt;
use std::path::Path;
use windows::Win32::Storage::FileSystem::GetDiskFreeSpaceExW;
use windows::core::PCWSTR;

/// `path` 所在卷对当前用户可用的字节数。取不到时返回 `None`，调用方不能当成“空间充足”也不能当成“空间不足”。
pub fn free_bytes(path: &Path) -> Option<u64> {
    let wide: Vec<u16> = path.as_os_str().encode_wide().chain(Some(0)).collect();
    let mut free = 0u64;
    unsafe { GetDiskFreeSpaceExW(PCWSTR(wide.as_ptr()), Some(&mut free), None, None) }.ok()?;
    Some(free)
}

//! 会话锁：录制期间进程独占打开会话目录里的 `.recording`（共享模式 0）。
//!
//! 进程被杀或崩溃时系统会关掉句柄，锁文件还在但没人占用；崩溃恢复靠这一点分清
//! “正在被别的进程录制”和“上次崩溃留下的半成品”，不会把正在录的会话当成崩溃去修复。

use std::fs::{File, OpenOptions};
use std::io;
use std::os::windows::fs::OpenOptionsExt;
use std::path::{Path, PathBuf};

pub const LOCK_FILE: &str = ".recording";
const ERROR_SHARING_VIOLATION: i32 = 32;

#[derive(Debug)]
pub struct SessionLock {
    file: Option<File>,
    path: PathBuf,
}

impl SessionLock {
    /// 创建并独占锁文件。已被别的进程占用时返回错误。
    pub fn acquire(dir: &Path) -> io::Result<Self> {
        let path = dir.join(LOCK_FILE);
        let file = OpenOptions::new().write(true).create(true).truncate(true).share_mode(0).open(&path)?;
        Ok(Self { file: Some(file), path })
    }

    /// 正常结束：放手并删除锁文件。
    pub fn release(mut self) {
        self.file = None;
        let _ = std::fs::remove_file(&self.path);
    }
}

/// 会话目录当前是否被某个进程占着录制。没有锁文件、或锁文件没人占（崩溃遗留）都是 `false`。
pub fn is_active(dir: &Path) -> bool {
    match OpenOptions::new().write(true).share_mode(0).open(dir.join(LOCK_FILE)) {
        Ok(_) => false,
        Err(e) => e.raw_os_error() == Some(ERROR_SHARING_VIOLATION),
    }
}
```

//! 可替换的共享句柄：采集线程每次交付数据时取当前写入器；编码器重启时换成新的，采集线程不用停。
//!
//! 交付与更换用读写锁隔开：采集线程在读锁里“交付并计数”，更换在写锁里“读计数并换上新的”，
//! 所以新写入器接手的位置与已交付的数量严格对得上，不会有数据同时交给新旧两个写入器，也不会漏。

use parking_lot::{RwLock, RwLockReadGuard};
use std::sync::Arc;

pub(crate) struct Slot<T>(RwLock<Arc<T>>);

impl<T> Slot<T> {
    pub fn new(value: T) -> Arc<Self> {
        Arc::new(Self(RwLock::new(Arc::new(value))))
    }

    pub fn get(&self) -> Arc<T> {
        Arc::clone(&self.0.read())
    }

    /// 持有读锁期间 [`Slot::replace_with`] 会等着。交付数据的采集线程在这里完成“交给写入器 + 计数”。
    pub fn read(&self) -> RwLockReadGuard<'_, Arc<T>> {
        self.0.read()
    }

    /// 换上新的，返回旧的。`at_swap` 在写锁内、替换之前执行：此时没有任何线程在交付数据，
    /// 用它读“已交付多少”，得到的就是旧写入器收到的全部、新写入器还没收到的起点。
    pub fn replace_with(&self, value: T, at_swap: impl FnOnce()) -> Arc<T> {
        let mut guard = self.0.write();
        at_swap();
        std::mem::replace(&mut *guard, Arc::new(value))
    }

    /// 所有持有者都放手之后取回里面的值；还有别人持有时返回 `None`。
    pub fn into_inner(self: Arc<Self>) -> Option<T> {
        let slot = Arc::try_unwrap(self).ok()?;
        Arc::try_unwrap(slot.0.into_inner()).ok()
    }
}

use windows::Win32::Media::Audio::IMMDeviceEnumerator;

fn default_name(en: &IMMDeviceEnumerator, flow: Flow, role: Role) -> Value {
    match devices::default_endpoint(en, flow, role).and_then(|d| devices::info(&d)) {
        Ok(i) => json!(i.name),
        Err(e) => json!(format!("（没有：{e}）")),
    }
}

fn endpoints(en: &IMMDeviceEnumerator, flow: Flow) -> Value {
    let Ok(list) = devices::active_endpoints(en, flow) else {
        return json!([]);
    };
    let items: Vec<Value> = list
        .iter()
        .filter_map(|d| {
            let name = devices::info(d).ok()?.name;
            let mix = devices::mix_format(d).map(|m| format!("{} Hz，{} 声道，{} 位{}", m.rate, m.channels, m.bits, if m.float { "浮点" } else { "" })).ok();
            Some(json!({ "name": name, "mix": mix }))
        })
        .collect();
    json!(items)
}

pub(crate) fn environment(en: &IMMDeviceEnumerator, cfg: &Config, encoder: Encoder, ffmpeg: &Path, monitors: &[String]) -> Value {
    json!({
        "os": "Windows",
        "ffmpeg": ffmpeg.display().to_string(),
        "encoder": format!("{encoder:?}"),
        "monitors": monitors,
        "render_default_console": default_name(en, Flow::Render, Role::Console),
        "render_default_communications": default_name(en, Flow::Render, Role::Communications),
        "capture_default_console": default_name(en, Flow::Capture, Role::Console),
        "capture_default_communications": default_name(en, Flow::Capture, Role::Communications),
        "render_devices": endpoints(en, Flow::Render),
        "capture_devices": endpoints(en, Flow::Capture),
        "system_capture": format!("{:?}", cfg.audio.system_capture),
        "mic_role": format!("{:?}", cfg.audio.mic_role),
        "mic_time_source": format!("{:?}", cfg.audio.mic_time_source),
        "system_time_source": format!("{:?}", cfg.audio.system_time_source),
        "system_keepalive": cfg.audio.system_keepalive,
    })
}

```rust
//! 生成 `meeting.mp4`：收尾与崩溃恢复共用（设计文档 5.7、5.8）。

use record_core::ffmpeg_args::{FinalizePlan, VIDEO_CONCAT_FILE, concat_list};
use record_core::session::{SegmentMeta, SessionMeta, TrackKind, TrackStatus};
use record_mux::MuxError;
use record_mux::finalize::finalize_meeting;
use std::path::{Path, PathBuf};
use std::time::Duration;

/// 混音输出的采样率，与采集一致。
pub const AUDIO_RATE: u32 = 48_000;
/// 生成成品的超时：1 小时录音的音频转码与封装通常在一分钟内完成，这里留足余量。
pub const FINALIZE_TIMEOUT: Duration = Duration::from_secs(15 * 60);

fn non_empty(dir: &Path, name: &str) -> bool {
    std::fs::metadata(dir.join(name)).is_ok_and(|m| m.len() > 0)
}

/// 编码器重启留下的一段是否有内容：文件非空，且不是已知一帧都没写出来的画面段。
fn segment_usable(dir: &Path, s: &SegmentMeta) -> bool {
    s.frames != Some(0) && non_empty(dir, &s.file)
}

/// 这一轨有可用的数据：文件存在且非空，元数据没有标为缺失。编码器重启过的轨道，任何一段有内容就算。
pub fn track_usable(dir: &Path, meta: &SessionMeta, kind: TrackKind) -> bool {
    meta.tracks.get(kind).is_some_and(|t| t.status != TrackStatus::Missing && if t.segments.is_empty() { non_empty(dir, &t.file) } else { t.segments.iter().any(|s| segment_usable(dir, s)) })
}

/// 去掉编码器重启轨道里没有内容的段。拼接和混音只认有内容的段。
fn without_empty_segments(dir: &Path, meta: &SessionMeta) -> SessionMeta {
    let mut m = meta.clone();
    for kind in TrackKind::ALL {
        if let Some(t) = m.tracks.get_mut(kind) {
            t.segments.retain(|s| segment_usable(dir, s));
        }
    }
    m
}

/// 按 `session.json` 里的起点与停止时刻生成成品。没有任何可用轨道时返回 `Ok(None)`。
pub fn make_meeting(ffmpeg: &Path, dir: &Path, meta: &SessionMeta) -> Result<Option<PathBuf>, MuxError> {
    // 可用与否按原始元数据判断：一条轨道的段全是空的，去掉空段之后列表为空，会被误当成“没重启过”
    let cleaned = without_empty_segments(dir, meta);
    let plan = FinalizePlan::from_meta(&cleaned, |k| track_usable(dir, meta, k));
    if plan.video.is_none() && plan.mic.is_none() && plan.system.is_none() {
        return Ok(None);
    }
    if let Some(segs) = plan.segments.get(&TrackKind::Video).filter(|s| s.len() > 1) {
        let fps = meta.output.as_ref().map(|o| o.fps).ok_or_else(|| MuxError::Failed { code: None, tail: "session.json 里没有画面输出参数，没法拼接画面的各段".into() })?;
        std::fs::write(dir.join(VIDEO_CONCAT_FILE), concat_list(segs, fps))?;
    }
    finalize_meeting(ffmpeg, dir, &plan, AUDIO_RATE, FINALIZE_TIMEOUT).map(Some)
}
```

/// “受限区间”：这段时间里画面是重复的上一帧（安全桌面、画面管线重建）。
#[derive(Debug, Default)]
pub(crate) struct IntervalTracker {
    open: Option<(u64, &'static str)>,
}

pub(crate) const SECURE_DESKTOP: &str = "secure_desktop";
pub(crate) const CAPTURE_LOST: &str = "capture_lost";
/// 画面管线重建一般只要 160 毫秒，不值得记；安全桌面不管多短都记，用户要知道那段是空的。
const MIN_LOST_MS: u64 = 1_000;

impl IntervalTracker {
    pub fn begin(&mut self, at_ms: u64, reason: &'static str) {
        match &mut self.open {
            None => self.open = Some((at_ms, reason)),
            // 重建过程中进入安全桌面：同一段，原因升级成安全桌面
            Some((_, r)) if reason == SECURE_DESKTOP => *r = SECURE_DESKTOP,
            Some(_) => {}
        }
    }

    pub fn end(&mut self, at_ms: u64) -> Option<RestrictedInterval> {
        let (start_ms, reason) = self.open.take()?;
        (reason == SECURE_DESKTOP || at_ms.saturating_sub(start_ms) >= MIN_LOST_MS).then(|| RestrictedInterval { start_ms, end_ms: at_ms, reason: reason.to_string() })
    }
}

/// 取回旧写入器的所有权以便收尾。画面采集线程可能刚好还捏着一个克隆，等一小会儿；
/// 一直等不到就放手：最后一个持有者放下时进程会被一并收掉。
fn reclaim<T>(mut shared: Arc<T>) -> Option<T> {
    for _ in 0..100 {
        match Arc::try_unwrap(shared) {
            Ok(v) => return Some(v),
            Err(back) => {
                shared = back;
                std::thread::sleep(Duration::from_millis(10));
            }
        }
    }
    None
}

fn label_kind(label: &str) -> TrackKind {
    if label == "mic" { TrackKind::Mic } else { TrackKind::System }
}

impl Loop {
    fn elapsed_ms(&self, now: Hns) -> u64 {
        ((now - self.h.t0).max(0) / 10_000) as u64
    }

    fn info(&self, text: String) {
        tracing::info!("{text}");
        let _ = self.h.events.send(EngineEvent::Info(text));
    }

    fn alert(&mut self, a: Alert) {
        let d = &mut self.h.meta.diagnostics;
        match &a {
            Alert::CaptureSilent { .. } => d.capture_silent_alerts += 1,
            Alert::Hung { .. } => d.hung_alerts += 1,
            Alert::LowFps { .. } => d.low_fps_alerts += 1,
            _ => {}
        }
        self.dirty = true;
        if a.is_warning() {
            tracing::warn!("{}", a.describe());
        } else {
            tracing::info!("{}", a.describe());
        }
        let _ = self.h.events.send(EngineEvent::Alert(a));
    }

    fn request_stop(&mut self, reason: EndReason) {
        if !self.stop_requested {
            self.stop_requested = true;
            let _ = self.h.events.send(EngineEvent::RequestStop(reason));
        }
    }

    fn mark_interrupted(&mut self, kind: TrackKind, note: String) {
        self.interrupted[track_index(kind)] = true;
        if let Some(t) = self.h.meta.tracks.get_mut(kind) {
            t.status = TrackStatus::Interrupted;
            t.note = Some(note);
        }
        self.dirty = true;
    }

    fn set_t0(&mut self, kind: TrackKind, t0: Hns) {
        if let Some(t) = self.h.meta.tracks.get_mut(kind).filter(|t| t.t0_hns.is_none()) {
            t.t0_hns = Some(t0);
            self.dirty = true;
        }
    }

    // ----- 事件 -----

    fn drain_events(&mut self) {
        let audio: Vec<AudioEvent> = self.h.audio_rx.try_iter().collect();
        for e in audio {
            self.info(describe_audio_event(&e));
            let now = self.h.qpc.now_hns();
            match &e {
                AudioEvent::LargeGap { label, filled_ms } => self.alert(Alert::LargeGap { track: label_kind(label), ms: *filled_ms }),
                AudioEvent::Interrupted { label } => {
                    let kind = label_kind(label);
                    self.mark_interrupted(kind, "设备丢失超过 10 秒仍未恢复".into());
                    self.alert(Alert::TrackInterrupted { track: kind });
                }
                AudioEvent::Recovered { label } => {
                    let kind = label_kind(label);
                    if self.interrupted[track_index(kind)] {
                        self.interrupted[track_index(kind)] = false;
                        self.alert(Alert::TrackRecovered { track: kind });
                    }
                    // 丢失期间时间线补了静音，这段时间不能算“挂起”
                    if kind == TrackKind::Mic {
                        self.mic_hung.rearm(now);
                    }
                }
                _ => {}
            }
        }
        let video: Vec<VideoEvent> = self.h.video_rx.try_iter().collect();
        for e in video {
            self.info(describe_video_event(&e));
            let now = self.h.qpc.now_hns();
            let at = self.elapsed_ms(now);
            match &e {
                VideoEvent::Opened { hdr: true, rebuild: false, .. } if !self.hdr_noted => {
                    self.hdr_noted = true;
                    self.alert(Alert::HdrActive);
                }
                VideoEvent::Lost { .. } => self.intervals.begin(at, CAPTURE_LOST),
                VideoEvent::SecureDesktop => self.intervals.begin(at, SECURE_DESKTOP),
                VideoEvent::Failed { .. } => {
                    self.video_failed_since.get_or_insert(now);
                    self.intervals.begin(at, CAPTURE_LOST);
                }
                VideoEvent::Recovered { .. } => {
                    self.video_failed_since = None;
                    if let Some(i) = self.intervals.end(at) {
                        self.h.meta.diagnostics.restricted_intervals.push(i);
                        self.dirty = true;
                    }
                    if self.interrupted[track_index(TrackKind::Video)] {
                        self.interrupted[track_index(TrackKind::Video)] = false;
                        self.alert(Alert::TrackRecovered { track: TrackKind::Video });
                    }
                }
                _ => {}
            }
        }
    }

    // ----- 每秒一次 -----

    fn tick_anchors(&mut self) {
        let t0 = self.h.t0;
        self.set_t0(TrackKind::Video, t0);
        for kind in [TrackKind::Mic, TrackKind::System] {
            let anchor = match kind {
                TrackKind::Mic => self.h.mic.as_ref(),
                _ => self.h.system.as_ref(),
            }
            .map(|w| w.live.anchor_hns())
            .unwrap_or(0);
            if anchor != 0 {
                self.set_t0(kind, anchor);
            }
        }
    }

    fn tick_mic(&mut self, now: Hns, active: bool) {
        let Some(mic) = &self.h.mic else { return };
        let pkt = mic.live.last_packet_hns();
        if pkt != self.seen_mic_packet {
            self.seen_mic_packet = pkt;
            if self.mic_hung.progress(now) == Some(HungEvent::Recovered) {
                self.alert(Alert::HungRecovered { track: TrackKind::Mic });
            }
        }
        // 设备丢失已经按“中断”告警过，不再重复报“挂起”
        if let Some(HungEvent::Hung { idle_secs }) = self.mic_hung.tick(now, active)
            && !self.interrupted[track_index(TrackKind::Mic)]
        {
            self.alert(Alert::Hung { track: TrackKind::Mic, secs: idle_secs });
        }
    }

    fn tick_video(&mut self, now: Hns, active: bool, dt: f64) {
        let Some(v) = &self.h.video else { return };
        let (emitted, on_time, fps, down) = (v.live.emitted_frames(), v.live.on_time_frames(), v.spec.fps, v.live.is_down());
        if emitted != self.seen_emitted {
            self.seen_emitted = emitted;
            if self.video_hung.progress(now) == Some(HungEvent::Recovered) {
                self.alert(Alert::HungRecovered { track: TrackKind::Video });
            }
        }
        if let Some(HungEvent::Hung { idle_secs }) = self.video_hung.tick(now, active) {
            self.alert(Alert::Hung { track: TrackKind::Video, secs: idle_secs });
        }
        let achieved = ((on_time - self.seen_on_time) as f64 / dt.max(0.1)).round() as u32;
        self.seen_on_time = on_time;
        match self.low.tick(achieved, fps, active) {
            Some(LowRateEvent::Low { ratio }) => self.alert(Alert::LowFps { ratio }),
            Some(LowRateEvent::Recovered) => self.alert(Alert::LowFpsRecovered),
            None => {}
        }
        // 画面管线持续打不开（不是安全桌面）
        let limit = VIDEO_INTERRUPTED_AFTER.as_secs() as i64 * HNS_PER_SEC;
        if down
            && let Some(since) = self.video_failed_since
            && now - since >= limit
            && !self.interrupted[track_index(TrackKind::Video)]
        {
            self.mark_interrupted(TrackKind::Video, "画面采集持续不可用".into());
            self.alert(Alert::TrackInterrupted { track: TrackKind::Video });
        }
    }

    fn tick_silence(&mut self, active: bool) {
        let Some(sys) = &self.h.system else { return };
        let captured = sys.live.take_peak();
        let meter = self.meters.as_ref().and_then(RenderMeters::max_peak);
        match self.dog.tick(meter, captured, active) {
            Some(WatchdogEvent::Alert) => {
                let device = self.meters.as_ref().and_then(RenderMeters::loudest).map(|(n, _)| n).unwrap_or_else(|| "（未知）".into());
                self.alert(Alert::CaptureSilent { device });
            }
            Some(WatchdogEvent::Recovered) => self.alert(Alert::CaptureSilentRecovered),
            None => {}
        }
    }

    fn writer_health(&self, kind: TrackKind) -> Option<Health> {
        match kind {
            TrackKind::Video => self.h.video.as_ref().map(|v| v.slot.get().health()),
            TrackKind::Mic => self.h.mic.as_ref().map(|a| a.slot.get().health()),
            TrackKind::System => self.h.system.as_ref().map(|a| a.slot.get().health()),
        }
    }

    /// 每个轮询周期看一眼各轨的编码器。出错时自动重启一次：新开一段文件接着写，旧的一段保留，成品里拼起来；
    /// 再出错，或者磁盘已满，这一轨就到此为止，其他轨继续（磁盘满则整场保存并结束）。
    fn check_writers(&mut self) {
        for kind in TrackKind::ALL {
            let i = track_index(kind);
            if self.writer_failed[i] {
                continue;
            }
            let Some(Health::Failed(why)) = self.writer_health(kind) else { continue };
            let short = first_line(&why);
            let disk_full = disk::free_bytes(&self.h.dir).is_some_and(|f| f < DISK_FULL_BYTES);
            let attempt = if disk_full {
                Err("磁盘空间已满，重启也写不进去".to_string())
            } else if self.restarts[i] >= MAX_RESTARTS {
                Err("已经自动重启过一次，不再重试".to_string())
            } else {
                self.restart(kind).map_err(|e| format!("自动重启失败：{e}"))
            };
            match attempt {
                Ok(()) => {
                    self.restarts[i] += 1;
                    self.h.meta.diagnostics.encoder_restarts += 1;
                    if let Some(t) = self.h.meta.tracks.get_mut(kind) {
                        t.note = Some(format!("编码器异常退出（{short}），已自动重启，中间有一小段缺失"));
                    }
                    self.alert(Alert::EncoderRestarted { track: kind, why: short });
                    self.persist();
                }
                Err(why_not) => {
                    self.writer_failed[i] = true;
                    let full = format!("{short}（{why_not}）");
                    self.mark_interrupted(kind, format!("编码器异常退出：{full}"));
                    self.alert(Alert::EncoderFailed { track: kind, why: full });
                    if disk_full {
                        self.request_stop(EndReason::WriteError);
                    }
                }
            }
        }
    }

    /// 换上写进新一段文件的写入器，并把这一段登记进 `session.json`（设计文档 9：编码器自动重启一次）。
    fn restart(&mut self, kind: TrackKind) -> Result<(), String> {
        let track = self.h.meta.tracks.get(kind).ok_or("元数据里没有这一轨")?;
        let file = track.next_segment_file(kind);
        let current = track.files().pop().unwrap_or_else(|| kind.file_name().to_string());
        match kind {
            TrackKind::Video => self.restart_video(&current, file),
            _ => self.restart_audio(kind, file),
        }
    }

    fn restart_video(&mut self, current: &str, file: String) -> Result<(), String> {
        let v = self.h.video.as_ref().ok_or("没有画面轨")?;
        let (spec, slot) = (v.spec, Arc::clone(&v.slot));
        // 旧编码器可能只是管道断了而进程还在：先让它死透，文件才不会再变，也才数得准
        slot.get().kill_process();
        let in_old = count_video_frames(&self.h.ffmpeg, &self.h.dir.join(current), COUNT_FRAMES_TIMEOUT).map_err(|e| format!("数不出上一段有多少帧：{e}"))?;
        // 新的一段从上一段的最后一帧之后接着写；中间丢失的一截，由新段收到的第一帧补齐（画面冻结）
        let next_base = self.video_base + in_old;
        let writer = VideoWriter::spawn_from(&self.h.ffmpeg, &spec, &self.h.dir.join(&file), spec.fps as usize, next_base).map_err(|e| e.to_string())?;
        let old = slot.replace_with(writer, || {});
        if let Some(old) = reclaim(old) {
            let r = old.finish(OLD_WRITER_FINISH);
            let d = &mut self.h.meta.diagnostics.dropped_video_frames;
            d.queue += r.dropped_queue;
            d.error += r.dropped_failed;
            d.resync += r.late_discarded;
        }
        let t0 = self.h.t0 + next_base as i64 * HNS_PER_SEC / i64::from(spec.fps);
        if let Some(t) = self.h.meta.tracks.get_mut(TrackKind::Video) {
            t.push_segment(file, t0, Some(in_old));
        }
        self.video_base = next_base;
        self.dirty = true;
        Ok(())
    }

    fn restart_audio(&mut self, kind: TrackKind, file: String) -> Result<(), String> {
        let w = match kind {
            TrackKind::Mic => self.h.mic.as_ref(),
            _ => self.h.system.as_ref(),
        }
        .ok_or("没有这一轨")?;
        let (slot, delivered, channels) = (Arc::clone(&w.slot), Arc::clone(&w.delivered), w.channels);
        let anchor = w.live.anchor_hns();
        if anchor == 0 {
            return Err("设备还没有开始录音，没有接着录的位置".into());
        }
        slot.get().kill_process();
        let writer = AudioWriter::spawn(&self.h.ffmpeg, &AudioSpec { rate: AUDIO_RATE, channels }, &self.h.dir.join(&file), AUDIO_QUEUE_SECONDS).map_err(|e| e.to_string())?;
        // 在写锁里读已交付的帧数：旧写入器收到的就是这么多，新写入器从下一帧开始；中间没写出来的部分在成品里是静音
        let mut already = 0;
        let old = slot.replace_with(writer, || already = delivered.load(Ordering::Acquire));
        if let Some(old) = reclaim(old) {
            let r = old.finish(OLD_WRITER_FINISH);
            self.h.meta.diagnostics.dropped_audio_samples += r.dropped_queue + r.dropped_failed;
        }
        let t0 = anchor + already as i64 * HNS_PER_SEC / i64::from(AUDIO_RATE);
        if let Some(t) = self.h.meta.tracks.get_mut(kind) {
            t.push_segment(file, t0, None);
        }
        self.dirty = true;
        Ok(())
    }

    fn tick_limits(&mut self, now: Hns) {
        if let Some(free) = disk::free_bytes(&self.h.dir)
            && let Some(reason) = limits::check(self.elapsed_ms(now) / 1000, free, &self.h.cfg.limits)
        {
            self.request_stop(reason);
        }
    }

    fn reopen_meters(&mut self) {
        if let Some(en) = &self.enumerator {
            self.meters = RenderMeters::open_all(en).ok();
        }
    }

    fn tick(&mut self, dt: f64) {
        let now = self.h.qpc.now_hns();
        let active = self.h.active.load(Ordering::Acquire);
        self.tick_n += 1;
        self.tick_anchors();
        self.tick_mic(now, active);
        self.tick_video(now, active, dt);
        self.tick_silence(active);
        if self.tick_n.is_multiple_of(5) {
            self.tick_limits(now);
        }
        // 插拔播放设备后，电平表要跟着重开，否则看门狗盯着已经不存在的设备
        if self.tick_n.is_multiple_of(15) {
            self.reopen_meters();
        }
        self.persist();
    }

    fn persist(&mut self) {
        if self.dirty {
            match save_meta(&self.h.dir, &self.h.meta) {
                Ok(()) => self.dirty = false,
                Err(e) => tracing::warn!("写 session.json 失败：{e}"),
            }
        }
    }
}

/// 线程主体，返回收尾时的 `SessionMeta`。
pub(crate) fn run(h: HealthInput) -> SessionMeta {
    // 这个线程自己初始化 COM（多线程单元），电平表和环境快照都在这里取
    let com = ComGuard::init();
    let enumerator = if com.is_ok() { devices::enumerator().ok() } else { None };
    let meters = enumerator.as_ref().and_then(|e| RenderMeters::open_all(e).ok());
    let now = h.qpc.now_hns();
    let (hung_s, low_ratio, low_s, confirm) = (h.cfg.health.hung_s, h.cfg.health.low_fps_ratio, h.cfg.health.low_fps_s, h.cfg.health.silent_confirm_s);
    let mut l = Loop {
        dog: SilenceWatchdog::new(WatchdogConfig { confirm_ticks: confirm, ..WatchdogConfig::default() }),
        mic_hung: HungDetector::new(hung_s, now),
        video_hung: HungDetector::new(hung_s, now),
        low: LowRateDetector::new(low_ratio, low_s),
        h,
        dirty: false,
        tick_n: 0,
        seen_mic_packet: 0,
        seen_emitted: 0,
        seen_on_time: 0,
        interrupted: [false; 3],
        writer_failed: [false; 3],
        restarts: [0; 3],
        video_base: 0,
        stop_requested: false,
        video_failed_since: None,
        intervals: IntervalTracker::default(),
        hdr_noted: false,
        meters,
        enumerator,
    };
    match &l.enumerator {
        Some(en) => {
            let env = crate::snapshot::environment(en, &l.h.cfg, l.h.encoder, &l.h.ffmpeg, &l.h.monitors);
            l.h.meta.extra.insert("environment".into(), env);
            l.dirty = true;
        }
        None => l.info("无法初始化设备枚举：环境快照与系统音静默检测不可用".into()),
    }
    if l.meters.is_none() && l.h.system.is_some() {
        l.info("无法打开播放设备的电平表：系统音“通但全是静音”的检测不可用".into());
    }

    let mut last = Instant::now();
    let mut next_tick = last + Duration::from_secs(1);
    while !l.h.stop.load(Ordering::Acquire) {
        std::thread::sleep(POLL);
        l.drain_events();
        l.check_writers();
        let t = Instant::now();
        if t >= next_tick {
            let dt = (t - last).as_secs_f64();
            last = t;
            next_tick += Duration::from_secs(1);
            if next_tick < t {
                next_tick = t + Duration::from_secs(1);
            }
            l.tick(dt);
        }
        l.persist();
    }
    l.drain_events();
    // 收尾时仍处于受限的区间：算到停止时刻
    let at = l.elapsed_ms(l.h.qpc.now_hns());
    if let Some(i) = l.intervals.end(at) {
        l.h.meta.diagnostics.restricted_intervals.push(i);
    }
    l.h.meta
}

/// 音频交付：在槽的读锁里“交给写入器 + 给已交付帧数计数”，编码器重启时换写入器正好卡在两次交付之间，
/// 新一段的起点 = 锚点 + 已交付帧数，不会错位。
fn audio_sink(slot: Arc<Slot<AudioWriter>>, kind: TrackKind, fault: Arc<FaultSwitch>, qpc: Qpc, channels: u16, delivered: Arc<AtomicU64>) -> AudioSink {
    Box::new(move |samples| {
        if let Some(d) = fault.remaining_stall(kind, qpc.now_hns()) {
            std::thread::sleep(d);
        }
        let writer = slot.read();
        let _ = writer.push(samples);
        delivered.fetch_add((samples.len() / usize::from(channels)) as u64, Ordering::Release);
    })
}

pub fn start(p: StartParams, events: Sender<EngineEvent>) -> Result<Recorder, StartError> {
    let cfg = &p.config;
    if !(p.tracks.video || p.tracks.mic || p.tracks.system) {
        return Err(StartError::NothingSelected);
    }
    if p.tracks.video && p.encoder == Encoder::Auto {
        return Err(StartError::EncoderNotResolved);
    }
    if p.tracks.system && cfg.audio.system_capture == SystemCapture::AllEndpoints {
        return Err(StartError::AllEndpointsNotImplemented);
    }
    std::fs::create_dir_all(&p.output_dir).map_err(StartError::SessionDir)?;
    if let Some(free) = disk::free_bytes(&p.output_dir)
        && (free as f64) < cfg.limits.min_free_gb * GIB
    {
        return Err(StartError::DiskLow { free_gb: free as f64 / GIB, min_gb: cfg.limits.min_free_gb });
    }
    // 先选显示器再建目录：失败不留任何痕迹
    let video_plan = if p.tracks.video { Some(plan_video(cfg, p.monitor)?) } else { None };

    let qpc = Qpc::new();
    let (dir, id) = create_session_dir(&p.output_dir, &session_id(Local::now().naive_local())).map_err(StartError::SessionDir)?;
    let lock = match SessionLock::acquire(&dir) {
        Ok(l) => l,
        Err(e) => {
            let _ = std::fs::remove_dir_all(&dir);
            return Err(StartError::SessionDir(e));
        }
    };

    let mut meta = SessionMeta::new(&id, &p.app_version, Utc::now(), qpc.frequency());
    for kind in TrackKind::ALL {
        if p.tracks.has(kind) {
            meta.tracks.set(kind, track_meta(kind));
        }
    }
    if let Some(v) = &video_plan {
        meta.monitor = Some(MonitorMeta { name: v.mon.device_name.clone(), width: v.mon.width, height: v.mon.height });
        meta.output = Some(OutputMeta { width: v.out_w, height: v.out_h, fps: cfg.video.fps, encoder: encoder_name(p.encoder) });
    }

    let (audio_tx, audio_rx) = unbounded();
    let (video_tx, video_rx) = unbounded();
    let fault = Arc::new(FaultSwitch::default());
    let active = Arc::new(AtomicBool::new(true));
    let health_stop = Arc::new(AtomicBool::new(false));
    let mut rec = Recorder {
        id: id.clone(),
        dir: dir.clone(),
        ffmpeg: p.ffmpeg.clone(),
        qpc,
        t0: 0,
        started: Instant::now(),
        video: None,
        mic: None,
        system: None,
        health: None,
        health_stop: Arc::clone(&health_stop),
        active: Arc::clone(&active),
        fault: Arc::clone(&fault),
        lock: Some(lock),
        initial_meta: meta.clone(),
    };

    let launched = (|| -> Result<(), StartError> {
        save_meta(&dir, &meta).map_err(StartError::SessionDir)?;

        // 先把各轨的 ffmpeg 起来：它们初始化编码器要几百毫秒，期间采集的数据在队列里等着
        let video_slot = match &video_plan {
            Some(v) => {
                let spec = VideoSpec { width: v.out_w, height: v.out_h, fps: cfg.video.fps, encoder: p.encoder };
                let w = VideoWriter::spawn(&p.ffmpeg, &spec, &dir.join(TrackKind::Video.file_name()), cfg.video.fps as usize)?;
                Some(Slot::new(w))
            }
            None => None,
        };
        let mut audio_slots: Vec<(TrackKind, Arc<Slot<AudioWriter>>)> = Vec::new();
        for (kind, channels) in [(TrackKind::System, 2u16), (TrackKind::Mic, 1u16)] {
            if p.tracks.has(kind) {
                let w = AudioWriter::spawn(&p.ffmpeg, &AudioSpec { rate: AUDIO_RATE, channels }, &dir.join(kind.file_name()), AUDIO_QUEUE_SECONDS)?;
                audio_slots.push((kind, Slot::new(w)));
            }
        }

        // 采集源：回环、麦克风、画面。所有 ffmpeg 就绪之后才取 t0
        let t0 = qpc.now_hns();
        rec.t0 = t0;
        for (kind, slot) in audio_slots {
            let (label, k, endpoint, channels, time_source) = match kind {
                TrackKind::System => {
                    let endpoint = match cfg.audio.system_device.as_str() {
                        "default" => Endpoint::Default(match cfg.audio.system_capture {
                            SystemCapture::CommunicationsEndpoint => Role::Communications,
                            _ => Role::Console,
                        }),
                        id => Endpoint::Id(id.to_string()),
                    };
                    ("system", Kind::Loopback, endpoint, 2u16, cfg.audio.system_time_source)
                }
                _ => {
                    let endpoint = match cfg.audio.mic_device.as_str() {
                        "default" => Endpoint::Default(role_of(cfg.audio.mic_role)),
                        id => Endpoint::Id(id.to_string()),
                    };
                    ("mic", Kind::Mic, endpoint, 1u16, cfg.audio.mic_time_source)
                }
            };
            let mut sc = SourceConfig::new(label, k, endpoint, cfg.timeline_config(AudioFormat { rate: AUDIO_RATE, channels }, time_source));
            if kind == TrackKind::System {
                sc.keepalive = cfg.audio.system_keepalive;
            }
            let delivered = Arc::new(AtomicU64::new(0));
            let sink = audio_sink(Arc::clone(&slot), kind, Arc::clone(&fault), qpc, channels, Arc::clone(&delivered));
            let source =
                AudioSource::start(sc, qpc, audio_tx.clone(), sink).map_err(|e| StartError::Capture { what: if kind == TrackKind::Mic { "麦克风" } else { "系统音" }, why: e.to_string() })?;
            let part = AudioPart { kind, slot, source, channels, delivered };
            if kind == TrackKind::System {
                rec.system = Some(part);
            } else {
                rec.mic = Some(part);
            }
        }
        if let (Some(v), Some(slot)) = (&video_plan, video_slot) {
            let vc = VideoConfig { monitor: v.mon.clone(), fps: cfg.video.fps, out_w: v.out_w, out_h: v.out_h, t0, rebuild_interval: Duration::from_secs(1) };
            let source =
                VideoSource::start(vc, qpc, video_tx.clone(), video_sink(Arc::clone(&slot), Arc::clone(&fault), qpc)).map_err(|e| StartError::Capture { what: "画面", why: e.to_string() })?;
            rec.video = Some(VideoPart { slot, source });
        }

        // 视频起点马上落盘；音频起点由健康线程在采集线程发布后补上
        if let Some(t) = meta.tracks.video.as_mut() {
            t.t0_hns = Some(t0);
        }
        save_meta(&dir, &meta).map_err(StartError::SessionDir)?;
        rec.initial_meta = meta.clone();

        let input = HealthInput {
            cfg: cfg.clone(),
            encoder: p.encoder,
            ffmpeg: p.ffmpeg.clone(),
            monitors: video_plan.as_ref().map(|v| v.all.clone()).unwrap_or_default(),
            dir: dir.clone(),
            qpc,
            t0,
            meta: meta.clone(),
            video: match (&rec.video, &video_plan) {
                (Some(v), Some(plan)) => {
                    Some(VideoWatch { live: Arc::clone(v.source.live()), slot: Arc::clone(&v.slot), spec: VideoSpec { width: plan.out_w, height: plan.out_h, fps: cfg.video.fps, encoder: p.encoder } })
                }
                _ => None,
            },
            mic: rec.mic.as_ref().map(AudioPart::watch),
            system: rec.system.as_ref().map(AudioPart::watch),
            audio_rx,
            video_rx,
            events: events.clone(),
            stop: Arc::clone(&health_stop),
            active: Arc::clone(&active),
        };
        let health = std::thread::Builder::new().name("health".into()).spawn(move || health_loop::run(input)).map_err(StartError::SessionDir)?;
        rec.health = Some(health);
        Ok(())
    })();

    if let Err(e) = launched {
        rec.abort();
        return Err(e);
    }
    if p.tracks.mic && !has_default_mic(role_of(cfg.audio.mic_role)) {
        let _ = events.send(EngineEvent::Alert(crate::events::Alert::NoMic));
    }
    rec.started = Instant::now();
    Ok(rec)
}

impl Recorder {
    pub fn id(&self) -> &str {
        &self.id
    }

    pub fn dir(&self) -> &std::path::Path {
        &self.dir
    }

    pub fn status(&self) -> Status {
        // 轨道文件：mkv 是画面，mka 是音频；编码器重启过的轨道还有后续各段
        let bytes = std::fs::read_dir(&self.dir)
            .into_iter()
            .flatten()
            .flatten()
            .filter(|e| matches!(e.path().extension().and_then(|x| x.to_str()), Some("mkv" | "mka")))
            .filter_map(|e| e.metadata().ok())
            .map(|m| m.len())
            .sum();
        Status { id: self.id.clone(), dir: self.dir.clone(), elapsed: self.started.elapsed(), bytes }
    }

    /// 睡眠、锁屏期间传 `false`：基于超时的探测器暂停，恢复后重新布防。
    pub fn set_active(&self, active: bool) {
        self.active.store(active, Ordering::Release);
    }

    /// 故障注入（设计文档 10.1 S3）。
    pub fn inject(&self, fault: Fault) -> Result<(), String> {
        match fault {
            Fault::StallCapture { track, secs } => {
                if !self.has(track) {
                    return Err(format!("这场录制没有{}", crate::events::track_name(track)));
                }
                self.fault.stall_until(track, self.qpc.now_hns() + secs as i64 * HNS_PER_SEC);
                Ok(())
            }
            Fault::KillEncoder { track } => match track {
                TrackKind::Video => self.video.as_ref().map(|v| v.slot.get().kill_process()),
                TrackKind::Mic => self.mic.as_ref().map(|a| a.slot.get().kill_process()),
                TrackKind::System => self.system.as_ref().map(|a| a.slot.get().kill_process()),
            }
            .ok_or_else(|| format!("这场录制没有{}", crate::events::track_name(track))),
        }
    }

    fn has(&self, kind: TrackKind) -> bool {
        match kind {
            TrackKind::Video => self.video.is_some(),
            TrackKind::Mic => self.mic.is_some(),
            TrackKind::System => self.system.is_some(),
        }
    }

    /// 启动中途失败时的清理：停掉已启动的一切，删掉会话目录，不留半成品。
    fn abort(mut self) {
        self.health_stop.store(true, Ordering::Release);
        if let Some(h) = self.health.take() {
            let _ = h.join();
        }
        let parts = [self.system.take(), self.mic.take()];
        for a in parts.into_iter().flatten() {
            a.slot.get().kill_process();
            drop(a.source);
        }
        if let Some(v) = self.video.take() {
            v.slot.get().kill_process();
            drop(v.source);
        }
        if let Some(l) = self.lock.take() {
            l.release();
        }
        let _ = std::fs::remove_dir_all(&self.dir);
    }

    /// 保存并结束：补齐各轨到停止时刻、等 ffmpeg 写完、生成 `meeting.mp4`、写好 `session.json`。
    /// 会阻塞几秒（视频编码器冲刷、成品封装），外壳应在工作线程里调用。
    pub fn stop(mut self, reason: EndReason) -> StopOutcome {
        let begin = Instant::now();
        let stopped_hns = self.qpc.now_hns();
        let mut warnings: Vec<String> = Vec::new();

        // 各轨先一起请求停止，停止时刻才几乎相同
        for a in [&self.system, &self.mic].into_iter().flatten() {
            a.source.request_stop();
        }
        if let Some(v) = &self.video {
            v.source.request_stop();
        }
        let video_res: Option<(Arc<Slot<VideoWriter>>, VideoResult)> = self.video.take().map(|v| {
            let res = v.source.stop();
            (v.slot, res)
        });
        let audio_res: Vec<(TrackKind, Arc<Slot<AudioWriter>>, SourceResult)> = [self.system.take(), self.mic.take()]
            .into_iter()
            .flatten()
            .map(|a| {
                let res = a.source.stop();
                (a.kind, a.slot, res)
            })
            .collect();

        self.health_stop.store(true, Ordering::Release);
        let mut meta = match self.health.take().map(JoinHandle::join) {
            Some(Ok(m)) => m,
            _ => {
                warnings.push("健康监测线程异常退出，诊断信息不完整".into());
                self.initial_meta.clone()
            }
        };
        let sources_ms = begin.elapsed().as_millis() as u64;

        let writers_begin = Instant::now();
        let mut writer_reports = serde_json::Map::new();
        meta.stopped_hns = Some(stopped_hns);

        if let Some((slot, res)) = video_res {
            let report = finish_video(slot);
            meta.diagnostics.absorb_video(&res.stats);
            // 加上去：编码器重启过的话，之前几段的计数已经由健康线程记进来了
            meta.diagnostics.dropped_video_frames.queue += report.dropped_queue;
            meta.diagnostics.dropped_video_frames.error += report.dropped_failed;
            meta.diagnostics.dropped_video_frames.resync += report.late_discarded;
            if let Some(t) = meta.tracks.video.as_mut()
                && res.first_frame_ms.is_none()
            {
                t.t0_hns = None;
                t.status = TrackStatus::Missing;
                t.note = Some("没有采到任何画面".into());
                warnings.push("没有采到任何画面，成品里不含画面".into());
            }
            meta.extra.insert(
                "video_capture".into(),
                json!({
                    "src": [res.src_w, res.src_h], "out": [res.out_w, res.out_h], "hdr": res.hdr,
                    "rebuilds": res.rebuilds, "lost": res.lost, "secure_desktop_episodes": res.secure_desktop_episodes,
                    "first_frame_ms": res.first_frame_ms, "down_ms": res.down_ms,
                    "frames": { "fresh": res.stats.fresh, "no_change": res.stats.repeat_no_change, "catch_up": res.stats.catch_up },
                    "grab_us": { "count": res.grab.count, "p50": res.grab.p50_us, "p95": res.grab.p95_us, "p99": res.grab.p99_us, "max": res.grab.max_us },
                }),
            );
            if let Some(why) = &report.failed {
                warnings.push(format!("画面编码器出错：{why}"));
            }
            writer_reports.insert("video".into(), writer_json(&report));
        }
        for (kind, slot, res) in audio_res {
            let report = finish_audio(slot);
            meta.diagnostics.absorb_audio(kind.key(), AUDIO_RATE, &res.stats);
            meta.diagnostics.device_changes += res.device_changes;
            meta.diagnostics.dropped_audio_samples += report.dropped_queue + report.dropped_failed;
            let has_data = res.anchor != 0;
            let track = match kind {
                TrackKind::Mic => meta.tracks.mic.as_mut(),
                _ => meta.tracks.system.as_mut(),
            };
            if let Some(t) = track {
                if has_data {
                    t.t0_hns = Some(res.anchor);
                } else {
                    t.t0_hns = None;
                    t.status = TrackStatus::Missing;
                    t.note = Some("设备始终没有打开".into());
                    warnings.push(format!("{}始终没有打开，成品里不含这一轨", crate::events::track_name(kind)));
                }
            }
            if let Some(why) = &report.failed {
                warnings.push(format!("{}编码器出错：{why}", crate::events::track_name(kind)));
            }
            writer_reports.insert(kind.key().into(), writer_json(&report));
        }
        meta.extra.insert("writers".into(), serde_json::Value::Object(writer_reports));
        for kind in TrackKind::ALL {
            if meta.tracks.get(kind).is_some_and(|t| t.segments.len() > 1) {
                warnings.push(format!("{}的编码器在录制中异常退出过，已自动重启，成品里有一小段缺失", crate::events::track_name(kind)));
            }
        }
        let writers_ms = writers_begin.elapsed().as_millis() as u64;

        // 先落一次盘（仍是 recording）：收尾中途崩溃时，恢复流程能拿到各轨起点与停止时刻
        if let Err(e) = save_meta(&self.dir, &meta) {
            warnings.push(format!("写 session.json 失败：{e}"));
        }
        let finalize_begin = Instant::now();
        let meeting = match meeting::make_meeting(&self.ffmpeg, &self.dir, &meta) {
            Ok(Some(path)) => Some(path),
            Ok(None) => {
                warnings.push("没有任何可用的轨道，没有生成 meeting.mp4".into());
                None
            }
            Err(e) => {
                warnings.push(format!("生成 meeting.mp4 失败（原始轨道文件都在，下次启动会重试）：{e}"));
                None
            }
        };
        let finalize_ms = finalize_begin.elapsed().as_millis() as u64;

        meta.finalize(reason, Utc::now());
        if let Err(e) = save_meta(&self.dir, &meta) {
            warnings.push(format!("写 session.json 失败：{e}"));
        }
        if let Some(l) = self.lock.take() {
            l.release();
        }
        let t0 = self.t0;
        StopOutcome {
            id: std::mem::take(&mut self.id),
            dir: std::mem::take(&mut self.dir),
            reason,
            meeting,
            duration_secs: (stopped_hns - t0).max(0) as f64 / HNS_PER_SEC as f64,
            warnings,
            meta,
            timings: StopTimings { sources_ms, writers_ms, finalize_ms },
        }
    }
}

fn probe_duration(path: &Path) -> f64 {
    let out = Command::new(ffprobe_for(&ffmpeg())).args(["-v", "error", "-show_entries", "format=duration", "-of", "default=nw=1:nk=1"]).arg(path).output().expect("启动 ffprobe");

/// 写一个 `seconds` 秒的单声道正弦波音轨。
fn write_tone(path: &Path, seconds: f64) {
    let w = AudioWriter::spawn(&ffmpeg(), &AudioSpec { rate: RATE, channels: 1 }, path, 10).unwrap();
    let frames = (seconds * f64::from(RATE)) as usize;
    let samples: Vec<f32> = (0..frames).map(|n| (2.0 * std::f64::consts::PI * 440.0 * n as f64 / f64::from(RATE)).sin() as f32 * 0.25).collect();

        w.push(chunk);
    }

}

/// 画面：640×360、15 帧/秒的合成帧，从全局序号 `from` 写到 `to`（不含）；`base` 是这一段的第一个序号。
fn write_video_segment(path: &Path, base: u64, from: u64, to: u64) {
    let spec = VideoSpec { width: 640, height: 360, fps: 15, encoder: Encoder::Nvenc };
    let w = VideoWriter::spawn_from(&ffmpeg(), &spec, path, 32, base).unwrap();
    for i in from..to {
        let mut f = vec![128u8; 640 * 360 * 3 / 2];
        for (n, px) in f[..640 * 360].iter_mut().enumerate() {
            *px = ((n % 640 + n / 640 + i as usize * 7) % 220 + 16) as u8;
        }
        w.submit(i, Arc::from(f));
    }
    let r = w.finish(Duration::from_secs(20));
    assert_eq!((r.exit_code, r.failed.clone()), (Some(0), None), "{r:?}");
}

//! 崩溃恢复的执行（设计文档 5.8）。判定在 `record_core::recovery`，这里调 ffmpeg、改文件。
//!
//! 启动时扫描保存目录；崩溃、被杀、断电留下的会话（`state = recording` 且没有进程占着）：
//! 每个轨道文件做拷贝式修复，补做 `meeting.mp4`，标为 `recovered`。

use crate::lock;
use crate::meeting::make_meeting;
use chrono::{DateTime, Utc};
use record_core::recovery::{RecoveryPlan, plan};
use record_core::session::{EndReason, SESSION_FILE, load_meta, save_meta};
use record_mux::finalize::repair_track;
use std::path::{Path, PathBuf};
use std::time::{Duration, SystemTime};

const REPAIR_TIMEOUT: Duration = Duration::from_secs(10 * 60);

#[derive(Debug, Clone, PartialEq)]
pub struct RecoveryReport {
    pub id: String,
    pub dir: PathBuf,
    pub plan: RecoveryPlan,
    /// 修复成功的轨道文件（编码器重启过的轨道含每一段）。
    pub repaired: Vec<String>,
    /// 修复失败的轨道文件：原文件原样保留。
    pub repair_errors: Vec<(String, String)>,
    pub meeting: Option<PathBuf>,
    /// 其他失败（读写 `session.json`、生成成品）。
    pub errors: Vec<String>,
}

fn has_file(dir: &Path) -> impl Fn(&str) -> bool + '_ {
    move |name| dir.join(name).is_file()
}

/// 需要恢复的会话目录：有 `session.json`、没有进程占着、计划里有事要做。读不懂的 `session.json` 不动，由调用方另行报告。
pub fn candidates(base: &Path) -> Vec<PathBuf> {
    let Ok(rd) = std::fs::read_dir(base) else { return Vec::new() };
    let mut dirs: Vec<PathBuf> = rd
        .filter_map(Result::ok)
        .map(|e| e.path())
        .filter(|p| p.is_dir() && p.join(SESSION_FILE).is_file())
        .filter(|p| !lock::is_active(p))
        .filter(|p| load_meta(p).is_ok_and(|m| !plan(&m, has_file(p)).is_noop()))
        .collect();
    dirs.sort();
    dirs
}

/// 修复一个会话。没有事要做或者正被别的进程录制时返回 `Ok(None)`。
pub fn recover(ffmpeg: &Path, dir: &Path) -> std::io::Result<Option<RecoveryReport>> {
    if lock::is_active(dir) {
        return Ok(None);
    }
    let mut meta = load_meta(dir)?;
    let todo = plan(&meta, has_file(dir));
    if todo.is_noop() {
        return Ok(None);
    }
    // 结束时间取各轨文件最后写入的时刻，比“现在”更接近真实；必须在修复改写这些文件之前读
    let ended = todo.repair.iter().filter_map(|f| std::fs::metadata(dir.join(f)).and_then(|m| m.modified()).ok()).max().unwrap_or_else(SystemTime::now);
    let mut report = RecoveryReport { id: meta.id.clone(), dir: dir.to_path_buf(), plan: todo.clone(), repaired: Vec::new(), repair_errors: Vec::new(), meeting: None, errors: Vec::new() };
    for file in &todo.repair {
        match repair_track(ffmpeg, &dir.join(file), REPAIR_TIMEOUT) {
            Ok(()) => report.repaired.push(file.clone()),
            Err(e) => report.repair_errors.push((file.clone(), e.to_string())),
        }
    }
    if todo.remux {
        match make_meeting(ffmpeg, dir, &meta) {
            Ok(path) => report.meeting = path,
            Err(e) => report.errors.push(format!("生成 meeting.mp4 失败：{e}")),
        }
    }
    if todo.mark_recovered {
        meta.finalize(EndReason::Recovered, DateTime::<Utc>::from(ended));
        if let Err(e) = save_meta(dir, &meta) {
            report.errors.push(format!("写 session.json 失败：{e}"));
        }
        // 崩溃遗留的、没人占用的锁文件
        let _ = std::fs::remove_file(dir.join(lock::LOCK_FILE));
    }
    Ok(Some(report))
}

pub fn recover_all(ffmpeg: &Path, base: &Path) -> Vec<RecoveryReport> {
    candidates(base).iter().filter_map(|d| recover(ffmpeg, d).ok().flatten()).collect()
}

//! 闪屏窗口：整块纯色在黑与白之间切换，用来测量画面与声音的同步（设计文档 10 的 S3）。
//!
//! 窗口置顶、不抢焦点、鼠标穿透。切换用事件唤醒窗口线程，不靠定时轮询，从调用 [`FlashWindow::set`] 到开始重绘不到 1 毫秒。
//! 这是验证用的辅助代码，不会进入正式的录制路径。

use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::mpsc;
use std::thread::{self, JoinHandle};
use windows::Win32::Foundation::{COLORREF, CloseHandle, HANDLE, HWND, LPARAM, LRESULT, RECT, WAIT_OBJECT_0, WPARAM};
use windows::Win32::Graphics::Gdi::{BeginPaint, CreateSolidBrush, DeleteObject, EndPaint, FillRect, InvalidateRect, PAINTSTRUCT, UpdateWindow};
use windows::Win32::System::LibraryLoader::GetModuleHandleW;
use windows::Win32::System::Threading::{CreateEventW, SetEvent};
use windows::Win32::UI::WindowsAndMessaging::{
    CREATESTRUCTW, CreateWindowExW, DefWindowProcW, DestroyWindow, DispatchMessageW, GWLP_USERDATA, GetClientRect, GetWindowLongPtrW, LWA_ALPHA, MSG, MsgWaitForMultipleObjects, PM_REMOVE,
    PeekMessageW, PostQuitMessage, QS_ALLINPUT, RegisterClassExW, SW_SHOWNOACTIVATE, SetLayeredWindowAttributes, SetWindowLongPtrW, ShowWindow, TranslateMessage, WM_DESTROY, WM_ERASEBKGND,
    WM_NCCREATE, WM_NCHITTEST, WM_PAINT, WM_QUIT, WNDCLASSEXW, WS_EX_LAYERED, WS_EX_NOACTIVATE, WS_EX_TOOLWINDOW, WS_EX_TOPMOST, WS_EX_TRANSPARENT, WS_POPUP,
};
use windows::core::{PCWSTR, w};

struct State {
    on: Arc<AtomicBool>,
}

pub struct FlashWindow {
    on: Arc<AtomicBool>,
    stop: Arc<AtomicBool>,
    /// 唤醒窗口线程的事件（句柄值，线程间传递用）。
    signal: isize,
    thread: Option<JoinHandle<()>>,
}

unsafe fn paint(hwnd: HWND, st: &State) {
    let mut ps = PAINTSTRUCT::default();
    let hdc = unsafe { BeginPaint(hwnd, &mut ps) };
    let mut rc = RECT::default();
    unsafe {
        let _ = GetClientRect(hwnd, &mut rc);
        let level = if st.on.load(Ordering::Acquire) { 255 } else { 0 };
        let brush = CreateSolidBrush(COLORREF(level | level << 8 | level << 16));
        FillRect(hdc, &rc, brush);
        let _ = DeleteObject(brush.into());
        let _ = EndPaint(hwnd, &ps);
    }
}

unsafe extern "system" fn wndproc(hwnd: HWND, msg: u32, wparam: WPARAM, lparam: LPARAM) -> LRESULT {
    if msg == WM_NCCREATE {
        let cs = lparam.0 as *const CREATESTRUCTW;
        unsafe { SetWindowLongPtrW(hwnd, GWLP_USERDATA, (*cs).lpCreateParams as isize) };
        return unsafe { DefWindowProcW(hwnd, msg, wparam, lparam) };
    }
    let st = unsafe { GetWindowLongPtrW(hwnd, GWLP_USERDATA) } as *const State;
    match msg {
        WM_PAINT if !st.is_null() => {
            unsafe { paint(hwnd, &*st) };
            LRESULT(0)
        }
        WM_ERASEBKGND => LRESULT(1),
        // HTTRANSPARENT 是 -1：鼠标点击穿过窗口，不挡住用户操作
        WM_NCHITTEST => LRESULT(-1),
        WM_DESTROY => {
            unsafe { PostQuitMessage(0) };
            LRESULT(0)
        }
        _ => unsafe { DefWindowProcW(hwnd, msg, wparam, lparam) },
    }
}

fn window_thread(rect: (i32, i32, u32, u32), on: Arc<AtomicBool>, stop: Arc<AtomicBool>, signal: isize, ready: mpsc::Sender<Result<(), String>>) {
    let hinstance = match unsafe { GetModuleHandleW(None) } {
        Ok(h) => h,
        Err(e) => {
            let _ = ready.send(Err(format!("GetModuleHandle：{e}")));
            return;
        }
    };
    let class = w!("RecordFlashWindow");
    let wc = WNDCLASSEXW { cbSize: std::mem::size_of::<WNDCLASSEXW>() as u32, lpfnWndProc: Some(wndproc), hInstance: hinstance.into(), lpszClassName: class, ..Default::default() };
    // 同一进程里第二次注册会失败（类已存在），不影响创建窗口
    unsafe { RegisterClassExW(&wc) };

    let state = Box::new(State { on });
    let ex = WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_LAYERED | WS_EX_TRANSPARENT;
    let (left, top, width, height) = rect;
    let hwnd =
        match unsafe { CreateWindowExW(ex, class, PCWSTR::null(), WS_POPUP, left, top, width as i32, height as i32, None, None, Some(hinstance.into()), Some(&*state as *const State as *const _)) } {
            Ok(h) => h,
            Err(e) => {
                let _ = ready.send(Err(format!("CreateWindowEx：{e}")));
                return;
            }
        };
    unsafe {
        let _ = SetLayeredWindowAttributes(hwnd, COLORREF(0), 255, LWA_ALPHA);
        let _ = ShowWindow(hwnd, SW_SHOWNOACTIVATE);
        let _ = UpdateWindow(hwnd);
    }
    let _ = ready.send(Ok(()));

    let handles = [HANDLE(signal as *mut _)];
    let mut msg = MSG::default();
    'outer: loop {
        // 有事件（要切换颜色）或消息就醒；50 毫秒的上限只是为了定期看一眼停止标志
        let woke = unsafe { MsgWaitForMultipleObjects(Some(&handles), false, 50, QS_ALLINPUT) };
        while unsafe { PeekMessageW(&mut msg, None, 0, 0, PM_REMOVE) }.as_bool() {
            if msg.message == WM_QUIT {
                break 'outer;
            }
            unsafe {
                let _ = TranslateMessage(&msg);
                DispatchMessageW(&msg);
            }
        }
        if stop.load(Ordering::Acquire) {
            unsafe {
                let _ = DestroyWindow(hwnd);
            }
            continue;
        }
        if woke == WAIT_OBJECT_0 {
            unsafe {
                let _ = InvalidateRect(Some(hwnd), None, false);
                let _ = UpdateWindow(hwnd);
            }
        }
    }
    drop(state);
}

impl FlashWindow {
    /// 在桌面坐标 `(left, top)` 处开一个 `width`×`height`（物理像素；进程需是 Per-Monitor DPI 感知）的窗口，初始为黑色。
    pub fn open(left: i32, top: i32, width: u32, height: u32) -> Result<Self, String> {
        let on = Arc::new(AtomicBool::new(false));
        let stop = Arc::new(AtomicBool::new(false));
        let signal = unsafe { CreateEventW(None, false, false, None) }.map_err(|e| format!("创建事件：{e}"))?;
        let signal = signal.0 as isize;
        let (tx, rx) = mpsc::channel();
        let (on2, stop2) = (Arc::clone(&on), Arc::clone(&stop));
        let thread = thread::Builder::new().name("flash-window".into()).spawn(move || window_thread((left, top, width, height), on2, stop2, signal, tx)).map_err(|e| e.to_string())?;
        rx.recv().map_err(|_| "窗口线程提前退出".to_string())??;
        Ok(Self { on, stop, signal, thread: Some(thread) })
    }

    /// 切换成白（`true`）或黑（`false`）。立即返回，重绘由窗口线程完成。
    pub fn set(&self, on: bool) {
        self.on.store(on, Ordering::Release);
        unsafe {
            let _ = SetEvent(HANDLE(self.signal as *mut _));
        }
    }

    pub fn close(mut self) {
        self.shutdown();
    }

    fn shutdown(&mut self) {
        self.stop.store(true, Ordering::Release);
        unsafe {
            let _ = SetEvent(HANDLE(self.signal as *mut _));
        }
        if let Some(t) = self.thread.take() {
            let _ = t.join();
            unsafe {
                let _ = CloseHandle(HANDLE(self.signal as *mut _));
            }
        }
    }
}

impl Drop for FlashWindow {
    fn drop(&mut self) {
        self.shutdown();
    }
}

}

/// `stall:mic:10@5`（5 秒时让麦克风采集线程停 10 秒）、`kill:video@20`（20 秒时杀掉画面编码器），逗号分隔可写多条。
pub(crate) fn parse_inject(text: &str) -> Result<Vec<(Duration, Fault)>> {
    let mut out = Vec::new();
    for item in text.split(',').map(str::trim).filter(|s| !s.is_empty()) {
        let (what, at) = item.split_once('@').with_context(|| format!("注入“{item}”缺少 @ 时刻"))?;
        let at = Duration::from_secs_f64(at.parse::<f64>().with_context(|| format!("注入“{item}”的时刻不是数字"))?);
        let parts: Vec<&str> = what.split(':').collect();
        let fault = match parts.as_slice() {
            ["stall", track, secs] => Fault::StallCapture { track: parse_track(track)?, secs: secs.parse().with_context(|| format!("注入“{item}”的秒数"))? },
            ["kill", track] => Fault::KillEncoder { track: parse_track(track)? },
            _ => bail!("注入“{item}”的格式应为 stall:轨道:秒@时刻 或 kill:轨道@时刻"),
        };
        out.push((at, fault));
    }
    out.sort_by_key(|(at, _)| *at);
    Ok(out)
}

fn parse_monitor(s: &str) -> Result<Pick> {
    let sel = match s.parse::<u32>() {
        Ok(n) => MonitorSel::Index(n),
        Err(_) => MonitorSel::Named(s.to_string()),
    };
    pick_from_config(&sel).map_err(anyhow::Error::msg)
}

fn stamp(since: Duration) -> String {
    format!("[{:02}:{:04.1}]", since.as_secs() / 60, since.as_secs_f64() % 60.0)
}

fn print_event(since: Duration, e: &EngineEvent) {
    match e {
        EngineEvent::Info(t) => println!("{} {t}", stamp(since)),
        EngineEvent::Alert(a) => println!("{} {} {}", stamp(since), if a.is_warning() { "!! 告警" } else { "-- 提示" }, a.describe()),
        EngineEvent::RequestStop(r) => println!("{} >> 引擎要求结束本场：{}", stamp(since), r.describe()),
    }
}

fn default_dir() -> PathBuf {
    std::env::temp_dir().join("record-sessions")
}

pub fn record_cmd(a: &Args) -> Result<()> {
    ensure_dpi_aware();
    let secs: f64 = a.num("secs", 30.0)?;
    let out_dir = a.get("out").map(PathBuf::from).unwrap_or_else(default_dir);
    let ffmpeg = record_mux::locate::find_ffmpeg()?;
    let mut config = match a.get("config") {
        Some(p) => Config::load(Path::new(p))?,
        None => Config::default(),
    };
    config.video.fps = a.num("fps", config.video.fps)?;
    let tracks = TrackSelect { video: !a.flag("no-video"), mic: !a.flag("no-mic"), system: !a.flag("no-system") };
    let wanted = parse_encoder(a.get("encoder").unwrap_or("auto"))?;
    let encoder = if tracks.video { record_mux::probe::resolve_encoder(&ffmpeg, wanted)? } else { wanted };
    let monitor = a.get("monitor").map(parse_monitor).transpose()?;
    let mut pending = a.get("inject").map(parse_inject).transpose()?.unwrap_or_default();

    let (tx, rx) = unbounded();
    let params = StartParams { config, ffmpeg, encoder, output_dir: out_dir.clone(), app_version: env!("CARGO_PKG_VERSION").into(), tracks, monitor };
    let t_call = Instant::now();
    let rec = start(params, tx)?;
    let start_ms = t_call.elapsed().as_millis();
    println!("已开始：{}（start 用时 {start_ms} ms，编码器 {encoder:?}，目录 {}）", rec.id(), rec.dir().display());

    let t0 = Instant::now();
    let mut reason = EndReason::User;
    let mut last_status = Instant::now();
    loop {
        let since = t0.elapsed();
        if since.as_secs_f64() >= secs {
            break;
        }
        while pending.first().is_some_and(|(at, _)| since >= *at) {
            let (_, fault) = pending.remove(0);
            match rec.inject(fault) {
                Ok(()) => println!("{} ** 注入：{fault:?}", stamp(since)),
                Err(e) => println!("{} ** 注入失败：{e}", stamp(since)),
            }
        }
        if last_status.elapsed() >= Duration::from_secs(10) {
            last_status = Instant::now();
            let st = rec.status();
            println!("{} 录制中：{:.0} 秒，已写入 {:.1} MB", stamp(since), st.elapsed.as_secs_f64(), st.bytes as f64 / 1e6);
        }
        match rx.recv_timeout(Duration::from_millis(100)) {
            Ok(EngineEvent::RequestStop(r)) => {
                print_event(since, &EngineEvent::RequestStop(r));
                reason = r;
                break;
            }
            Ok(e) => print_event(since, &e),
            Err(RecvTimeoutError::Timeout) => {}
            Err(RecvTimeoutError::Disconnected) => {}
        }
    }

    let t_stop = Instant::now();
    let outcome = rec.stop(reason);
    let stop_ms = t_stop.elapsed().as_millis();
    for e in rx.try_iter() {
        print_event(t0.elapsed(), &e);
    }
    println!("已保存：{}（{}）", outcome.dir.display(), outcome.reason.describe());
    println!(
        "录制时长 {:.2} 秒；stop 用时 {stop_ms} ms（采集源 {} ms，写入器 {} ms，成品 {} ms）",
        outcome.duration_secs, outcome.timings.sources_ms, outcome.timings.writers_ms, outcome.timings.finalize_ms
    );
    for kind in TrackKind::ALL {
        let Some(t) = outcome.meta.tracks.get(kind) else { continue };
        // 编码器重启过的轨道有好几段文件，每段单独列出
        for file in t.files() {
            if let Ok(m) = std::fs::metadata(outcome.dir.join(&file)) {
                println!("  {:<11} {:>8.2} MB  状态 {:?}  起点偏移 {:?} ms", file, m.len() as f64 / 1e6, t.status, outcome.meta.tracks.offsets_hns().get(&kind).map(|v| v / 10_000));
            }
        }
    }
    match &outcome.meeting {
        Some(p) => println!("  meeting.mp4 {:>8.2} MB  {}", std::fs::metadata(p)?.len() as f64 / 1e6, p.display()),
        None => println!("  没有生成 meeting.mp4"),
    }
    for w in &outcome.warnings {
        println!("  警告：{w}");
    }
    println!("{}", serde_json::to_string_pretty(&outcome.meta.diagnostics)?);
    Ok(())
}

pub fn recover_cmd(a: &Args) -> Result<()> {
    let ffmpeg = record_mux::locate::find_ffmpeg()?;
    let reports = match a.get("session") {
        Some(dir) => recovery::recover(&ffmpeg, Path::new(dir))?.into_iter().collect(),
        None => recovery::recover_all(&ffmpeg, &a.get("out").map(PathBuf::from).unwrap_or_else(default_dir)),
    };
    if reports.is_empty() {
        println!("没有需要恢复的会话");
    }
    for r in reports {
        println!("{}：修复 {:?}，失败 {:?}，成品 {:?}，其他错误 {:?}", r.dir.display(), r.repaired, r.repair_errors, r.meeting, r.errors);
    }
    Ok(())
}

//! S2 压力与 CPU：真实编码器 + 独立进程里的动画测试窗口，分别计量采集进程与 ffmpeg 的 CPU。
//!
//! 为什么窗口要放在独立进程：动画窗口自己的绘制也吃 CPU，放在同一进程里会算进采集的账。
//! 编码输出写到 `NUL`：只要吞吐与 CPU，不在磁盘上留下任何画面内容（整块显示器都会被录进去）。

use crate::args::Args;
use crate::rec::parse_encoder;
use crate::s2::{parse_size, pick_from_args};
use anyhow::{Context, Result, bail};
use crossbeam_channel::unbounded;
use record_capture::cpu::{ProcCpu, logical_cpus, system_busy_total_ms};

use record_capture::video::{VideoConfig, VideoSource};
use record_core::ffmpeg_args::VideoSpec;

/// 只放一个动画测试窗口，不采集。`bench` 把它当子进程拉起。
pub fn window_cmd(a: &Args) -> Result<()> {
    ensure_dpi_aware();
    let secs: u64 = a.num("secs", 30)?;
    let (w, h) = parse_size(a.get("size").unwrap_or("960x540"))?;
    let list = list_monitors()?;
    let mon = pick_from_args(a, &list)?;
    if w > mon.width || h > mon.height {
        bail!("测试窗口 {w}×{h} 比显示器 {}×{} 还大", mon.width, mon.height);
    }
    let window = TestWindow::open(TestWindowSpec { left: mon.left + ((mon.width - w) / 2) as i32, top: mon.top + ((mon.height - h) / 2) as i32, width: w, height: h, animate: true }, Qpc::new())
        .map_err(anyhow::Error::msg)
        .context("创建测试窗口")?;
    std::thread::sleep(Duration::from_secs(secs));
    window.close();
    Ok(())
}

/// 两次读数之间某个进程占用的 CPU 毫秒。
struct Meter<'a> {
    cpu: &'a ProcCpu,
    start_ms: u64,
}

impl<'a> Meter<'a> {
    fn start(cpu: &'a ProcCpu) -> Self {
        Self { cpu, start_ms: cpu.total_ms().unwrap_or(0) }
    }

    fn used_ms(&self) -> u64 {
        self.cpu.total_ms().unwrap_or(0).saturating_sub(self.start_ms)
    }
}

/// `used_ms` 毫秒 CPU 在 `wall` 内占一个核的百分之几。
fn pct_of_core(used_ms: u64, wall: Duration) -> f64 {
    used_ms as f64 / 10.0 / wall.as_secs_f64()
}

pub fn bench_cmd(a: &Args) -> Result<()> {
    ensure_dpi_aware();
    let secs: u64 = a.num("secs", 30)?;
    let fps: u32 = a.num("fps", 15)?;
    let report_every: u64 = a.num("report", 10)?;
    let limit_pct: f64 = a.num("limit", 5.0)?;
    let size_text = a.get("size").unwrap_or("960x540").to_string();
    let monitor_arg = a.get("monitor").unwrap_or("primary").to_string();
    let wanted = parse_encoder(a.get("encoder").unwrap_or("auto"))?;

    let list = list_monitors()?;
    let mon = pick_from_args(a, &list)?;
    let out = output_size(mon.width, mon.height, 1920, 1080);
    let ffmpeg = find_ffmpeg().context("找 ffmpeg")?;
    let encoder = resolve_encoder(&ffmpeg, wanted).context("选编码器")?;
    println!("显示器：{}", mon.describe());
    println!("输出：{}×{}，{} fps，编码器 {:?}，时长 {} 秒，{}", out.0, out.1, fps, encoder, secs, if a.flag("no-window") { "不放测试窗口（采集当前桌面）" } else { "测试窗口在独立进程里" });

    let mut window_proc = if a.flag("no-window") {
        None
    } else {
        let exe = std::env::current_exe().context("找自己的路径")?;
        let child = Command::new(exe)
            .args(["s2", "window", "--secs", &(secs + 8).to_string(), "--size", &size_text, "--monitor", &monitor_arg])
            .stdout(Stdio::null())
            .stderr(Stdio::null())
            .spawn()
            .context("拉起测试窗口进程")?;
        std::thread::sleep(Duration::from_millis(1500)); // 窗口出现、桌面稳定
        Some(child)
    };
    let window_cpu = window_proc.as_ref().and_then(|c| ProcCpu::open(c.id()));

    let writer = VideoWriter::spawn(&ffmpeg, &VideoSpec { width: out.0, height: out.1, fps, encoder }, Path::new("NUL"), fps as usize * 2).context("启动 ffmpeg")?;
    let ffmpeg_cpu = writer.process_id().and_then(ProcCpu::open).context("打开 ffmpeg 进程读 CPU 时间")?;
    let writer = Arc::new(writer);
    let me = ProcCpu::current();

    let (event_tx, event_rx) = unbounded();
    let started = Instant::now();
    let printer = std::thread::spawn(move || {
        for e in event_rx {
            println!("  [+{:.1}s] {e:?}", started.elapsed().as_secs_f64());
        }
    });
    let overflow = Arc::new(AtomicU64::new(0));
    let rejected = Arc::new(AtomicU64::new(0));
    let (w, ov, rj) = (Arc::clone(&writer), Arc::clone(&overflow), Arc::clone(&rejected));
    let qpc = Qpc::new();
    println!("\n── 运行（每 {report_every} 秒一行：已交付帧 / 新画面 / 采集进程与 ffmpeg 各占一个核的百分比）──");
    let source = VideoSource::start(
        VideoConfig { monitor: mon.clone(), fps, out_w: out.0, out_h: out.1, t0: qpc.now_hns(), rebuild_interval: Duration::from_secs(1) },
        qpc,
        event_tx,
        Box::new(move |index, data, _kind| match w.submit(index, data) {
            Pushed::Queued => {}
            Pushed::Overflow(n) => {
                ov.fetch_add(n, Ordering::Relaxed);
            }
            Pushed::WriterFailed => {
                rj.fetch_add(1, Ordering::Relaxed);
            }
        }),
    )
    .context("启动画面采集")?;

    // 从首帧稳定之后开始计量，把着色器编译、编码器启动这类一次性开销排除在外
    std::thread::sleep(Duration::from_secs(2));
    let (me_meter, ff_meter) = (Meter::start(&me), Meter::start(&ffmpeg_cpu));
    let win_meter = window_cpu.as_ref().map(Meter::start);
    let sys_start = system_busy_total_ms();
    let t_start = Instant::now();
    let live = Arc::clone(source.live());
    let frames_start = live.emitted_frames();
    let mut next_report = report_every;
    while t_start.elapsed().as_secs() < secs {
        std::thread::sleep(Duration::from_millis(250));
        let t = t_start.elapsed();
        if t.as_secs() >= next_report {
            next_report += report_every;
            println!(
                "  t={:>4}s  帧 {:>6}  新画面 {:>6}  采集进程 {:.1}%  ffmpeg {:.1}%  写入器 {:?}",
                t.as_secs(),
                live.emitted_frames() - frames_start,
                live.fresh_frames(),
                pct_of_core(me_meter.used_ms(), t),
                pct_of_core(ff_meter.used_ms(), t),
                writer.health()
            );
        }
    }
    let wall = t_start.elapsed();
    let (me_ms, ff_ms) = (me_meter.used_ms(), ff_meter.used_ms());
    let win_ms = win_meter.as_ref().map(Meter::used_ms);
    let sys_end = system_busy_total_ms();
    let frames_in_window = live.emitted_frames() - frames_start;

    let result = source.stop();
    printer.join().expect("事件打印线程");
    if let Some(c) = window_proc.as_mut() {
        let _ = c.kill();
        let _ = c.wait();
    }
    let report = Arc::try_unwrap(writer).map_err(|_| anyhow::anyhow!("写入器仍被引用")).context("收回写入器")?.finish(Duration::from_secs(20));

    let cpus = logical_cpus();
    let (me_core, ff_core) = (pct_of_core(me_ms, wall), pct_of_core(ff_ms, wall));
    let total_core = me_core + ff_core;
    let total_machine = total_core / cpus as f64;
    println!("\n── 帧 ──");
    let st = &result.stats;
    println!(
        "计量窗口 {:.1} 秒内交付 {frames_in_window} 帧（期望约 {:.0}）；全程新画面 {}，无变化重复 {}，安全桌面 {}，重建中 {}，落后补帧 {}",
        wall.as_secs_f64(),
        wall.as_secs_f64() * f64::from(fps),
        st.fresh,
        st.repeat_no_change,
        st.repeat_secure_desktop,
        st.repeat_duplication_rebuild,
        st.catch_up
    );
    println!(
        "桌面格式 {}；首帧 {} ms；失效 {} 次；重建 {} 次；断开累计 {} ms；取帧耗时 p50 {:.1} ms，p95 {:.1} ms，p99 {:.1} ms，最大 {:.1} ms",
        result.src_format.map_or("未知".into(), |f| f.to_string()),
        result.first_frame_ms.map_or("无".into(), |v| v.to_string()),
        result.lost,
        result.rebuilds,
        result.down_ms,
        f64::from(result.grab.p50_us) / 1000.0,
        f64::from(result.grab.p95_us) / 1000.0,
        f64::from(result.grab.p99_us) / 1000.0,
        f64::from(result.grab.max_us) / 1000.0
    );
    println!("\n── 写入器 ──");
    println!(
        "ffmpeg 退出码 {:?}；强杀 {}；失败 {:?}；写入 {:.1} MB（{} 帧）；队列溢出丢帧 {}；写入器拒收 {}；序号空缺重复 {}；迟到丢弃 {}",
        report.exit_code,
        report.killed,
        report.failed,
        report.bytes_written as f64 / 1e6,
        report.bytes_written / (out.0 as u64 * out.1 as u64 * 3 / 2),
        overflow.load(Ordering::Relaxed),
        rejected.load(Ordering::Relaxed),
        report.gap_repeats,
        report.late_discarded
    );
    if !report.stderr_tail.trim().is_empty() {
        println!("ffmpeg 输出的末尾：{}", report.stderr_tail.trim());
    }

    println!("\n── CPU（{} 个逻辑处理器，计量窗口 {:.1} 秒）──", cpus, wall.as_secs_f64());
    println!("  采集进程（捕获 + GPU 转换 + 回读 + 写管道）  {me_core:.2}% 个核");
    println!("  ffmpeg（{encoder:?} 编码）                    {ff_core:.2}% 个核");
    println!("  合计                                          {total_core:.2}% 个核 = 整机 {total_machine:.2}%");
    if let Some(ms) = win_ms {
        println!("  （测试窗口进程的绘制，不计入）                {:.2}% 个核", pct_of_core(ms, wall));
    }
    if let (Some((b0, t0)), Some((b1, t1))) = (sys_start, sys_end)
        && t1 > t0
    {
        println!("  （整机 CPU 使用率，含所有程序，仅供参考）      {:.1}%", (b1 - b0) as f64 * 100.0 / (t1 - t0) as f64);
    }

    let mut problems: Vec<String> = Vec::new();
    if total_machine >= limit_pct {
        problems.push(format!("整机占用 {total_machine:.2}% 超过上限 {limit_pct}%"));
    }
    if report.exit_code != Some(0) || report.killed || report.failed.is_some() {
        problems.push("ffmpeg 没有正常结束".into());
    }
    if overflow.load(Ordering::Relaxed) > 0 || rejected.load(Ordering::Relaxed) > 0 {
        problems.push("写入器有丢帧".into());
    }
    if (frames_in_window as f64) < wall.as_secs_f64() * f64::from(fps) * 0.95 {
        problems.push(format!("计量窗口内只交付了 {frames_in_window} 帧"));
    }
    if result.lost > 0 || result.down_ms > 0 {
        problems.push(format!("管线断开过：失效 {} 次，累计 {} ms", result.lost, result.down_ms));
    }
    if problems.is_empty() {
        println!("\n压力测试通过（整机占用 {total_machine:.2}% < {limit_pct}%）。");
        Ok(())
    } else {
        for p in &problems {
            println!("✘ {p}");
        }
        bail!("压力测试未通过（{} 项）", problems.len())
    }
}

//! S3 同步 spike 的命令：闪屏加测试音的刺激，以及从录好的成品里测量画面与声音的偏移。
//!
//! 用法：先 `s3 stimulus` 在屏幕中央闪白（同时在默认播放设备上响一声 1 kHz 的短音），同时用录制引擎录；
//! 再对录出来的 `meeting.mp4` 跑 `s3 analyze`。刺激只在屏幕中央占一块区域，分析只看这块区域的平均亮度，
//! 不会去读用户屏幕上的其它内容。
//!
//! 声音写进播放设备后要过一段延迟才会出声（本机实测约 0.6 秒），回环采集给它打的是出声时刻；
//! 所以闪屏要等到测试音“出声”的那一刻才亮（时刻由播放流的设备位置推算），否则刺激自己就带着这段延迟。

use crate::args::Args;
use crate::s2::pick_from_args;
use anyhow::{Context, Result, bail};
use record_capture::devices::Role;
use record_capture::flashwin::FlashWindow;
use record_capture::monitor::{ensure_dpi_aware, list_monitors};
use record_capture::qpc::Qpc;
use record_capture::render::{PlayClock, RenderPlayer};
use record_core::syncprobe::{ToneLevels, estimate, flash_onsets, keep_consistent, pair_flashes, within};
use record_mux::locate::{ffprobe_for, find_ffmpeg};
use std::path::Path;
use std::process::Command;
use std::sync::Arc;
use std::sync::atomic::{AtomicU32, AtomicU64, Ordering};
use std::time::{Duration, Instant};

const BEEP_RATE: u32 = 48_000;
/// 测试音长度与闪屏亮着的时间。
const BEEP_SECS: f64 = 0.15;
const FLASH_SECS: f64 = 0.3;
const NOT_YET: u64 = u64::MAX;

/// 睡到 QPC 时刻 `target`（100 ns）：大部分时间睡眠，最后 2 毫秒自旋，减少 Windows 默认定时器的抖动。
fn sleep_until_hns(qpc: &Qpc, target: i64) {
    loop {
        let left = target - qpc.now_hns();
        if left <= 0 {
            return;
        }
        if left > 20_000 {
            std::thread::sleep(Duration::from_nanos((left - 20_000) as u64 * 100));
        } else {
            std::hint::spin_loop();
        }
    }
}

/// 等渲染线程把测试音写进缓冲区，返回测试音第一帧的序号。
fn wait_for_beep(frame: &AtomicU64) -> Option<u64> {
    let until = Instant::now() + Duration::from_secs(1);
    while Instant::now() < until {
        let f = frame.load(Ordering::Acquire);
        if f != NOT_YET {
            return Some(f);
        }
        std::thread::sleep(Duration::from_millis(1));
    }
    None
}

pub fn stimulus_cmd(a: &Args) -> Result<()> {
    ensure_dpi_aware();
    let secs: f64 = a.num("secs", 60.0)?;
    // 默认间隔 2 + 1/120 秒：与 15 帧/秒的帧周期错开，让闪屏的相位均匀扫过帧格（分析时才能修正半帧的量化误差）
    let interval: f64 = a.num("interval", 2.0 + 1.0 / 120.0)?;
    let lead: f64 = a.num("lead", 3.0)?;
    let freq: f64 = a.num("freq", 1000.0)?;
    // 诊断用：测试音一写进缓冲区就闪屏（不等它出声），此时测出来的偏移就是播放设备的延迟
    let naive = a.flag("naive");
    if interval < FLASH_SECS + 0.5 + 0.7 {
        bail!("--interval 太短：至少要比闪屏时间 {FLASH_SECS} 秒多 1.2 秒（出声延迟可达 0.6 秒以上）");
    }
    let list = list_monitors()?;
    let mon = pick_from_args(a, &list)?;
    // 占显示器宽高的一半，居中：分析取中央 30%，确保落在窗口内
    let (w, h) = ((mon.width / 2) & !1, (mon.height / 2) & !1);
    let window = FlashWindow::open(mon.left + ((mon.width - w) / 2) as i32, mon.top + ((mon.height - h) / 2) as i32, w, h).map_err(anyhow::Error::msg).context("创建闪屏窗口")?;

    // 测试音：主线程要求播放时置位，渲染线程在下一次填充缓冲区时从头播一声，并记下它第一帧的序号
    let request = Arc::new(AtomicU32::new(0));
    let beep_frame = Arc::new(AtomicU64::new(NOT_YET));
    let clock = Arc::new(PlayClock::new(BEEP_RATE));
    let beep_frames = (BEEP_SECS * f64::from(BEEP_RATE)) as u32;
    let fade = (0.002 * f64::from(BEEP_RATE)) as u32;
    let (req, first, gen_clock) = (Arc::clone(&request), Arc::clone(&beep_frame), Arc::clone(&clock));
    let (mut left, mut done) = (0u32, 0u32);
    let player = RenderPlayer::start_clocked(a.get("device").map(String::from), Role::Console, BEEP_RATE, 2, Arc::clone(&clock), move |buf| {
        let r = req.swap(0, Ordering::AcqRel);
        if r > 0 {
            (left, done) = (r, 0);
            first.store(gen_clock.written(), Ordering::Release);
        }
        for frame in buf.chunks_exact_mut(2) {
            if left == 0 {
                break;
            }
            let ramp = (done as f32 / fade as f32).min(1.0);
            let v = ramp * 0.15 * (2.0 * std::f64::consts::PI * freq * f64::from(done) / f64::from(BEEP_RATE)).sin() as f32;
            frame.fill(v);
            left -= 1;
            done += 1;
        }
    })
    .map_err(anyhow::Error::msg)
    .context("在播放设备上播放测试音")?;

    let qpc = Qpc::new();
    println!("刺激开始：{secs} 秒，每 {interval:.4} 秒响一声 {freq} Hz 的短音，并在它出声的那一刻闪白（第一次约在 {lead} 秒后）{}", if naive { "【--naive：写入即闪】" } else { "" });
    let begin = Instant::now();
    let mut count = 0;
    loop {
        let at = lead + f64::from(count) * interval;
        if at + FLASH_SECS + 1.2 > secs {
            break;
        }
        let ask_at = begin + Duration::from_secs_f64(at);
        while Instant::now() < ask_at {
            std::thread::sleep(Duration::from_millis(1));
        }
        beep_frame.store(NOT_YET, Ordering::Release);
        let asked = qpc.now_hns();
        request.store(beep_frames, Ordering::Release);
        let frame = wait_for_beep(&beep_frame).context("渲染线程没有取走测试音")?;
        let heard = clock.heard_at(frame).context("还没有读到播放设备的位置")?;
        let flash_at = if naive { qpc.now_hns() } else { heard };
        sleep_until_hns(&qpc, flash_at);
        window.set(true);
        println!("[{:7.3}] 第 {} 次：写入后 {:.0} ms 出声，闪白", begin.elapsed().as_secs_f64(), count + 1, (heard - asked) as f64 / 10_000.0);
        sleep_until_hns(&qpc, flash_at + (FLASH_SECS * 1e7) as i64);
        window.set(false);
        count += 1;
    }
    let end = begin + Duration::from_secs_f64(secs);
    while Instant::now() < end {
        std::thread::sleep(Duration::from_millis(5));
    }
    window.close();
    player.stop();
    println!("刺激结束，共 {count} 次");
    Ok(())
}

/// ffprobe 取视频流的帧率与起点，以及音频流的起点。
fn probe_streams(ffprobe: &Path, file: &Path) -> Result<(f64, f64, f64)> {
    let run = |stream: &str, entries: &str| -> Result<String> {
        let out = Command::new(ffprobe).args(["-v", "error", "-select_streams", stream, "-show_entries", entries, "-of", "default=nw=1"]).arg(file).output().context("启动 ffprobe")?;
        if !out.status.success() {
            bail!("ffprobe 失败：{}", String::from_utf8_lossy(&out.stderr));
        }
        Ok(String::from_utf8_lossy(&out.stdout).into_owned())
    };
    let field = |text: &str, key: &str| -> Option<String> { text.lines().find_map(|l| l.strip_prefix(key)?.strip_prefix('=')).map(|v| v.trim().to_string()) };
    let v = run("v:0", "stream=r_frame_rate,start_time")?;
    let fps = {
        let r = field(&v, "r_frame_rate").context("没有 r_frame_rate")?;
        let (n, d) = r.split_once('/').context("r_frame_rate 格式不对")?;
        n.parse::<f64>()? / d.parse::<f64>()?
    };
    let vstart = field(&v, "start_time").context("画面流没有 start_time")?.parse()?;
    let astart = field(&run("a:0", "stream=start_time")?, "start_time").context("音频流没有 start_time")?.parse()?;
    Ok((fps, vstart, astart))
}

/// 感兴趣区域：占整幅画面的比例 `x,y,w,h`。
fn parse_roi(text: &str) -> Result<[f64; 4]> {
    let v: Vec<f64> = text.split(',').map(|p| p.trim().parse::<f64>()).collect::<Result<_, _>>().with_context(|| format!("--roi 的值“{text}”应形如 0.35,0.35,0.3,0.3"))?;
    let [x, y, w, h]: [f64; 4] = v.try_into().map_err(|_| anyhow::anyhow!("--roi 要 4 个数：x,y,w,h"))?;
    if !(w > 0.0 && h > 0.0 && x >= 0.0 && y >= 0.0 && x + w <= 1.0 && y + h <= 1.0) {
        bail!("--roi 必须落在画面内：x,y 不小于 0，x+w、y+h 不大于 1");
    }
    Ok([x, y, w, h])
}

pub fn analyze_cmd(a: &Args) -> Result<()> {
    let file = a.pos.get(2).map(Path::new).context("用法：s3 analyze <meeting.mp4> [--roi 0.35,0.35,0.3,0.3] [--freq 1000] [--limit-ms 80] [--search 1.0] [--verbose]")?;
    let [rx, ry, rw, rh] = parse_roi(a.get("roi").unwrap_or("0.35,0.35,0.3,0.3"))?;
    let freq: f64 = a.num("freq", 1000.0)?;
    let limit_ms: f64 = a.num("limit-ms", 80.0)?;
    // 在每个闪屏前后各这么多秒里找测试音：要小于刺激间隔的一半，免得配到邻居
    let search: f64 = a.num("search", 1.0)?;
    let ffmpeg = find_ffmpeg()?;
    let (fps, vstart, astart) = probe_streams(&ffprobe_for(&ffmpeg), file)?;

    // 画面：只取中央区域的平均亮度，一帧一个字节
    let crop = format!("crop=iw*{rw}:ih*{rh}:iw*{rx}:ih*{ry},scale=1:1:flags=area,format=gray");
    let vout = Command::new(&ffmpeg).args(["-v", "error", "-i"]).arg(file).args(["-an", "-vf", &crop, "-f", "rawvideo", "-"]).output().context("启动 ffmpeg 取画面亮度")?;
    if !vout.status.success() {
        bail!("取画面亮度失败：{}", String::from_utf8_lossy(&vout.stderr));
    }
    // 声音：单声道 48 kHz 浮点
    let aout = Command::new(&ffmpeg).args(["-v", "error", "-i"]).arg(file).args(["-vn", "-ac", "1", "-ar", "48000", "-f", "f32le", "-"]).output().context("启动 ffmpeg 解码声音")?;
    if !aout.status.success() {
        bail!("解码声音失败：{}", String::from_utf8_lossy(&aout.stderr));
    }
    let samples: Vec<f32> = aout.stdout.chunks_exact(4).map(|b| f32::from_le_bytes([b[0], b[1], b[2], b[3]])).collect();

    let video = flash_onsets(&vout.stdout, fps, vstart);
    let tone = ToneLevels::new(&samples, 48_000, freq, astart);
    println!("画面：{} 帧，{fps} 帧/秒，起点 {vstart:.3} 秒；找到 {} 次闪屏", vout.stdout.len(), video.len());
    println!("声音：{:.1} 秒，起点 {astart:.3} 秒；在 {freq} Hz 处全程共 {} 次起音", samples.len() as f64 / 48_000.0, tone.onsets().len());
    let found = pair_flashes(&tone, &video, search);
    let (pairs, dropped) = keep_consistent(&found, 2.0 / fps);
    if a.flag("verbose") {
        println!("闪屏时刻（秒）：{}", video.iter().map(|t| format!("{t:.3}")).collect::<Vec<_>>().join(" "));
        println!("配上的对（画面−声音，ms）：{}", found.iter().map(|p| format!("{:.3}→{:.3}({:+.0})", p.video, p.audio, p.delta() * 1000.0)).collect::<Vec<_>>().join("  "));
    }
    if pairs.len() < 6 {
        bail!("只配上 {} 对（至少需要 6 对才能估计；配上 {} 对，去掉不一致的 {dropped} 对）。检查刺激是否在录制期间运行、系统音是否录到了测试音、闪屏是否在画面中央", pairs.len(), found.len());
    }
    println!("  序号  闪屏(秒)  测试音(秒)  画面−声音(ms)");
    for (i, p) in pairs.iter().enumerate() {
        println!("  {:>3}  {:>8.3}  {:>9.3}  {:>+10.1}", i + 1, p.video, p.audio, p.delta() * 1000.0);
    }
    let e = estimate(&pairs, fps).context("没有配对")?;
    println!(
        "配对 {} 对（另有 {dropped} 对与中位数相差超过两帧，已去掉）；平均差 {:+.1} ms；修正半帧（{:.1} ms）后的偏移 {:+.1} ms（±{:.1} ms）；差值范围 {:.1} ms（相位扫满时应接近一帧 {:.1} ms）",
        e.n,
        e.raw_mean * 1000.0,
        500.0 / fps,
        e.offset * 1000.0,
        e.uncertainty * 1000.0,
        e.spread * 1000.0,
        1000.0 / fps
    );
    println!("说明：负数表示画面比声音先到。声音按出声时刻放置，画面按屏幕上出现的时刻放置；闪屏窗口自己从绘制到被桌面复制抓到还有几毫秒。");
    if dropped * 4 > found.len() {
        bail!("结论：不可信（{} 对里有 {dropped} 对与其它的不一致，声音环境里有别的 {freq} Hz 声音，请在安静时重测）", found.len());
    }
    if within(&e, limit_ms / 1000.0) {
        println!("结论：通过（|偏移| + 两倍不确定度 ≤ {limit_ms} ms）");
        Ok(())
    } else {
        bail!("结论：未通过（偏移 {:+.1} ms，限值 {limit_ms} ms）", e.offset * 1000.0)
    }
}

## 任务 21：S3 音画同步：闪屏加测试音

**目标：** 设计文档 §10.1 的 S3 第一项：用“闪屏 + 蜂鸣”合成信号录一段，从成品里测出画面与声音的偏差，要求 ≤ 80 ms。`s3 stimulus` 在屏幕中央闪白、同时在播放设备上响一声 1 kHz 的短音；`record` 同时录；`s3 analyze` 从 `meeting.mp4` 里找闪屏与测试音、配对、估计偏移。分析只看画面中央一块区域的平均亮度和 1 kHz 的电平，不读你屏幕上的其他内容。

**刺激怎么对时。** 声音写进播放设备后要过一段延迟才会真的出声：有线 / HDMI 端点约几十毫秒，蓝牙耳机此前约 0.58 秒。回环采集给声音打的时间戳是“出声时刻”，所以刺激让闪屏等到测试音出声的那一刻才亮（时刻由播放流的设备位置推算）；这样测出来的偏移，衡量的是录制器的时间线（声音按回环时间戳放置、画面按屏幕上出现的时刻放置）与“播放流位置”这个参照是否一致。**前提是端点自己的两个时间来源（播放流位置、回环时间戳）对“出声时刻”的说法一致**：有线 / HDMI 端点上成立；本机的蓝牙端点在 2026-10-14 傍晚起不成立（播放流位置说写入后约 44 ms 出声，回环时间戳却比到达晚约 260 ms），见本任务末尾。`--naive` 把闪屏改成“写入即闪”，测出来的就是播放设备的延迟，作为诊断。

```powershell

Remove-Item $out -Recurse -Force -ErrorAction SilentlyContinue

Start-Sleep -Seconds 12
Stop-Process -Id $p.Id -Force

"强杀后留下：" + ((Get-ChildItem $out -Recurse -File -Force | ForEach-Object Name) -join "、")

```

预期：强杀后目录里有 `.recording`（会话锁）、`session.json`、`video.mkv`、`system.mka`，没有 `meeting.mp4`；`recover` 打印一行：`……：修复 ["video.mkv", "system.mka"]，失败 []，成品 Some("……\\meeting.mp4")，其他错误 []`。

- [ ] **步骤 7：核对修复结果**

```powershell
$out = "$env:TEMP\record-crash"
$s = Get-ChildItem $out -Directory | Select-Object -First 1
$m = Get-Content -Raw -Encoding UTF8 (Join-Path $s.FullName 'session.json') | ConvertFrom-Json
if ($m.state -ne 'recovered') { throw "state 应为 recovered，实际是 $($m.state)" }
foreach ($f in 'video.mkv', 'system.mka', 'meeting.mp4') {
  $d = [double](.\vendor\ffmpeg\bin\ffprobe.exe -v error -show_entries format=duration -of csv=p=0 (Join-Path $s.FullName $f))
  if ($d -lt 8 -or $d -gt 14) { throw "$f 的时长 $d 秒，不在 8～14 秒之间" }
  "$f 时长 $d 秒"
}
if (Test-Path (Join-Path $s.FullName '.recording')) { throw "会话锁没有清掉" }
"状态 $($m.state)，会话锁已清除"
```

预期：三个文件的时长都在 8～14 秒之间（强杀前约 12 秒；修复只会丢失最后约 1 秒），`session.json` 的 `state` 是 `recovered`，`.recording` 已被清除。
