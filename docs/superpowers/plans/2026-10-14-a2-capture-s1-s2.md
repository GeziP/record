## 全局约束

以下条目来自设计文档 `docs/superpowers/specs/2026-10-13-meeting-recorder-design.md`，数值与措辞不要擅自改动；与它冲突时以设计文档为准，并先回头改文档。

- **平台与工具链**：Windows 11 x64（开发机为 Windows 11 build 26200）；v1 不做其他平台。Rust 1.95 以上、edition 2024；Tauri v2；前端 TypeScript + Vite + React（§2、§12）。
- **统一时钟**：所有数据用 QPC（`QueryPerformanceCounter`）打时间戳，换算为 **100 ns** 单位。`t0_session` = 热键按下时的 QPC；每轨 `t0_stream` = 该轨第一份数据的 QPC；收尾时每轨偏移 = `t0_stream` − 所有轨 `t0_stream` 的最小值（§5.1）。
- **只存原始音频**：采集阶段不降噪、不做回声消除、不做自动增益（§5.1）。
- **画面**：Desktop Duplication；恒定 **15 fps**（可设 10 / 15 / 30）；输出长边 ≤ 1920、短边 ≤ 1080，保持宽高比，宽高取偶数；缩放与 BGRA → NV12 在 GPU 上做；中途显示模式变化时按比例缩放加黑边，输出尺寸不变（§5.2）。
- **声音**：系统音走 WASAPI 回环，麦克风走 WASAPI 采集；都是 **48 kHz / float32**，系统音立体声，麦克风下混为单声道；事件驱动共享模式；采集线程是普通线程 + 事件句柄 + MMCSS（任务名 `Audio`），不用 RTWQ（§5.3、§5.4、§6.6）。
- **落盘**：每轨一个 ffmpeg 子进程，stdin 喂原始数据；`video.mkv`（H.264，无声）、`mic.mka`（FLAC）、`system.mka`（FLAC）；ffmpeg 用 LGPL 构建，开发时放在 `vendor/ffmpeg/`，不入库（§5.6）。
- **编码器**：启动时按 NVENC → QSV → AMF 探测；都没有就明确报错；软件编码只能由用户显式选择，**不悄悄降级**（§5.2、§9）。
- **时间线修复**：补静音阈值初值 40 ms、带滞回；回环空闲时每 10 ms 检查一次并补静音；单次补静音超过 5 秒记 `large_gap` 并告警；音频绝不丢，视频队列满时丢最旧帧（§5.5、§5.9）。
- **成品**：`meeting.mp4` = 画面直接拷贝 + 两轨按偏移对齐后等增益相加并限幅、编码为 AAC（1 路画面 + 1 路混音）；三轨文件在保存后几秒内即可用，`meeting.mp4` 稍后生成（§5.7）。
- **崩溃恢复**：启动时扫描 `state=recording` 的会话，对每个 MKV / MKA 做拷贝式修复，`state=recovered`，补做 `meeting.mp4`，通知用户；`state=finalized` 但缺 `meeting.mp4` 的会话补做收尾（§5.8）。
- **不静默失败**：回环“通但全是静音”、设备挂起、补静音过长、持续低帧率都要探测；告警动作是托盘变琥珀、写日志、弹提示、`session.json` 计数加一；**不自动切换采集方案**（§5.10、§9）。
- **状态机与热键**：待命 → 启动中 → 录制中 → 收尾中 → 待命；所有命令进入同一个控制器串行处理，500 ms 内的重复触发被忽略；热键默认 `Ctrl+Alt+R`（开始）、`Ctrl+Alt+S`（保存并结束本场）、`Ctrl+Alt+Q`（保存并退出程序），均可改、均幂等；三个热键常驻注册（§6.1、§6.2）。
- **静默程度**：安静模式为默认——没有弹窗和提示音，只有托盘图标变化（灰 = 待命、红点 = 录制中、琥珀 = 告警）；标准模式另加开始 / 保存的气泡；出错一定弹提示；**不提供“完全隐形”模式**（§6.3）。
- **自动保护**：单场上限 6 小时、磁盘剩余空间低于 5 GB 时自动保存并结束；睡眠 = 先保存，唤醒后提示“因睡眠已保存”；关机、注销先保存再退出（§6.5）。
- **位置**：配置 `%APPDATA%\record\config.toml`；日志 `%LOCALAPPDATA%\record\logs\`（按天滚动）；保存目录默认 `<视频库>\Record`（§4.3、§4.4）。
- **公开仓库与合规**：不提交密钥、录音录像、转写稿、模型文件和研究产物；测试产物只放 `%TEMP%\record-*` 并在结束时删除；验证画面与声音靠合成信号和统计量，不去看、不去听用户的真实录制；对第三方软件不拷贝代码（OBS GPLv2、Cap AGPLv3、Sokuji AGPL-3.0、Screenpipe 源码可见许可的项目只借鉴思路）；录制需取得与会者同意（§14）。
- **工程约定**：每个任务先写失败的测试、再实现；`rustfmt.toml` 与 `clippy -D warnings` 是质量门；提交信息用 `类型(范围): 中文说明`；不改系统环境变量。

## 任务 2：record-capture：com

**目标：** 线程级 COM 初始化：每个用到 WASAPI 的线程先建一个 [`ComGuard`]，线程结束时自动反初始化；进程里另外留着一个永远不退出的多线程单元成员线程。

**为什么 `ComGuard` 之外还要一个守护线程：** 这是在外壳验收（计划 A4）里实测踩到的。最后一个 MTA 线程反初始化时，COM 会拆掉整个多线程单元，并卸载没有人在用的组件 DLL；而 `windows` 库把 WinRT 的激活工厂缓存在静态变量里（外壳弹系统通知用的 `XmlDocument`），DLL 被卸载之后再用缓存的工厂就是访问违例。每场录制结束时采集线程全部退出，正好触发这件事：标准模式下，第二场开始弹“开始录制”通知时进程直接崩溃（退出码 0xC0000005，崩溃位置在 `XmlDocument` 的激活函数里）。

测试 `the_mta_outlives_the_last_guard` 把这个不变量钉住：最后一个守卫释放之后，一个没有初始化过 COM 的新线程仍然落在 MTA 里。把 `ComGuard::init` 里的 `keep_mta_alive()` 去掉，它就会失败。

//! 线程级 COM 初始化：每个用到 WASAPI 的线程先建一个 [`ComGuard`]，线程结束时自动反初始化；进程里另外留着一个永远不退出的多线程单元成员线程。

use std::sync::Once;
use windows::Win32::System::Com::{COINIT_MULTITHREADED, CoInitializeEx, CoUninitialize};

static KEEPER: Once = Once::new();

/// 启动一个永远不退出、留在多线程单元（MTA）里的线程（只做一次）；[`ComGuard::init`] 会自动调用它，外壳启动时也要先调用一次。
///
/// 为什么需要：最后一个 MTA 成员线程反初始化时，COM 会拆掉整个多线程单元，并卸载没有人在用的组件 DLL；
/// 而 `windows` 库把 WinRT 的激活工厂缓存在静态变量里（外壳弹系统通知要用 `XmlDocument`），
/// DLL 被卸载之后下一次用缓存的工厂就是访问违例。每场录制结束时采集线程全部退出，正好触发这件事：
/// 标准模式下第二场开始时弹“开始录制”通知，外壳进程直接崩溃（退出码 0xC0000005，崩溃位置在 `XmlDocument` 的激活函数里）。
pub fn keep_mta_alive() {
    KEEPER.call_once(|| {
        let (ready, wait) = std::sync::mpsc::channel();
        std::thread::Builder::new()
            .name("com-mta".into())
            .spawn(move || {
                let ok = unsafe { CoInitializeEx(None, COINIT_MULTITHREADED).is_ok() };
                let _ = ready.send(ok);
                loop {
                    std::thread::park();
                }
            })
            .expect("启动 COM 单元守护线程");
        let _ = wait.recv();
    });
}

pub struct ComGuard(());

impl ComGuard {
    pub fn init() -> windows::core::Result<Self> {
        keep_mta_alive();
        // 重复初始化返回 S_FALSE，同样需要配对反初始化，所以只要不是失败码就算成功
        unsafe { CoInitializeEx(None, COINIT_MULTITHREADED).ok()? };
        Ok(Self(()))
    }
}

impl Drop for ComGuard {
    fn drop(&mut self) {
        unsafe { CoUninitialize() };
    }
}
```

    pub fn ticks_to_hns(&self, ticks: i64) -> Hns {
        self.clock.ticks_to_hns(ticks)
    }
}

    }

//! 进程 CPU 时间计量（设计文档 10 的 S2：整体 CPU 占用 < 5%）。
//!
//! 持有进程句柄，进程退出之后仍可读到累计时间，所以可以先停止、再读数。

use windows::Win32::Foundation::{CloseHandle, FILETIME, HANDLE};
use windows::Win32::System::Threading::{GetCurrentProcess, GetProcessTimes, GetSystemTimes, OpenProcess, PROCESS_QUERY_LIMITED_INFORMATION};

pub struct ProcCpu {
    handle: HANDLE,
    owned: bool,
}

fn filetime_ms(t: FILETIME) -> u64 {
    // 单位是 100 ns
    (u64::from(t.dwHighDateTime) << 32 | u64::from(t.dwLowDateTime)) / 10_000
}

impl ProcCpu {
    /// 当前进程。
    pub fn current() -> Self {
        Self { handle: unsafe { GetCurrentProcess() }, owned: false }
    }

    pub fn open(pid: u32) -> Option<Self> {
        let handle = unsafe { OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, false, pid) }.ok()?;
        Some(Self { handle, owned: true })
    }

    /// 累计 `(内核态毫秒, 用户态毫秒)`。
    pub fn times_ms(&self) -> Option<(u64, u64)> {
        let (mut create, mut exit, mut kernel, mut user) = (FILETIME::default(), FILETIME::default(), FILETIME::default(), FILETIME::default());
        unsafe { GetProcessTimes(self.handle, &mut create, &mut exit, &mut kernel, &mut user) }.ok()?;
        Some((filetime_ms(kernel), filetime_ms(user)))
    }

    /// 累计 CPU 毫秒（内核 + 用户）。
    pub fn total_ms(&self) -> Option<u64> {
        self.times_ms().map(|(k, u)| k + u)
    }
}

impl Drop for ProcCpu {
    fn drop(&mut self) {
        if self.owned {
            let _ = unsafe { CloseHandle(self.handle) };
        }
    }
}

/// 逻辑处理器数，用来把“占几个核”换算成“占整机百分之几”。
pub fn logical_cpus() -> usize {
    std::thread::available_parallelism().map_or(1, usize::from)
}

/// 整机累计 `(忙碌毫秒, 总毫秒)`，总毫秒 = 全部逻辑处理器的墙钟时间之和。仅作背景参考：包含所有程序。
pub fn system_busy_total_ms() -> Option<(u64, u64)> {
    let (mut idle, mut kernel, mut user) = (FILETIME::default(), FILETIME::default(), FILETIME::default());
    unsafe { GetSystemTimes(Some(&mut idle), Some(&mut kernel), Some(&mut user)) }.ok()?;
    // 内核时间里包含空闲时间
    let total = filetime_ms(kernel) + filetime_ms(user);
    Some((total.saturating_sub(filetime_ms(idle)), total))
}
```

use crate::com::ComGuard;

        let p = PropVariantToStringAlloc(&v)?;
        let s = p.to_string().unwrap_or_default();
        CoTaskMemFree(Some(p.0 as *const _));
        Ok(s)
    }
}

    Ok(EndpointInfo { id: device_id(d)?, name: device_name(d).unwrap_or_else(|_| "（未知设备）".into()) })

/// 全部处于活动状态的端点。
pub fn active_endpoints(e: &IMMDeviceEnumerator, flow: Flow) -> Result<Vec<IMMDevice>> {
    unsafe {
        let col = e.EnumAudioEndpoints(flow.raw(), DEVICE_STATE_ACTIVE)?;
        let n = col.GetCount()?;
        (0..n).map(|i| col.Item(i)).collect()
    }
}

/// 设备的共享模式混音格式。
pub fn mix_format(d: &IMMDevice) -> Result<MixFormat> {
    unsafe {
        let client: IAudioClient = d.Activate(CLSCTX_ALL, None)?;
        let p = client.GetMixFormat()?;
        let f = &*p;
        // WAVE_FORMAT_IEEE_FLOAT = 3；扩展格式（0xFFFE）的子格式这里不展开，位深 32 视为浮点
        let float = f.wFormatTag == 3 || (f.wFormatTag == 0xFFFE && f.wBitsPerSample == 32);
        let m = MixFormat { rate: f.nSamplesPerSec, channels: f.nChannels, bits: f.wBitsPerSample, float };
        CoTaskMemFree(Some(p as *const _));
        Ok(m)
    }
}

/// 端点电平表的当前峰值（0.0–1.0），静默失效监测用（设计文档 5.10）。
pub struct Meter {

}

impl Meter {
    pub fn open(d: &IMMDevice) -> Result<Self> {
        let meter: IAudioMeterInformation = unsafe { d.Activate(CLSCTX_ALL, None)? };
        Ok(Self { meter })
    }

/// 所有活动播放设备电平表的最大峰值。取不到任何电平表时返回 `None`（不报告，也不猜）。
pub struct RenderMeters {
    meters: Vec<(String, Meter)>,
}

impl RenderMeters {
    pub fn open_all(e: &IMMDeviceEnumerator) -> Result<Self> {
        let mut meters = Vec::new();
        for d in active_endpoints(e, Flow::Render)? {
            if let (Ok(i), Ok(m)) = (info(&d), Meter::open(&d)) {
                meters.push((i.name, m));
            }
        }
        Ok(Self { meters })
    }

    pub fn max_peak(&self) -> Option<f32> {
        self.meters.iter().map(|(_, m)| m.peak()).fold(None, |acc, p| Some(acc.map_or(p, |a: f32| a.max(p))))

    /// 峰值最高的设备名，告警时指明哪个设备有声。
    pub fn loudest(&self) -> Option<(String, f32)> {
        self.meters.iter().map(|(n, m)| (n.clone(), m.peak())).max_by(|a, b| a.1.total_cmp(&b.1))
    }
}

pub fn list_active() -> std::result::Result<Vec<DeviceEntry>, String> {

        let _com = ComGuard::init()?;
        let e = enumerator()?;
        let mut out = Vec::new();
        for flow in [Flow::Render, Flow::Capture] {

    .map_err(|e| e.to_string())

use crate::devices::{self, Flow, Role};
use crossbeam_channel::bounded;
use std::sync::atomic::{AtomicBool, AtomicU64, Ordering};
use std::sync::{Arc, Mutex};

use windows::Win32::Foundation::{CloseHandle, HANDLE};
use windows::Win32::Media::Audio::{
    AUDCLNT_SHAREMODE_SHARED, AUDCLNT_STREAMFLAGS_AUTOCONVERTPCM, AUDCLNT_STREAMFLAGS_EVENTCALLBACK, AUDCLNT_STREAMFLAGS_SRC_DEFAULT_QUALITY, IAudioClient, IAudioClock, IAudioRenderClient,
    WAVEFORMATEX,
};
use windows::Win32::System::Com::CLSCTX_ALL;

pub fn float_format(rate: u32, channels: u16) -> WAVEFORMATEX {
    WAVEFORMATEX {
        wFormatTag: 3, // WAVE_FORMAT_IEEE_FLOAT
        nChannels: channels,
        nSamplesPerSec: rate,
        nAvgBytesPerSec: rate * u32::from(channels) * 4,
        nBlockAlign: channels * 4,
        wBitsPerSample: 32,
        cbSize: 0,
    }
}

/// 第 `frame` 帧（从 0 数起）出声的 QPC 时刻（100 ns）：设备位置 `position` 帧在 `position_qpc` 时刻正在出声，其余按采样率推算。
pub fn heard_hns(position: u64, position_qpc: i64, frame: u64, rate: u32) -> i64 {
    position_qpc + ((frame as f64 - position as f64) * 1e7 / f64::from(rate)).round() as i64
}

/// 渲染流的“出声时钟”：渲染线程每次醒来读一次设备位置，外部据此推算某个已交给引擎的帧什么时候从扬声器里出声。
/// 播放设备的缓冲与驱动延迟可以很大（本机实测约 0.6 秒），写进去的声音要这么久之后才听得到；
/// 回环采集给声音打的是出声时刻，所以做同步测试时，画面必须按这个时刻去闪，而不是按写入时刻。
pub struct PlayClock {
    rate: u32,
    written: AtomicU64,
    /// （设备位置对应的帧序号，读取该位置时的 QPC，单位 100 ns）
    position: Mutex<Option<(u64, i64)>>,
}

impl PlayClock {
    pub fn new(rate: u32) -> Self {
        Self { rate, written: AtomicU64::new(0), position: Mutex::new(None) }
    }

    /// 到目前为止交给引擎的帧数；在生成器里读到的就是这次要填的缓冲区第一帧的序号。
    pub fn written(&self) -> u64 {
        self.written.load(Ordering::Acquire)
    }

    /// 第 `frame` 帧出声的 QPC 时刻；还没读到过设备位置时返回 `None`。
    pub fn heard_at(&self, frame: u64) -> Option<i64> {
        let (position, qpc) = (*self.position.lock().ok()?)?;
        Some(heard_hns(position, qpc, frame, self.rate))
    }
}

/// 在指定的播放设备上持续播放。`generator` 每次要填满给定的交错 f32 缓冲区。
pub struct RenderPlayer {
    stop: Arc<AtomicBool>,
    thread: Option<JoinHandle<()>>,
}

impl RenderPlayer {
    /// 流成功启动后才返回；失败时返回原因。`role` 为 `None` 时用 `device_id` 指定的设备。
    pub fn start(device_id: Option<String>, role: Role, rate: u32, channels: u16, generator: impl FnMut(&mut [f32]) + Send + 'static) -> Result<Self, String> {
        Self::start_clocked(device_id, role, rate, channels, Arc::new(PlayClock::new(rate)), generator)
    }

    /// 同 [`start`](Self::start)，并把出声时钟交给调用方：生成器和主线程都可以读它。`clock` 必须用同一个 `rate` 创建。
    pub fn start_clocked(device_id: Option<String>, role: Role, rate: u32, channels: u16, clock: Arc<PlayClock>, generator: impl FnMut(&mut [f32]) + Send + 'static) -> Result<Self, String> {
        let stop = Arc::new(AtomicBool::new(false));
        let (ready_tx, ready_rx) = bounded::<Result<(), String>>(1);
        let stop2 = Arc::clone(&stop);
        let thread = thread::Builder::new()
            .name("render-player".into())
            .spawn(move || {
                let r = run(Target { device_id, role, rate, channels }, &clock, generator, &stop2, &ready_tx);
                if let Err(e) = r {
                    let _ = ready_tx.try_send(Err(e));
                }
            })
            .map_err(|e| e.to_string())?;
        match ready_rx.recv() {
            Ok(Ok(())) => Ok(Self { stop, thread: Some(thread) }),
            Ok(Err(e)) => {
                let _ = thread.join();
                Err(e)
            }
            Err(_) => Err("渲染线程在启动前退出".into()),
        }
    }

    pub fn stop(mut self) {
        self.shutdown();
    }

    fn shutdown(&mut self) {
        self.stop.store(true, Ordering::Release);
        if let Some(t) = self.thread.take() {
            let _ = t.join();
        }
    }
}

impl Drop for RenderPlayer {
    fn drop(&mut self) {
        self.shutdown();
    }
}

/// 渲染到哪个设备、什么格式。
struct Target {
    device_id: Option<String>,
    role: Role,
    rate: u32,
    channels: u16,
}

fn run(target: Target, clock: &PlayClock, mut generator: impl FnMut(&mut [f32]), stop: &AtomicBool, ready: &crossbeam_channel::Sender<Result<(), String>>) -> Result<(), String> {
    let Target { device_id, role, rate, channels } = target;
    let e = |what: &str| {
        let what = what.to_string();
        move |err: windows::core::Error| format!("{what}：{err}")
    };
    let _com = ComGuard::init().map_err(e("COM 初始化"))?;
    let en = devices::enumerator().map_err(e("创建设备枚举器"))?;
    let dev = match &device_id {
        Some(id) => devices::endpoint_by_id(&en, id),
        None => devices::default_endpoint(&en, Flow::Render, role),
    }
    .map_err(e("取播放设备"))?;
    unsafe {
        let client: IAudioClient = dev.Activate(CLSCTX_ALL, None).map_err(e("激活 IAudioClient"))?;
        let fmt = float_format(rate, channels);
        client
            .Initialize(AUDCLNT_SHAREMODE_SHARED, AUDCLNT_STREAMFLAGS_EVENTCALLBACK | AUDCLNT_STREAMFLAGS_AUTOCONVERTPCM | AUDCLNT_STREAMFLAGS_SRC_DEFAULT_QUALITY, 0, 0, &fmt, None)
            .map_err(e("初始化渲染流"))?;
        let event: HANDLE = CreateEventW(None, false, false, None).map_err(e("创建事件"))?;
        client.SetEventHandle(event).map_err(e("设置事件"))?;
        let buffer_frames = client.GetBufferSize().map_err(e("取缓冲大小"))?;
        let render: IAudioRenderClient = client.GetService().map_err(e("取渲染服务"))?;
        let ch = usize::from(channels);

        let mut fill = |frames: u32| -> Result<(), String> {
            let p = render.GetBuffer(frames).map_err(e("GetBuffer"))?;
            let slice = std::slice::from_raw_parts_mut(p as *mut f32, frames as usize * ch);
            slice.fill(0.0);
            generator(slice);
            render.ReleaseBuffer(frames, 0).map_err(e("ReleaseBuffer"))?;
            clock.written.fetch_add(u64::from(frames), Ordering::AcqRel);
            Ok(())
        };
        // 设备位置：按流的采样率换算成帧；每次醒来读一次，供 `PlayClock::heard_at` 外推
        let device_clock: IAudioClock = client.GetService().map_err(e("取时钟服务"))?;
        let device_freq = device_clock.GetFrequency().map_err(e("取时钟频率"))?.max(1);
        let read_position = || {
            let (mut position, mut qpc) = (0u64, 0u64);
            if device_clock.GetPosition(&mut position, Some(&mut qpc)).is_ok()
                && let Ok(mut slot) = clock.position.lock()
            {
                *slot = Some(((u128::from(position) * u128::from(rate) / u128::from(device_freq)) as u64, qpc as i64));
            }
        };
        fill(buffer_frames)?;
        client.Start().map_err(e("启动渲染流"))?;
        let _ = ready.try_send(Ok(()));
        while !stop.load(Ordering::Acquire) {
            WaitForSingleObject(event, 100);
            read_position();
            let padding = client.GetCurrentPadding().map_err(e("GetCurrentPadding"))?;
            let avail = buffer_frames.saturating_sub(padding);
            if avail > 0 {
                fill(avail)?;
            }
        }
        let _ = client.Stop();
        let _ = CloseHandle(event);
    }
    Ok(())
}

    frames_out: AtomicU64,

impl Live {
    /// 取走并清零自上次调用以来的峰值（0.0–1.0）。
    pub fn take_peak(&self) -> f32 {
        f32::from_bits(self.peak_bits.swap(0, Ordering::AcqRel))
    }

    pub fn frames_out(&self) -> u64 {
        self.frames_out.load(Ordering::Relaxed)
    }

    /// 最近一次收到数据包的时刻，没收到过为 0。
    pub fn last_packet_hns(&self) -> Hns {
        self.last_packet_hns.load(Ordering::Relaxed)
    }

    pub fn anchor_hns(&self) -> Hns {
        self.anchor_hns.load(Ordering::Acquire)
    }

    fn publish_peak(&self, p: f32) {
        // 非负 f32 的位模式与数值同序，可以直接取最大值
        self.peak_bits.fetch_max(p.to_bits(), Ordering::AcqRel);
    }

pub struct AudioSource {

/// 采集线程交付一块时间线上的音频（交错的 f32）时调用的回调。
pub type AudioSink = Box<dyn FnMut(&[f32]) + Send>;

impl AudioSource {
    /// 启动线程。`sink` 在采集线程上被调用，要尽快返回（只入队，不做 IO）。
    pub fn start(cfg: SourceConfig, qpc: Qpc, events: Sender<AudioEvent>, sink: AudioSink) -> std::io::Result<Self> {
        let stop = Arc::new(AtomicBool::new(false));
        let stop_at = Arc::new(AtomicI64::new(0));
        let live = Arc::new(Live::default());
        let (s, at, l) = (Arc::clone(&stop), Arc::clone(&stop_at), Arc::clone(&live));
        let thread = thread::Builder::new().name(format!("audio-{}", cfg.label)).spawn(move || run(cfg, qpc, events, sink, &s, &at, &l))?;
        Ok(Self { stop, stop_at, qpc, live, thread: Some(thread) })
    }

    /// 记下请求停止的时刻（只记第一次），再通知线程退出。不等线程结束；
    /// 多轨一起停时先对每一轨调用它，各轨的“停止时刻”才几乎相同，再逐个 `stop()` 收结果。
    pub fn request_stop(&self) {
        let _ = self.stop_at.compare_exchange(0, self.qpc.now_hns(), Ordering::AcqRel, Ordering::Acquire);
        self.stop.store(true, Ordering::Release);
    }

    pub fn live(&self) -> &Arc<Live> {
        &self.live
    }

    /// 停止采集：时间线补齐到停止时刻，返回统计。
    pub fn stop(mut self) -> SourceResult {
        self.request_stop();
        self.thread.take().map(|t| t.join().unwrap_or_default()).unwrap_or_default()
    }
}

impl Drop for AudioSource {
    fn drop(&mut self) {
        self.request_stop();
        if let Some(t) = self.thread.take() {
            let _ = t.join();
        }
    }
}

fn resolve(cfg: &SourceConfig) -> windows::core::Result<IMMDevice> {
    let en = devices::enumerator()?;
    match (&cfg.endpoint, cfg.kind) {
        (Endpoint::Default(role), Kind::Loopback) => devices::default_endpoint(&en, Flow::Render, *role),
        (Endpoint::Default(role), Kind::Mic) => devices::default_endpoint(&en, Flow::Capture, *role),
        (Endpoint::Id(id), _) => devices::endpoint_by_id(&en, id),
    }
}

fn open(cfg: &SourceConfig) -> Result<Stream, String> {
    let err = |what: &'static str| move |e: windows::core::Error| format!("{what}：{e}");
    let dev = resolve(cfg).map_err(err("取设备"))?;
    let info = devices::info(&dev).map_err(err("取设备信息"))?;
    let fmt = cfg.timeline.format;
    unsafe {
        let client: IAudioClient = dev.Activate(CLSCTX_ALL, None).map_err(err("激活 IAudioClient"))?;
        let wf = float_format(fmt.rate, fmt.channels);
        let mut flags = AUDCLNT_STREAMFLAGS_EVENTCALLBACK | AUDCLNT_STREAMFLAGS_AUTOCONVERTPCM | AUDCLNT_STREAMFLAGS_SRC_DEFAULT_QUALITY;
        if cfg.kind == Kind::Loopback {
            flags |= AUDCLNT_STREAMFLAGS_LOOPBACK;
        }
        // 200 ms 缓冲：事件驱动下由引擎周期决定唤醒间隔，这里只是上限
        client.Initialize(AUDCLNT_SHAREMODE_SHARED, flags, 2_000_000, 0, &wf, None).map_err(err("初始化音频流（自动格式转换）"))?;
        let event = CreateEventW(None, false, false, None).map_err(err("创建事件"))?;
        client.SetEventHandle(event).map_err(err("设置事件"))?;
        let capture: IAudioCaptureClient = client.GetService().map_err(err("取采集服务"))?;
        let keepalive = if cfg.kind == Kind::Loopback && cfg.keepalive {
            // 保活流必须与被采集的设备是同一个，否则无声时仍然不出包
            Some(RenderPlayer::start(Some(info.id.clone()), Role::Console, fmt.rate, 2, |_| {}).map_err(|e| format!("启动保活渲染流：{e}"))?)
        } else {
            None
        };
        client.Start().map_err(err("启动采集"))?;
        Ok(Stream { client, capture, event, info, channels: usize::from(fmt.channels), _keepalive: keepalive })
    }
}

fn run(cfg: SourceConfig, qpc: Qpc, events: Sender<AudioEvent>, mut sink: AudioSink, stop: &AtomicBool, stop_at: &AtomicI64, live: &Live) -> SourceResult {
    let _com = ComGuard::init().expect("COM 初始化");
    let _mmcss = Mmcss::enter();
    let label = cfg.label.clone();
    let channels = usize::from(cfg.timeline.format.channels);
    let anchor = qpc.now_hns();
    live.anchor_hns.store(anchor, Ordering::Release);
    let mut tl = AudioTimeline::new(cfg.timeline, anchor);
    let mut result = SourceResult { anchor, ..Default::default() };
    let mut emit = |s: &[f32]| {
        live.frames_out.fetch_add((s.len() / channels) as u64, Ordering::Relaxed);
        sink(s);
    };
    let mut down_since: Option<Hns> = None;
    let mut interrupted = false;
    let mut connected_once = false;

    while !stop.load(Ordering::Acquire) {
        let mut wait = cfg.reconnect_interval;
        match open(&cfg) {
            Ok(mut stream) => {
                if connected_once {
                    result.reconnects += 1;
                }
                connected_once = true;
                down_since = None;
                // 打开设备花的时间（或重连的空档）在这一刻补齐，之后的空闲/空档才有意义
                let started = tl.stream_started(qpc.now_hns(), &mut emit);
                notify_large_gap(&events, &cfg, &started);
                let _ = events.send(AudioEvent::Opened { label: label.clone(), device: stream.info.clone(), mix: None });
                if interrupted {
                    interrupted = false;
                    let _ = events.send(AudioEvent::Recovered { label: label.clone() });
                }
                match pump(&mut stream, &cfg, &qpc, &mut tl, &mut emit, stop, live, &events) {
                    StreamEnd::Stop => break,
                    StreamEnd::DeviceChanged { from, to } => {
                        result.device_changes += 1;
                        let _ = events.send(AudioEvent::DeviceChanged { label: label.clone(), from, to });
                        wait = Duration::ZERO; // 默认设备变了，立刻连新设备
                    }
                    StreamEnd::Lost(error) => {
                        let _ = events.send(AudioEvent::StreamLost { label: label.clone(), error });
                        down_since = Some(qpc.now_hns());
                    }
                }
            }
            Err(error) => {
                let _ = events.send(AudioEvent::OpenFailed { label: label.clone(), error });
                down_since.get_or_insert_with(|| qpc.now_hns());
            }
        }
        // 重连等待：期间照常由 QPC 推算补静音，时间线保持连续
        let until = qpc.now_hns() + wait.as_millis() as i64 * 10_000;
        while !stop.load(Ordering::Acquire) {
            let now = qpc.now_hns();
            if let Some(since) = down_since
                && !interrupted
                && now - since >= cfg.interrupted_after.as_millis() as i64 * 10_000
            {
                interrupted = true;
                let _ = events.send(AudioEvent::Interrupted { label: label.clone() });
            }
            let r = if down_since.is_some() { tl.tick_outage(now, &mut emit) } else { tl.tick(now, &mut emit) };
            notify_large_gap(&events, &cfg, &r);
            if now >= until {
                break;
            }
            thread::sleep(Duration::from_millis(10));
        }
    }
    // 补齐到“请求停止”的时刻；没有记录（线程自己结束）才用当前时刻
    let requested = stop_at.load(Ordering::Acquire);
    tl.finish(if requested > 0 { requested } else { qpc.now_hns() }, &mut emit);
    result.stats = tl.stats().clone();
    result
}

/// 单次补静音达到 `large_gap_ms` 时通知上层（用于告警，不影响录制本身）。
fn notify_large_gap(events: &Sender<AudioEvent>, cfg: &SourceConfig, r: &Report) {
    if r.large_gap {
        let _ = events.send(AudioEvent::LargeGap { label: cfg.label.clone(), filled_ms: r.filled_frames * 1000 / u64::from(cfg.timeline.format.rate) });
    }
}

#[allow(clippy::too_many_arguments)]
fn pump(s: &mut Stream, cfg: &SourceConfig, qpc: &Qpc, tl: &mut AudioTimeline, emit: &mut dyn FnMut(&[f32]), stop: &AtomicBool, live: &Live, events: &Sender<AudioEvent>) -> StreamEnd {
    let mut last_default_check = qpc.now_hns();
    let mut scratch: Vec<f32> = Vec::new();
    loop {
        if stop.load(Ordering::Acquire) {
            return StreamEnd::Stop;
        }
        unsafe { WaitForSingleObject(s.event, 10) };
        let now = qpc.now_hns();

        // 取走所有已就绪的包
        loop {
            let n = match unsafe { s.capture.GetNextPacketSize() } {
                Ok(n) => n,
                Err(e) => return StreamEnd::Lost(format!("GetNextPacketSize：{e}")),
            };
            if n == 0 {
                break;
            }
            let (mut data, mut frames, mut flags, mut dev_pos, mut qpc_pos) = (std::ptr::null_mut(), 0u32, 0u32, 0u64, 0u64);
            if let Err(e) = unsafe { s.capture.GetBuffer(&mut data, &mut frames, &mut flags, Some(&mut dev_pos), Some(&mut qpc_pos)) } {
                return StreamEnd::Lost(format!("GetBuffer：{e}"));
            }
            let arrival = qpc.now_hns();
            let pf = PacketFlags {
                silent: flags & (AUDCLNT_BUFFERFLAGS_SILENT.0 as u32) != 0,
                timestamp_error: flags & (AUDCLNT_BUFFERFLAGS_TIMESTAMP_ERROR.0 as u32) != 0,
                discontinuity: flags & (AUDCLNT_BUFFERFLAGS_DATA_DISCONTINUITY.0 as u32) != 0,
            };
            let samples: &[f32] = if pf.silent || data.is_null() {
                &[]
            } else {
                let len = frames as usize * s.channels;
                let p = data as *const f32;
                if p.is_aligned() {
                    unsafe { std::slice::from_raw_parts(p, len) }
                } else {
                    scratch.clear();
                    scratch.extend((0..len).map(|i| unsafe { p.add(i).read_unaligned() }));
                    &scratch
                }
            };
            // qpcPosition 已经是 100 ns 单位
            let device_qpc = qpc_pos as Hns;
            let pkt = AudioPacket { device_qpc: Some(device_qpc), arrival_qpc: arrival, frames: frames as usize, samples, flags: pf };
            if let Some(tap) = &cfg.packet_tap {
                let _ = tap.send(PacketRecord { device_qpc, arrival_qpc: arrival, frames, flags: pf });
            }
            live.last_packet_hns.store(arrival, Ordering::Relaxed);
            let r = tl.push_packet(&pkt, emit);
            notify_large_gap(events, cfg, &r);
            if let Err(e) = unsafe { s.capture.ReleaseBuffer(frames) } {
                return StreamEnd::Lost(format!("ReleaseBuffer：{e}"));
            }
        }

        // 空闲：没有包也要让时间线继续走
        let r = tl.tick(now, emit);
        notify_large_gap(events, cfg, &r);
        live.publish_peak(tl.take_peak());

        // 默认设备变化：每 500 ms 比较一次（比 IMMNotificationClient 回调简单，且没有跨线程回调的死锁风险）
        if let Endpoint::Default(_) = cfg.endpoint
            && now - last_default_check >= ms_to_hns(500)
        {
            last_default_check = now;
            if let Ok(dev) = resolve(cfg)
                && let Ok(cur) = devices::info(&dev)
                && cur.id != s.info.id
            {
                return StreamEnd::DeviceChanged { from: s.info.name.clone(), to: cur.name };
            }
        }
    }
}

pub type SharedResult = Arc<Mutex<Option<SourceResult>>>;

//!
//! 每块屏对应一个 DXGI 输出，附带桌面坐标、旋转、HDR、刷新率与缩放：既用于选屏

fn wide_to_string(w: &[u16]) -> String {
    let end = w.iter().position(|&c| c == 0).unwrap_or(w.len());
    String::from_utf16_lossy(&w[..end])

fn refresh_rate(device_name: &[u16]) -> u32 {
    let mut mode = DEVMODEW { dmSize: std::mem::size_of::<DEVMODEW>() as u16, ..Default::default() };
    let ok = unsafe { EnumDisplaySettingsW(PCWSTR(device_name.as_ptr()), ENUM_CURRENT_SETTINGS, &mut mode) };
    if ok.as_bool() { mode.dmDisplayFrequency } else { 0 }
}

fn is_primary(hmon: HMONITOR) -> bool {
    let mut mi = MONITORINFO { cbSize: std::mem::size_of::<MONITORINFO>() as u32, ..Default::default() };
    unsafe { GetMonitorInfoW(hmon, &mut mi) }.as_bool() && mi.dwFlags & MONITORINFOF_PRIMARY_FLAG != 0
}

/// 某块显示器（GDI 设备名，如 `\\.\DISPLAY1`）当前的 SDR 内容亮度，单位尼特。
/// 系统接口给的是以 1000 = 80 尼特为基准的整数。查询失败返回 `None`。
pub fn sdr_white_nits(device_name: &str) -> Option<f32> {
    let header = |kind, adapter, id, size: usize| DISPLAYCONFIG_DEVICE_INFO_HEADER { r#type: kind, size: size as u32, adapterId: adapter, id };
    unsafe {
        let (mut np, mut nm) = (0u32, 0u32);
        GetDisplayConfigBufferSizes(QDC_ONLY_ACTIVE_PATHS, &mut np, &mut nm).ok().ok()?;
        let mut paths = vec![DISPLAYCONFIG_PATH_INFO::default(); np as usize];
        let mut modes = vec![DISPLAYCONFIG_MODE_INFO::default(); nm as usize];
        QueryDisplayConfig(QDC_ONLY_ACTIVE_PATHS, &mut np, paths.as_mut_ptr(), &mut nm, modes.as_mut_ptr(), None).ok().ok()?;
        for p in &paths[..np as usize] {
            let mut src = DISPLAYCONFIG_SOURCE_DEVICE_NAME {
                header: header(DISPLAYCONFIG_DEVICE_INFO_GET_SOURCE_NAME, p.sourceInfo.adapterId, p.sourceInfo.id, std::mem::size_of::<DISPLAYCONFIG_SOURCE_DEVICE_NAME>()),
                ..Default::default()
            };
            if DisplayConfigGetDeviceInfo(&mut src.header) != 0 || wide_to_string(&src.viewGdiDeviceName) != device_name {
                continue;
            }
            let mut white = DISPLAYCONFIG_SDR_WHITE_LEVEL {
                header: header(DISPLAYCONFIG_DEVICE_INFO_GET_SDR_WHITE_LEVEL, p.targetInfo.adapterId, p.targetInfo.id, std::mem::size_of::<DISPLAYCONFIG_SDR_WHITE_LEVEL>()),
                ..Default::default()
            };
            return (DisplayConfigGetDeviceInfo(&mut white.header) == 0 && white.SDRWhiteLevel > 0).then(|| white.SDRWhiteLevel as f32 * 80.0 / 1000.0);
        }
        None
    }
}

fn dpi_scale_percent(hmon: HMONITOR) -> u32 {
    let (mut x, mut y) = (0u32, 0u32);
    match unsafe { GetDpiForMonitor(hmon, MDT_EFFECTIVE_DPI, &mut x, &mut y) } {
        Ok(()) if x > 0 => (x * 100 + 48) / 96,
        _ => 100,
    }
}

/// 枚举所有接在桌面上的显示器，按“显卡序号、输出序号”排列。
pub fn list_monitors() -> windows::core::Result<Vec<MonitorInfo>> {
    let factory: IDXGIFactory1 = unsafe { CreateDXGIFactory1()? };
    let mut found = Vec::new();
    let mut adapter_index = 0u32;
    loop {
        let adapter = match unsafe { factory.EnumAdapters1(adapter_index) } {
            Ok(a) => a,
            Err(e) if e.code() == DXGI_ERROR_NOT_FOUND => break,
            Err(e) => return Err(e),
        };
        let adapter_name = wide_to_string(&unsafe { adapter.GetDesc1()? }.Description);
        let mut output_index = 0u32;
        loop {
            let output = match unsafe { adapter.EnumOutputs(output_index) } {
                Ok(o) => o,
                Err(e) if e.code() == DXGI_ERROR_NOT_FOUND => break,
                Err(e) => return Err(e),
            };
            let desc = unsafe { output.GetDesc()? };
            if desc.AttachedToDesktop.as_bool() {
                let r = desc.DesktopCoordinates;
                let hdr = output.cast::<IDXGIOutput6>().ok().and_then(|o| unsafe { o.GetDesc1() }.ok()).is_some_and(|d| d.ColorSpace == DXGI_COLOR_SPACE_RGB_FULL_G2084_NONE_P2020);
                let device_name = wide_to_string(&desc.DeviceName);
                found.push(MonitorInfo {
                    adapter_index,
                    output_index,
                    adapter: adapter_name.clone(),
                    sdr_white_nits: if hdr { sdr_white_nits(&device_name) } else { None },
                    device_name,
                    hmonitor: desc.Monitor.0 as isize,
                    left: r.left,
                    top: r.top,
                    width: (r.right - r.left).max(0) as u32,
                    height: (r.bottom - r.top).max(0) as u32,
                    rotation: desc.Rotation.0 as u32,
                    primary: is_primary(desc.Monitor),
                    hdr,
                    refresh_hz: refresh_rate(&desc.DeviceName),
                    dpi_scale_percent: dpi_scale_percent(desc.Monitor),
                });
            }
            output_index += 1;
        }
        adapter_index += 1;
    }
    Ok(found)
}

/// 某个窗口所在的显示器（句柄值）。
pub fn hmonitor_of(hwnd: HWND) -> isize {
    unsafe { MonitorFromWindow(hwnd, MONITOR_DEFAULTTOPRIMARY) }.0 as isize
}

/// 前台窗口所在的显示器；没有前台窗口时是主显示器。
pub fn foreground_hmonitor() -> isize {
    hmonitor_of(unsafe { GetForegroundWindow() })
}

/// 按 `pick` 从 `list` 里选一块屏；没有匹配时返回 `None`，由调用方报告，不替用户换一块屏。
pub fn pick_monitor(list: &[MonitorInfo], pick: Pick) -> Option<&MonitorInfo> {
    match pick {
        Pick::Foreground => {
            let h = foreground_hmonitor();
            list.iter().find(|m| m.hmonitor == h)
        }
        Pick::Primary => list.iter().find(|m| m.primary),
        Pick::Index(i) => list.get(i),
        Pick::Hmonitor(h) => list.iter().find(|m| m.hmonitor == h),
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ErrorKind {
    /// 复制对象失效（显示模式变化、全屏独占切换等），需要重建。
    AccessLost,
    /// 系统不允许抓取：UAC、锁屏等安全桌面，或会话已断开。
    AccessDenied,
    /// 显卡设备丢失或重置，整套管线要重建。
    DeviceLost,
    /// 桌面复制名额被占满（同一会话数量有限），或此刻不可用。
    Busy,
    /// 这块屏的当前配置不支持（旋转、没有视频处理器、复制在系统内存里等）。
    Unsupported,
    Other,

#[derive(Debug, Clone)]
pub struct PipelineError {
    pub kind: ErrorKind,
    pub message: String,
}

impl fmt::Display for PipelineError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}", self.message)
    }
}

impl std::error::Error for PipelineError {}

fn classify(e: &windows::core::Error) -> ErrorKind {
    let c = e.code();
    if c == DXGI_ERROR_ACCESS_LOST {
        ErrorKind::AccessLost
    } else if c == E_ACCESSDENIED || c == DXGI_ERROR_SESSION_DISCONNECTED {
        ErrorKind::AccessDenied
    } else if c == DXGI_ERROR_DEVICE_REMOVED || c == DXGI_ERROR_DEVICE_RESET || c == DXGI_ERROR_DEVICE_HUNG {
        ErrorKind::DeviceLost
    } else if c == DXGI_ERROR_NOT_CURRENTLY_AVAILABLE {
        ErrorKind::Busy
    } else if c == DXGI_ERROR_UNSUPPORTED {
        ErrorKind::Unsupported
    } else {
        ErrorKind::Other
    }
}

pub(crate) fn win(context: &str) -> impl Fn(windows::core::Error) -> PipelineError + '_ {
    move |e| PipelineError { kind: classify(&e), message: format!("{context}：{e}") }
}

pub(crate) fn fail(kind: ErrorKind, message: impl Into<String>) -> PipelineError {
    PipelineError { kind, message: message.into() }
}

fn tex_desc(w: u32, h: u32) -> D3D11_TEXTURE2D_DESC {

        Width: w,
        Height: h,
        MipLevels: 1,
        ArraySize: 1,
        Format: DXGI_FORMAT_NV12,
        SampleDesc: DXGI_SAMPLE_DESC { Count: 1, Quality: 0 },
        Usage: D3D11_USAGE_DEFAULT,

impl Pipeline {
    /// 为 `mon` 建一条输出 `out_w`×`out_h`（偶数）的管线。
    pub fn open(mon: &MonitorInfo, out_w: u32, out_h: u32) -> Result<Self, PipelineError> {
        assert!(out_w >= 2 && out_h >= 2 && out_w.is_multiple_of(2) && out_h.is_multiple_of(2), "输出尺寸必须是不小于 2 的偶数");
        if mon.rotation > 1 {
            return Err(fail(ErrorKind::Unsupported, format!("显示器有旋转（代码 {}），暂不支持", mon.rotation)));
        }

        // 设备必须建在输出所在的显卡上，跨显卡的桌面复制不被支持
        let factory: IDXGIFactory1 = unsafe { CreateDXGIFactory1() }.map_err(win("创建 DXGI 工厂"))?;
        let adapter = unsafe { factory.EnumAdapters1(mon.adapter_index) }.map_err(win("取显卡"))?;
        let output = unsafe { adapter.EnumOutputs(mon.output_index) }.map_err(win("取显示输出"))?;

        let (mut device, mut context): (Option<ID3D11Device>, Option<ID3D11DeviceContext>) = (None, None);
        unsafe {
            D3D11CreateDevice(
                &adapter,
                D3D_DRIVER_TYPE_UNKNOWN,
                HMODULE::default(),
                D3D11_CREATE_DEVICE_BGRA_SUPPORT | D3D11_CREATE_DEVICE_VIDEO_SUPPORT,
                Some(&[D3D_FEATURE_LEVEL_11_1, D3D_FEATURE_LEVEL_11_0]),
                D3D11_SDK_VERSION,
                Some(&mut device),
                None,
                Some(&mut context),
            )
        }
        .map_err(win("创建 D3D11 设备"))?;
        let (device, context) = (device.expect("设备已创建"), context.expect("上下文已创建"));

        // 优先 DuplicateOutput1 并同时要 FP16 与 BGRA8：HDR 开着时旧接口返回的 8 位图已被系统截断（高光丢失）；
        // 只有 Windows 10 1709 之前没有 IDXGIOutput5，那时才用旧接口
        let dup = match output.cast::<IDXGIOutput5>() {
            Ok(o5) => unsafe { o5.DuplicateOutput1(&device, 0, &[DXGI_FORMAT_R16G16B16A16_FLOAT, DXGI_FORMAT_B8G8R8A8_UNORM]) }.map_err(win("DuplicateOutput1"))?,
            Err(_) => {
                let output1: IDXGIOutput1 = output.cast().map_err(win("取 IDXGIOutput1"))?;
                unsafe { output1.DuplicateOutput(&device) }.map_err(win("DuplicateOutput"))?
            }
        };
        let dd: DXGI_OUTDUPL_DESC = unsafe { dup.GetDesc() };
        let (src_w, src_h) = (dd.ModeDesc.Width, dd.ModeDesc.Height);
        let tonemap = match dd.ModeDesc.Format {
            f if f == DXGI_FORMAT_B8G8R8A8_UNORM => None,
            f if f == DXGI_FORMAT_R16G16B16A16_FLOAT => {
                let nits = sdr_white_nits(&mon.device_name).unwrap_or(80.0);
                Some(Tonemap::new(&device, src_w, src_h, nits)?)
            }
            f => return Err(fail(ErrorKind::Unsupported, format!("桌面图像格式 {} 暂不支持", f.0))),
        };
        if dd.Rotation != DXGI_MODE_ROTATION_IDENTITY && dd.Rotation != DXGI_MODE_ROTATION_UNSPECIFIED {
            return Err(fail(ErrorKind::Unsupported, format!("复制对象报告旋转 {}，暂不支持", dd.Rotation.0)));
        }
        if dd.DesktopImageInSystemMemory.as_bool() {
            return Err(fail(ErrorKind::Unsupported, "桌面图像在系统内存里（没有 GPU 复制路径）"));
        }

        let vdev: ID3D11VideoDevice = device.cast().map_err(win("取 ID3D11VideoDevice（显卡不支持视频处理？）"))?;
        let vctx: ID3D11VideoContext = context.cast().map_err(win("取 ID3D11VideoContext"))?;
        let vctx1: ID3D11VideoContext1 = vctx.cast().map_err(win("取 ID3D11VideoContext1"))?;

        let content = D3D11_VIDEO_PROCESSOR_CONTENT_DESC {
            InputFrameFormat: D3D11_VIDEO_FRAME_FORMAT_PROGRESSIVE,
            InputFrameRate: DXGI_RATIONAL { Numerator: 30, Denominator: 1 },
            InputWidth: src_w,
            InputHeight: src_h,
            OutputFrameRate: DXGI_RATIONAL { Numerator: 30, Denominator: 1 },
            OutputWidth: out_w,
            OutputHeight: out_h,
            Usage: D3D11_VIDEO_USAGE_PLAYBACK_NORMAL,
        };
        let enumerator = unsafe { vdev.CreateVideoProcessorEnumerator(&content) }.map_err(win("创建视频处理器枚举器"))?;
        let can_in = unsafe { enumerator.CheckVideoProcessorFormat(DXGI_FORMAT_B8G8R8A8_UNORM) }.map_err(win("检查 BGRA 输入支持"))?;
        let can_out = unsafe { enumerator.CheckVideoProcessorFormat(DXGI_FORMAT_NV12) }.map_err(win("检查 NV12 输出支持"))?;
        if can_in & D3D11_VIDEO_PROCESSOR_FORMAT_SUPPORT_INPUT.0 as u32 == 0 {
            return Err(fail(ErrorKind::Unsupported, "视频处理器不支持 BGRA 输入"));
        }
        if can_out & D3D11_VIDEO_PROCESSOR_FORMAT_SUPPORT_OUTPUT.0 as u32 == 0 {
            return Err(fail(ErrorKind::Unsupported, "视频处理器不支持 NV12 输出"));
        }
        let processor = unsafe { vdev.CreateVideoProcessor(&enumerator, 0) }.map_err(win("创建视频处理器"))?;

        let mut nv12 = None;
        unsafe { device.CreateTexture2D(&tex_desc(out_w, out_h), None, Some(&mut nv12)) }.map_err(win("创建 NV12 输出纹理"))?;
        let nv12 = nv12.expect("纹理已创建");
        let mut staging = None;
        let mut sd = tex_desc(out_w, out_h);
        sd.Usage = D3D11_USAGE_STAGING;
        sd.BindFlags = 0;
        sd.CPUAccessFlags = D3D11_CPU_ACCESS_READ.0 as u32;
        unsafe { device.CreateTexture2D(&sd, None, Some(&mut staging)) }.map_err(win("创建 NV12 回读纹理（显卡不支持 NV12 的 CPU 读取？）"))?;
        let staging = staging.expect("纹理已创建");

        let out_desc = D3D11_VIDEO_PROCESSOR_OUTPUT_VIEW_DESC {
            ViewDimension: D3D11_VPOV_DIMENSION_TEXTURE2D,
            Anonymous: D3D11_VIDEO_PROCESSOR_OUTPUT_VIEW_DESC_0 { Texture2D: D3D11_TEX2D_VPOV { MipSlice: 0 } },
        };
        let mut out_view = None;
        unsafe { vdev.CreateVideoProcessorOutputView(&nv12, &enumerator, &out_desc, Some(&mut out_view)) }.map_err(win("创建输出视图"))?;
        let out_view = out_view.expect("视图已创建");

        // 画面：整块源放进输出里，比例不同时留黑边；输出尺寸在整场录制里不变
        let layout = letterbox(src_w, src_h, out_w, out_h);
        unsafe {
            vctx1.VideoProcessorSetStreamFrameFormat(&processor, 0, D3D11_VIDEO_FRAME_FORMAT_PROGRESSIVE);
            vctx1.VideoProcessorSetStreamAutoProcessingMode(&processor, 0, false);
            vctx1.VideoProcessorSetStreamSourceRect(&processor, 0, true, Some(&rect(Rect { x: 0, y: 0, w: src_w, h: src_h })));
            vctx1.VideoProcessorSetStreamDestRect(&processor, 0, true, Some(&rect(layout)));
            vctx1.VideoProcessorSetOutputTargetRect(&processor, true, Some(&rect(Rect { x: 0, y: 0, w: out_w, h: out_h })));
            // 黑边必须是有限范围的黑（Y16、U/V128）：用 RGB 黑色设背景时驱动给出的是 Y0（实测），低于有限范围下限
            let black = D3D11_VIDEO_COLOR { Anonymous: D3D11_VIDEO_COLOR_0 { YCbCr: D3D11_VIDEO_COLOR_YCbCrA { Y: 16.0 / 255.0, Cb: 128.0 / 255.0, Cr: 128.0 / 255.0, A: 1.0 } } };
            vctx1.VideoProcessorSetOutputBackgroundColor(&processor, true, &black);
            // 输入是 sRGB 全范围，输出是 BT.709 有限范围（编码器与播放器按它解读）
            vctx1.VideoProcessorSetStreamColorSpace1(&processor, 0, DXGI_COLOR_SPACE_RGB_FULL_G22_NONE_P709);
            vctx1.VideoProcessorSetOutputColorSpace1(&processor, DXGI_COLOR_SPACE_YCBCR_STUDIO_G22_LEFT_P709);
        }

        Ok(Self { device, context, dup, tonemap, vctx: vctx1, vdev, enumerator, processor, nv12, out_view, staging, src_w, src_h, out_w, out_h, layout, src_format: None })
    }

    /// 桌面是 HDR（FP16）：画面要先经过 HDR→SDR 转换。
    pub fn is_hdr(&self) -> bool {
        self.tonemap.is_some()
    }

    /// 用户调了系统的“SDR 内容亮度”：更新转换增益。非 HDR 管线上无作用。
    pub fn set_sdr_white_nits(&self, nits: f32) {
        if let Some(t) = &self.tonemap {
            t.set_white_nits(&self.context, nits);
        }
    }

    /// 取一帧：桌面有更新就转成 NV12 返回，没有更新返回 `None`（调用方沿用上一帧）。
    /// 以 0 超时调用 `AcquireNextFrame`，不会阻塞等待屏幕变化。
    pub fn grab(&mut self) -> Result<Option<Arc<[u8]>>, PipelineError> {
        let mut info = DXGI_OUTDUPL_FRAME_INFO::default();
        let mut resource: Option<IDXGIResource> = None;
        match unsafe { self.dup.AcquireNextFrame(0, &mut info, &mut resource) } {
            Ok(()) => {}
            Err(e) if e.code() == DXGI_ERROR_WAIT_TIMEOUT => return Ok(None),
            Err(e) => return Err(win("AcquireNextFrame")(e)),
        }
        // LastPresentTime 为 0 表示只有鼠标指针动了，桌面图像没有更新
        let result = if info.LastPresentTime == 0 { Ok(None) } else { self.convert(resource).map(Some) };
        // 无论转换成功与否都必须释放，否则下一次 Acquire 会报调用无效
        let _ = unsafe { self.dup.ReleaseFrame() };
        result
    }

    fn convert(&mut self, resource: Option<IDXGIResource>) -> Result<Arc<[u8]>, PipelineError> {
        let texture: ID3D11Texture2D = resource.ok_or_else(|| fail(ErrorKind::Other, "AcquireNextFrame 没有给出资源"))?.cast().map_err(win("桌面资源转纹理"))?;
        let mut desc = D3D11_TEXTURE2D_DESC::default();
        unsafe { texture.GetDesc(&mut desc) };
        self.src_format = Some(desc.Format.0);
        if (desc.Width, desc.Height) != (self.src_w, self.src_h) {
            // 显示模式已经变了，复制对象马上就会报失效；按失效处理，让上层重建
            return Err(fail(ErrorKind::AccessLost, format!("桌面尺寸从 {}×{} 变成 {}×{}", self.src_w, self.src_h, desc.Width, desc.Height)));
        }

        let in_desc = D3D11_VIDEO_PROCESSOR_INPUT_VIEW_DESC {
            FourCC: 0,
            ViewDimension: D3D11_VPIV_DIMENSION_TEXTURE2D,
            Anonymous: D3D11_VIDEO_PROCESSOR_INPUT_VIEW_DESC_0 { Texture2D: D3D11_TEX2D_VPIV { MipSlice: 0, ArraySlice: 0 } },
        };
        // HDR 时先转成 SDR 的 BGRA8，视频处理器的输入永远是 sRGB 的 BGRA8
        let input: &ID3D11Texture2D = match &self.tonemap {
            Some(t) => t.apply(&self.device, &self.context, &texture)?,
            None => &texture,
        };
        let mut in_view = None;
        unsafe { self.vdev.CreateVideoProcessorInputView(input, &self.enumerator, &in_desc, Some(&mut in_view)) }.map_err(win("创建输入视图"))?;
        let stream = D3D11_VIDEO_PROCESSOR_STREAM { Enable: true.into(), pInputSurface: std::mem::ManuallyDrop::new(in_view), ..Default::default() };
        let blt = unsafe { self.vctx.VideoProcessorBlt(&self.processor, &self.out_view, 0, std::slice::from_ref(&stream)) };
        // 视图的引用要自己放：结构体里是 ManuallyDrop
        drop(std::mem::ManuallyDrop::into_inner(stream.pInputSurface));
        blt.map_err(win("VideoProcessorBlt"))?;

        unsafe { self.context.CopyResource(&self.staging, &self.nv12) };
        let mut mapped = D3D11_MAPPED_SUBRESOURCE::default();
        unsafe { self.context.Map(&self.staging, 0, D3D11_MAP_READ, 0, Some(&mut mapped)) }.map_err(win("Map 回读纹理"))?;
        let frame = self.copy_planes(&mapped);
        unsafe { self.context.Unmap(&self.staging, 0) };
        Ok(frame)
    }

    /// 把带行距的 NV12 紧凑地复制出来：Y 平面 `h` 行，紧接着 UV 平面 `h/2` 行，行距相同。
    fn copy_planes(&self, mapped: &D3D11_MAPPED_SUBRESOURCE) -> Arc<[u8]> {
        let (w, h) = (self.out_w as usize, self.out_h as usize);
        let pitch = mapped.RowPitch as usize;
        let base = mapped.pData as *const u8;
        let mut frame: Arc<[u8]> = unsafe { Arc::<[u8]>::new_zeroed_slice(nv12_frame_bytes(self.out_w, self.out_h)).assume_init() };
        let dst = Arc::get_mut(&mut frame).expect("刚创建，没有其它引用");
        for row in 0..h + h / 2 {
            // 行 0..h 是 Y，之后是 UV；两个平面行距相同，UV 平面从第 h 行开始
            let src = unsafe { std::slice::from_raw_parts(base.add(row * pitch), w) };
            dst[row * w..(row + 1) * w].copy_from_slice(src);
        }
        frame
    }
}

//! HDR → SDR（设计文档 5.2 的 HDR 策略 ②）。
//!
//! 显示器开着 HDR 时，桌面在系统里是 scRGB（FP16 线性，1.0 = 80 尼特），SDR 内容被放大到“SDR 内容亮度”
//! （本机 240 尼特即放大 3 倍）。旧版 `DuplicateOutput` 直接把它截断成 8 位，高光信息当场丢失，事后无法修复；
//! 所以要用 `DuplicateOutput1` 要 FP16，再在 GPU 上除掉这个放大比例，截断到 SDR 范围，做 sRGB 编码。
//! HDR 高光会被截断（输出本来就是 SDR 的 H.264）。

use crate::pipeline::{ErrorKind, PipelineError, fail, win};
use windows::Win32::Graphics::Direct3D::Fxc::{D3DCOMPILE_OPTIMIZATION_LEVEL3, D3DCompile};
use windows::Win32::Graphics::Direct3D::{D3D_PRIMITIVE_TOPOLOGY_TRIANGLELIST, ID3DBlob};
use windows::Win32::Graphics::Direct3D11::{
    D3D11_BIND_CONSTANT_BUFFER, D3D11_BIND_RENDER_TARGET, D3D11_BIND_SHADER_RESOURCE, D3D11_BUFFER_DESC, D3D11_SUBRESOURCE_DATA, D3D11_TEXTURE2D_DESC, D3D11_USAGE_DEFAULT, D3D11_VIEWPORT,
    ID3D11Buffer, ID3D11Device, ID3D11DeviceContext, ID3D11PixelShader, ID3D11RenderTargetView, ID3D11Texture2D, ID3D11VertexShader,
};
use windows::Win32::Graphics::Dxgi::Common::{DXGI_FORMAT_B8G8R8A8_UNORM, DXGI_SAMPLE_DESC};
use windows::core::s;

const HLSL: &str = r#"
cbuffer Params : register(b0) { float gain; float3 pad; };
Texture2D<float4> src : register(t0);
struct VSOut { float4 pos : SV_Position; };
VSOut vs_main(uint id : SV_VertexID) {
    float2 uv = float2((id << 1) & 2, id & 2);
    VSOut o;
    o.pos = float4(uv * float2(2, -2) + float2(-1, 1), 0, 1);
    return o;
}
float3 encode(float3 c) {
    float3 lo = c * 12.92;
    float3 hi = 1.055 * pow(c, 1.0 / 2.4) - 0.055;
    return lerp(hi, lo, step(c, 0.0031308));
}
float4 ps_main(VSOut i) : SV_Target {
    float3 lin = saturate(src.Load(int3(i.pos.xy, 0)).rgb * gain);
    return float4(encode(lin), 1);
}
"#;

/// 系统“SDR 内容亮度”换算成线性增益：scRGB 的 1.0 是 80 尼特。
pub fn gain_for(white_nits: f32) -> f32 {
    80.0 / white_nits.max(1.0)
}

fn compile(entry: windows::core::PCSTR, target: windows::core::PCSTR) -> Result<ID3DBlob, PipelineError> {
    let mut code: Option<ID3DBlob> = None;
    let mut errors: Option<ID3DBlob> = None;
    let r = unsafe {
        D3DCompile(
            HLSL.as_ptr().cast(),
            HLSL.len(),
            s!("tonemap.hlsl"),
            None,
            None::<&windows::Win32::Graphics::Direct3D::ID3DInclude>,
            entry,
            target,
            D3DCOMPILE_OPTIMIZATION_LEVEL3,
            0,
            &mut code,
            Some(&mut errors),
        )
    };
    if let Err(e) = r {
        let detail = errors.map(|b| blob_text(&b)).unwrap_or_default();
        return Err(fail(ErrorKind::Other, format!("编译 HDR 转换着色器失败：{e} {detail}")));
    }
    code.ok_or_else(|| fail(ErrorKind::Other, "着色器编译没有产出"))
}

fn blob_bytes(b: &ID3DBlob) -> &[u8] {
    unsafe { std::slice::from_raw_parts(b.GetBufferPointer().cast::<u8>(), b.GetBufferSize()) }
}

fn blob_text(b: &ID3DBlob) -> String {
    String::from_utf8_lossy(blob_bytes(b)).trim().to_string()
}

pub struct Tonemap {
    sdr: ID3D11Texture2D,
    rtv: ID3D11RenderTargetView,
    vs: ID3D11VertexShader,
    ps: ID3D11PixelShader,
    cb: ID3D11Buffer,
    w: u32,
    h: u32,
}

impl Tonemap {
    pub fn new(device: &ID3D11Device, w: u32, h: u32, white_nits: f32) -> Result<Self, PipelineError> {
        let vs_code = compile(s!("vs_main"), s!("vs_5_0"))?;
        let ps_code = compile(s!("ps_main"), s!("ps_5_0"))?;
        let mut vs = None;
        unsafe { device.CreateVertexShader(blob_bytes(&vs_code), None, Some(&mut vs)) }.map_err(win("创建顶点着色器"))?;
        let mut ps = None;
        unsafe { device.CreatePixelShader(blob_bytes(&ps_code), None, Some(&mut ps)) }.map_err(win("创建像素着色器"))?;

        let desc = D3D11_TEXTURE2D_DESC {
            Width: w,
            Height: h,
            MipLevels: 1,
            ArraySize: 1,
            Format: DXGI_FORMAT_B8G8R8A8_UNORM,
            SampleDesc: DXGI_SAMPLE_DESC { Count: 1, Quality: 0 },
            Usage: D3D11_USAGE_DEFAULT,
            BindFlags: (D3D11_BIND_RENDER_TARGET.0 | D3D11_BIND_SHADER_RESOURCE.0) as u32,
            CPUAccessFlags: 0,
            MiscFlags: 0,
        };
        let mut sdr = None;
        unsafe { device.CreateTexture2D(&desc, None, Some(&mut sdr)) }.map_err(win("创建 SDR 中间纹理"))?;
        let sdr: ID3D11Texture2D = sdr.expect("纹理已创建");
        let mut rtv = None;
        unsafe { device.CreateRenderTargetView(&sdr, None, Some(&mut rtv)) }.map_err(win("创建渲染目标视图"))?;

        let gain = [gain_for(white_nits), 0.0, 0.0, 0.0];
        let init = D3D11_SUBRESOURCE_DATA { pSysMem: gain.as_ptr().cast(), SysMemPitch: 0, SysMemSlicePitch: 0 };
        let bd = D3D11_BUFFER_DESC { ByteWidth: 16, Usage: D3D11_USAGE_DEFAULT, BindFlags: D3D11_BIND_CONSTANT_BUFFER.0 as u32, CPUAccessFlags: 0, MiscFlags: 0, StructureByteStride: 0 };
        let mut cb = None;
        unsafe { device.CreateBuffer(&bd, Some(&init), Some(&mut cb)) }.map_err(win("创建常量缓冲"))?;

        Ok(Self { sdr, rtv: rtv.expect("视图已创建"), vs: vs.expect("着色器已创建"), ps: ps.expect("着色器已创建"), cb: cb.expect("缓冲已创建"), w, h })
    }

    /// 用户调了“SDR 内容亮度”滑块时更新增益。
    pub fn set_white_nits(&self, context: &ID3D11DeviceContext, white_nits: f32) {
        let gain = [gain_for(white_nits), 0.0, 0.0, 0.0];
        unsafe { context.UpdateSubresource(&self.cb, 0, None, gain.as_ptr().cast(), 0, 0) };
    }

    /// 把 FP16 的桌面图像转成 SDR 的 BGRA8，返回结果纹理。
    pub fn apply(&self, device: &ID3D11Device, context: &ID3D11DeviceContext, src: &ID3D11Texture2D) -> Result<&ID3D11Texture2D, PipelineError> {
        let mut srv = None;
        unsafe { device.CreateShaderResourceView(src, None, Some(&mut srv)) }.map_err(win("创建桌面纹理的着色器视图"))?;
        unsafe {
            context.OMSetRenderTargets(Some(&[Some(self.rtv.clone())]), None);
            context.RSSetViewports(Some(&[D3D11_VIEWPORT { TopLeftX: 0.0, TopLeftY: 0.0, Width: self.w as f32, Height: self.h as f32, MinDepth: 0.0, MaxDepth: 1.0 }]));
            context.IASetPrimitiveTopology(D3D_PRIMITIVE_TOPOLOGY_TRIANGLELIST);
            context.VSSetShader(&self.vs, None);
            context.PSSetShader(&self.ps, None);
            context.PSSetConstantBuffers(0, Some(&[Some(self.cb.clone())]));
            context.PSSetShaderResources(0, Some(&[srv]));
            context.Draw(3, 0);
            // 解绑：后面这张纹理要当视频处理器的输入，不能同时还挂在渲染目标上
            context.PSSetShaderResources(0, Some(&[None]));
            context.OMSetRenderTargets(None, None);
        }
        Ok(&self.sdr)
    }
}

//! 画面采集线程（设计文档 5.2、5.9）。
//!
//! 按恒定帧率节拍取帧：每到一个节拍以 0 超时向桌面复制要一帧，有更新就转成 NV12，没有就沿用上一帧。
//! 每个到期的帧恰好交付一次（序号 = floor((now − t0) × fps)）。采集循环落后时，较早到期的帧用上一帧补齐，

//!
//! 失败不做静默兜底：复制失效就按节流重建，期间重复上一帧，按原因计数并发事件告警。

/// 取一帧（含 GPU 转换与回读）耗时的分布。
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct GrabTimes {
    pub count: u64,
    pub p50_us: u32,
    pub p95_us: u32,
    pub p99_us: u32,
    pub max_us: u32,
}

impl GrabTimes {
    pub fn from_samples(samples: &mut [u32]) -> Self {
        if samples.is_empty() {
            return Self::default();
        }
        samples.sort_unstable();
        let at = |p: f64| samples[(((samples.len() - 1) as f64) * p).round() as usize];
        Self { count: samples.len() as u64, p50_us: at(0.50), p95_us: at(0.95), p99_us: at(0.99), max_us: *samples.last().unwrap() }
    }
}

pub struct VideoResult {

    pub src_w: u32,
    pub src_h: u32,

    pub lost: u32,

    pub src_format: Option<i32>,
    pub first_frame_ms: Option<u64>,
    /// 管线不可用的累计毫秒数（第一次打开之前的等待不算）。
    pub down_ms: u64,
    pub grab: GrabTimes,

#[derive(Debug, Clone, PartialEq, Eq)]
enum DownKind {
    Rebuilding,
    SecureDesktop,
    Failed(String),
}

struct Down {
    since: Hns,
    last_attempt: Option<Hns>,
    kind: DownKind,
}

fn repeat_reason(up: bool, kind: &DownKind) -> RepeatReason {
    match (up, kind) {
        (true, _) => RepeatReason::NoChange,
        (false, DownKind::Rebuilding) => RepeatReason::DuplicationRebuild,
        (false, DownKind::SecureDesktop) => RepeatReason::SecureDesktop,
        (false, DownKind::Failed(_)) => RepeatReason::DuplicationFailed,
    }
}

/// 把一次打开或取帧的失败记到断开状态里，状态变化时才发事件。
fn note_failure(e: &PipelineError, down: &mut Down, result: &mut VideoResult, events: &Sender<VideoEvent>) {
    let kind = if e.kind == ErrorKind::AccessDenied { DownKind::SecureDesktop } else { DownKind::Failed(e.message.clone()) };
    if kind != down.kind {
        match &kind {
            DownKind::SecureDesktop => {
                result.secure_desktop_episodes += 1;
                let _ = events.send(VideoEvent::SecureDesktop);
            }
            DownKind::Failed(m) => {
                let _ = events.send(VideoEvent::Failed { error: m.clone() });
            }
            DownKind::Rebuilding => {}
        }
        down.kind = kind;
    }
}

/// 交付一帧：序号、NV12 数据（重复帧共享同一份）、种类。在采集线程上调用，要尽快返回（只入队）。
pub type FrameSink = Box<dyn FnMut(u64, Arc<[u8]>, FrameKind) + Send>;

pub struct VideoSource {
    stop: Arc<AtomicBool>,
    live: Arc<VideoLive>,
    thread: Option<JoinHandle<VideoResult>>,
}

impl VideoSource {
    pub fn start(cfg: VideoConfig, qpc: Qpc, events: Sender<VideoEvent>, sink: FrameSink) -> std::io::Result<Self> {
        let stop = Arc::new(AtomicBool::new(false));
        let live = Arc::new(VideoLive::default());
        let (s, l) = (Arc::clone(&stop), Arc::clone(&live));
        let thread = thread::Builder::new().name("video-capture".into()).spawn(move || run(cfg, qpc, events, sink, &s, &l))?;
        Ok(Self { stop, live, thread: Some(thread) })
    }

    pub fn live(&self) -> &Arc<VideoLive> {
        &self.live
    }

    /// 通知线程退出，不等它结束（多轨一起停时先对每一轨调用，再逐个 `stop()` 收结果）。
    pub fn request_stop(&self) {
        self.stop.store(true, Ordering::Release);
    }

    pub fn stop(mut self) -> VideoResult {
        self.stop.store(true, Ordering::Release);
        self.thread.take().map(|t| t.join().unwrap_or_default()).unwrap_or_default()
    }
}

impl Drop for VideoSource {
    fn drop(&mut self) {
        self.stop.store(true, Ordering::Release);
        if let Some(t) = self.thread.take() {
            let _ = t.join();
        }
    }
}

fn run(cfg: VideoConfig, qpc: Qpc, events: Sender<VideoEvent>, mut sink: FrameSink, stop: &AtomicBool, live: &VideoLive) -> VideoResult {
    let _com = ComGuard::init().expect("COM 初始化");
    let interval = cfg.rebuild_interval.as_millis() as i64 * 10_000;
    let mut pacer = FramePacer::new(cfg.fps, cfg.t0);
    let mut result = VideoResult { out_w: cfg.out_w, out_h: cfg.out_h, hdr: cfg.monitor.hdr, ..Default::default() };
    let mut pipeline: Option<Pipeline> = None;
    let mut down = Down { since: qpc.now_hns(), last_attempt: None, kind: DownKind::Rebuilding };
    let mut ever_up = false;
    let mut last_frame: Option<Arc<[u8]>> = None;
    let mut grab_us: Vec<u32> = Vec::new();
    let mut white_nits: Option<f32> = None;
    let mut last_white_check: Hns = 0;
    live.down.store(true, Ordering::Relaxed);

    while !stop.load(Ordering::Acquire) {
        let mut now = qpc.now_hns();
        let mut due = pacer.due(now);
        if due.is_empty() {
            let wait = pacer.time_of(pacer.next_index()) - now;
            thread::sleep(Duration::from_micros((wait / 10).clamp(500, 20_000) as u64));
            continue;
        }

        // 1. 管线断开时按节流尝试（第一次不等）
        if pipeline.is_none() && down.last_attempt.is_none_or(|t| now - t >= interval) {
            down.last_attempt = Some(now);
            match Pipeline::open(&cfg.monitor, cfg.out_w, cfg.out_h) {
                Ok(p) => {
                    let _ = events.send(VideoEvent::Opened {
                        monitor: cfg.monitor.device_name.clone(),
                        src_w: p.src_w,
                        src_h: p.src_h,
                        out_w: p.out_w,
                        out_h: p.out_h,
                        hdr: p.is_hdr(),
                        took_ms: ((qpc.now_hns() - now) / 10_000).max(0) as u64,
                        rebuild: ever_up,
                    });
                    (result.src_w, result.src_h) = (p.src_w, p.src_h);
                    result.hdr = p.is_hdr();
                    white_nits = sdr_white_nits(&cfg.monitor.device_name);
                    last_white_check = now;
                    if ever_up {
                        result.rebuilds += 1;
                        let down_ms = ((qpc.now_hns() - down.since) / 10_000).max(0) as u64;
                        result.down_ms += down_ms;
                        let _ = events.send(VideoEvent::Recovered { down_ms });
                    }
                    ever_up = true;
                    pipeline = Some(p);
                    live.down.store(false, Ordering::Relaxed);
                    // 打开管线本身要 100~200 ms。到期的帧要按“现在”重新算，否则第一张新画面会被标上早了这么久的时刻
                    now = qpc.now_hns();
                    let more = pacer.due(now);
                    if !more.is_empty() {
                        due.end = more.end;
                    }
                }
                Err(e) => note_failure(&e, &mut down, &mut result, &events),
            }
        }

        // 1.5 HDR 下每秒看一次“SDR 内容亮度”，用户调了滑块就更新增益
        if let Some(p) = pipeline.as_ref().filter(|p| p.is_hdr())
            && now - last_white_check >= 10_000_000
        {
            last_white_check = now;
            let current = sdr_white_nits(&cfg.monitor.device_name);
            if let (Some(n), true) = (current, current != white_nits) {
                p.set_sdr_white_nits(n);
                white_nits = current;
                let _ = events.send(VideoEvent::SdrWhiteChanged { nits: n });
            }
        }

        // 2. 向桌面复制要一帧
        let mut fresh: Option<Arc<[u8]>> = None;
        if let Some(p) = pipeline.as_mut() {
            let t = qpc.now_hns();
            match p.grab() {
                Ok(Some(f)) => {
                    grab_us.push(((qpc.now_hns() - t) / 10).clamp(0, i64::from(u32::MAX)) as u32);
                    result.src_format = p.src_format;
                    fresh = Some(f);
                }
                Ok(None) => {}
                Err(e) => {
                    pipeline = None;
                    live.down.store(true, Ordering::Relaxed);
                    down = Down { since: qpc.now_hns(), last_attempt: None, kind: DownKind::Rebuilding };
                    if matches!(e.kind, ErrorKind::AccessLost | ErrorKind::DeviceLost) {
                        result.lost += 1;
                        let _ = events.send(VideoEvent::Lost { reason: e.message });
                    } else {
                        note_failure(&e, &mut down, &mut result, &events);
                    }
                }
            }
        }

        // 3. 每个到期的帧恰好交付一次：最新的一帧用新画面，其余用上一帧补齐
        let last = due.end - 1;
        for idx in due {
            let (data, kind) = if idx == last && fresh.is_some() {
                let f = fresh.take().expect("刚判断过");
                result.stats.fresh += 1;
                live.fresh.fetch_add(1, Ordering::Relaxed);
                live.last_fresh_hns.store(now, Ordering::Relaxed);
                if result.first_frame_ms.is_none() {
                    let after_ms = ((now - cfg.t0) / 10_000).max(0) as u64;
                    result.first_frame_ms = Some(after_ms);
                    let _ = events.send(VideoEvent::FirstFrame { after_ms });
                }
                last_frame = Some(Arc::clone(&f));
                (f, FrameKind::Fresh)
            } else if let Some(prev) = &last_frame {
                if idx == last {
                    let reason = repeat_reason(pipeline.is_some(), &down.kind);
                    result.stats.record_repeat(reason);
                    (Arc::clone(prev), FrameKind::Repeat(reason))
                } else {
                    result.stats.catch_up += 1;
                    (Arc::clone(prev), FrameKind::CatchUp)
                }
            } else {
                // 还没有任何画面：不交付，写入器会用第一帧补齐开头
                continue;
            };
            live.emitted.fetch_add(1, Ordering::Relaxed);
            if kind != FrameKind::CatchUp {
                live.on_time.fetch_add(1, Ordering::Relaxed);
            }
            sink(idx, data, kind);
        }
    }

    if pipeline.is_none() {
        result.down_ms += ((qpc.now_hns() - down.since) / 10_000).max(0) as u64;
    }
    result.grab = GrabTimes::from_samples(&mut grab_us);
    result
}

fn rgb(c: [u8; 3]) -> COLORREF {
    COLORREF(u32::from(c[0]) | u32::from(c[1]) << 8 | u32::from(c[2]) << 16)

fn fill(hdc: windows::Win32::Graphics::Gdi::HDC, r: record_core::geometry::Rect, color: [u8; 3]) {
    let rc = RECT { left: r.x as i32, top: r.y as i32, right: r.right() as i32, bottom: r.bottom() as i32 };
    unsafe {
        let brush: HBRUSH = CreateSolidBrush(rgb(color));
        FillRect(hdc, &rc, brush);
        let _ = DeleteObject(brush.into());
    }
}

unsafe fn paint(hwnd: HWND, st: &State) {
    let (w, h) = (st.spec.width, st.spec.height);
    let mut ps = PAINTSTRUCT::default();
    let hdc = unsafe { BeginPaint(hwnd, &mut ps) };
    // 先画到内存位图再整块拷贝，避免桌面复制抓到画了一半的画面
    let mem = unsafe { CreateCompatibleDC(Some(hdc)) };
    let bmp = unsafe { CreateCompatibleBitmap(hdc, w as i32, h as i32) };
    let old = unsafe { SelectObject(mem, bmp.into()) };
    for (r, c) in quadrants(w, h).into_iter().zip(QUADRANT_RGB) {
        fill(mem, r, c);
    }
    let s = strip(w, h);
    fill(mem, s, STRIP_RGB);
    if st.spec.animate {
        let left = bar_left(phase_at(st.qpc.now_hns(), st.t_ref), w);
        fill(mem, record_core::geometry::Rect { x: left, y: s.y, w: bar_width(w), h: s.h }, BAR_RGB);
    }
    unsafe {
        let _ = BitBlt(hdc, 0, 0, w as i32, h as i32, Some(mem), 0, 0, SRCCOPY);
        SelectObject(mem, old);
        let _ = DeleteObject(bmp.into());
        let _ = DeleteDC(mem);
        let _ = EndPaint(hwnd, &ps);
    }
}

unsafe extern "system" fn wndproc(hwnd: HWND, msg: u32, wparam: WPARAM, lparam: LPARAM) -> LRESULT {
    if msg == WM_NCCREATE {
        let cs = lparam.0 as *const CREATESTRUCTW;
        unsafe { SetWindowLongPtrW(hwnd, GWLP_USERDATA, (*cs).lpCreateParams as isize) };
        return unsafe { DefWindowProcW(hwnd, msg, wparam, lparam) };
    }
    let st = unsafe { GetWindowLongPtrW(hwnd, GWLP_USERDATA) } as *const State;
    match msg {
        WM_PAINT if !st.is_null() => {
            unsafe { paint(hwnd, &*st) };
            LRESULT(0)
        }
        WM_ERASEBKGND => LRESULT(1),
        // HTTRANSPARENT 是 -1；常量在不同绑定里的类型不同，直接写数值更稳妥
        WM_NCHITTEST => LRESULT(-1),
        WM_DESTROY => {
            unsafe { PostQuitMessage(0) };
            LRESULT(0)
        }
        _ => unsafe { DefWindowProcW(hwnd, msg, wparam, lparam) },
    }
}

fn window_thread(spec: TestWindowSpec, qpc: Qpc, stop: Arc<AtomicBool>, ready: mpsc::Sender<Result<(isize, Hns), String>>) {
    let hinstance = match unsafe { GetModuleHandleW(None) } {
        Ok(h) => h,
        Err(e) => {
            let _ = ready.send(Err(format!("GetModuleHandle：{e}")));
            return;
        }
    };
    let class = w!("RecordS2TestWindow");
    let wc = WNDCLASSEXW { cbSize: std::mem::size_of::<WNDCLASSEXW>() as u32, lpfnWndProc: Some(wndproc), hInstance: hinstance.into(), lpszClassName: class, ..Default::default() };
    // 同一进程里第二次注册会失败（类已存在），不影响创建窗口
    unsafe { RegisterClassExW(&wc) };

    let t_ref = qpc.now_hns();
    let state = Box::new(State { spec: spec.clone(), qpc, t_ref });
    let ex = WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_LAYERED | WS_EX_TRANSPARENT;
    let hwnd = match unsafe {
        CreateWindowExW(ex, class, PCWSTR::null(), WS_POPUP, spec.left, spec.top, spec.width as i32, spec.height as i32, None, None, Some(hinstance.into()), Some(&*state as *const State as *const _))
    } {
        Ok(h) => h,
        Err(e) => {
            let _ = ready.send(Err(format!("CreateWindowEx：{e}")));
            return;
        }
    };
    unsafe {
        let _ = SetLayeredWindowAttributes(hwnd, COLORREF(0), 255, LWA_ALPHA);
        let _ = ShowWindow(hwnd, SW_SHOWNOACTIVATE);
        let _ = UpdateWindow(hwnd);
    }
    let _ = ready.send(Ok((hwnd.0 as isize, t_ref)));

    let mut msg = MSG::default();
    'outer: loop {
        while unsafe { PeekMessageW(&mut msg, None, 0, 0, PM_REMOVE) }.as_bool() {
            if msg.message == WM_QUIT {
                break 'outer;
            }
            unsafe {
                let _ = TranslateMessage(&msg);
                DispatchMessageW(&msg);
            }
        }
        if stop.load(Ordering::Acquire) {
            unsafe {
                let _ = DestroyWindow(hwnd);
            }
            continue;
        }
        if state.spec.animate {
            unsafe {
                let _ = InvalidateRect(Some(hwnd), None, false);
                let _ = UpdateWindow(hwnd);
            }
        }
        thread::sleep(Duration::from_millis(4));
    }
    drop(state);
}

/// 屏幕上某点的实际颜色（GDI 读取的是 DWM 合成后的结果），用作独立于桌面复制的参照。
pub fn screen_pixel(x: i32, y: i32) -> [u8; 3] {
    unsafe {
        let hdc = GetDC(None);
        let c = GetPixel(hdc, x, y).0;
        ReleaseDC(None, hdc);
        [(c & 0xFF) as u8, (c >> 8 & 0xFF) as u8, (c >> 16 & 0xFF) as u8]
    }
}

impl TestWindow {
    /// 窗口当前在桌面上的实际位置：`(left, top, width, height)`，以及它所在显示器的 DPI。
    pub fn actual_rect(&self) -> ((i32, i32, i32, i32), u32) {
        let mut r = RECT::default();
        unsafe {
            let _ = GetWindowRect(self.hwnd(), &mut r);
            ((r.left, r.top, r.right - r.left, r.bottom - r.top), GetDpiForWindow(self.hwnd()))
        }
    }

    pub fn open(spec: TestWindowSpec, qpc: Qpc) -> Result<Self, String> {
        let stop = Arc::new(AtomicBool::new(false));
        let (tx, rx) = mpsc::channel();
        let (s, sp) = (Arc::clone(&stop), spec.clone());
        let thread = thread::Builder::new().name("test-window".into()).spawn(move || window_thread(sp, qpc, s, tx)).map_err(|e| e.to_string())?;
        let (hwnd, t_ref) = rx.recv().map_err(|_| "窗口线程提前退出".to_string())??;
        Ok(Self { hwnd, spec, t_ref, stop, thread: Some(thread) })
    }

    pub fn hwnd(&self) -> HWND {
        HWND(self.hwnd as *mut _)
    }

    pub fn close(mut self) {
        self.shutdown();
    }

    fn shutdown(&mut self) {
        self.stop.store(true, Ordering::Release);
        if let Some(t) = self.thread.take() {
            let _ = t.join();
        }
    }
}

impl Drop for TestWindow {
    fn drop(&mut self) {
        self.shutdown();
    }
}

//! 找不到时报错并列出查找过的位置，不去 PATH 里碰运气（避免悄悄用上带 GPL 组件的别的 ffmpeg）。

use crate::MuxError;
use std::env;
use std::path::{Path, PathBuf};

pub const ENV_VAR: &str = "RECORD_FFMPEG";

pub fn find_ffmpeg() -> Result<PathBuf, MuxError> {
    let exe_dir = env::current_exe().ok().and_then(|p| p.parent().map(Path::to_path_buf));
    let cwd = env::current_dir().ok();
    find_ffmpeg_in(env::var_os(ENV_VAR).map(PathBuf::from), exe_dir.as_deref(), cwd.as_deref())
}

pub fn find_ffmpeg_in(env_value: Option<PathBuf>, exe_dir: Option<&Path>, cwd: Option<&Path>) -> Result<PathBuf, MuxError> {
    let mut tried: Vec<String> = Vec::new();
    let check = |p: PathBuf, tried: &mut Vec<String>| -> Option<PathBuf> {
        if p.is_file() {
            Some(p)
        } else {
            tried.push(p.display().to_string());
            None
        }
    };

    if let Some(p) = env_value
        && let Some(found) = check(p, &mut tried)
    {
        return Ok(found);
    }
    if let Some(dir) = exe_dir
        && let Some(found) = check(dir.join("ffmpeg.exe"), &mut tried)
    {
        return Ok(found);
    }
    for start in [exe_dir, cwd].into_iter().flatten() {
        for dir in start.ancestors() {
            let candidate = dir.join("vendor").join("ffmpeg").join("bin").join("ffmpeg.exe");
            if candidate.is_file() {
                return Ok(candidate);
            }
        }
        tried.push(format!("{}\\…\\vendor\\ffmpeg\\bin\\ffmpeg.exe", start.display()));
    }
    Err(MuxError::NotFound(tried.join("；")))
}

/// 与 ffmpeg 放在一起的 ffprobe（仅测试与诊断工具使用）。
pub fn ffprobe_for(ffmpeg: &Path) -> PathBuf {

//! 极简参数解析：`--key value`、`--key=value`、`--flag`，其余是位置参数。不引入 clap，工具程序用不着。

use std::collections::{HashMap, HashSet};
use std::str::FromStr;

#[derive(Debug, Default)]
pub struct Args {
    pub pos: Vec<String>,
    opts: HashMap<String, String>,
    flags: HashSet<String>,
}

impl Args {
    pub fn parse(items: impl IntoIterator<Item = String>) -> Self {
        let mut a = Args::default();
        let mut it = items.into_iter().peekable();
        while let Some(item) = it.next() {
            let Some(key) = item.strip_prefix("--") else {
                a.pos.push(item);
                continue;
            };
            if let Some((k, v)) = key.split_once('=') {
                a.opts.insert(k.to_string(), v.to_string());
            } else if it.peek().is_some_and(|n| !n.starts_with("--")) {
                a.opts.insert(key.to_string(), it.next().unwrap());
            } else {
                a.flags.insert(key.to_string());
            }
        }
        a
    }

    pub fn get(&self, key: &str) -> Option<&str> {
        self.opts.get(key).map(String::as_str)
    }

    pub fn flag(&self, key: &str) -> bool {
        self.flags.contains(key)
    }

    pub fn num<T: FromStr>(&self, key: &str, default: T) -> anyhow::Result<T> {
        match self.get(key) {
            None => Ok(default),
            Some(v) => v.parse().map_err(|_| anyhow::anyhow!("参数 --{key} 的值“{v}”不是有效的数字")),
        }
    }
}
```

//! 最小的 WAV 读写（32 位浮点），只供 S1 / S3 的采集与分析使用，不依赖 ffmpeg。

use std::fs::File;
use std::io::{self, BufWriter, Read, Seek, SeekFrom, Write};
use std::path::Path;

pub struct WavWriter {
    file: BufWriter<File>,
    frames: u64,
    channels: u16,
    rate: u32,
}

impl WavWriter {
    pub fn create(path: &Path, channels: u16, rate: u32) -> io::Result<Self> {
        let mut file = BufWriter::new(File::create(path)?);
        file.write_all(&header(channels, rate, 0))?;
        Ok(Self { file, frames: 0, channels, rate })
    }

    pub fn write(&mut self, samples: &[f32]) -> io::Result<()> {
        let mut buf = Vec::with_capacity(samples.len() * 4);
        for s in samples {
            buf.extend_from_slice(&s.to_le_bytes());
        }
        self.file.write_all(&buf)?;
        self.frames += (samples.len() / usize::from(self.channels)) as u64;
        Ok(())
    }

    /// 回填头部里的长度并关闭。
    pub fn finish(mut self) -> io::Result<u64> {
        self.file.flush()?;
        let mut f = self.file.into_inner().map_err(|e| e.into_error())?;
        f.seek(SeekFrom::Start(0))?;
        f.write_all(&header(self.channels, self.rate, self.frames))?;
        f.sync_all()?;
        Ok(self.frames)
    }
}

fn header(channels: u16, rate: u32, frames: u64) -> [u8; 44] {
    let data = (frames * u64::from(channels) * 4) as u32;
    let mut h = [0u8; 44];
    h[0..4].copy_from_slice(b"RIFF");
    h[4..8].copy_from_slice(&(36 + data).to_le_bytes());
    h[8..16].copy_from_slice(b"WAVEfmt ");
    h[16..20].copy_from_slice(&16u32.to_le_bytes());
    h[20..22].copy_from_slice(&3u16.to_le_bytes()); // IEEE float
    h[22..24].copy_from_slice(&channels.to_le_bytes());
    h[24..28].copy_from_slice(&rate.to_le_bytes());
    h[28..32].copy_from_slice(&(rate * u32::from(channels) * 4).to_le_bytes());
    h[32..34].copy_from_slice(&(channels * 4).to_le_bytes());
    h[34..36].copy_from_slice(&32u16.to_le_bytes());
    h[36..40].copy_from_slice(b"data");
    h[40..44].copy_from_slice(&data.to_le_bytes());
    h
}

pub struct Wav {
    pub channels: u16,
    pub rate: u32,
    pub samples: Vec<f32>,
}

impl Wav {
    pub fn frames(&self) -> usize {
        self.samples.len() / usize::from(self.channels)
    }

    /// 所有声道取平均得到单声道。
    pub fn mono(&self) -> Vec<f32> {
        let ch = usize::from(self.channels);
        self.samples.chunks_exact(ch).map(|f| f.iter().sum::<f32>() / ch as f32).collect()
    }
}

pub fn read(path: &Path) -> io::Result<Wav> {
    let mut b = Vec::new();
    File::open(path)?.read_to_end(&mut b)?;
    let bad = |m: &str| io::Error::new(io::ErrorKind::InvalidData, format!("{}：{m}", path.display()));
    if b.len() < 44 || &b[0..4] != b"RIFF" || &b[8..12] != b"WAVE" {
        return Err(bad("不是 WAV 文件"));
    }
    let (mut pos, mut fmt) = (12usize, None);
    while pos + 8 <= b.len() {
        let id = &b[pos..pos + 4];
        let size = u32::from_le_bytes(b[pos + 4..pos + 8].try_into().unwrap()) as usize;
        let body = pos + 8;
        match id {
            b"fmt " => {
                let tag = u16::from_le_bytes(b[body..body + 2].try_into().unwrap());
                let ch = u16::from_le_bytes(b[body + 2..body + 4].try_into().unwrap());
                let rate = u32::from_le_bytes(b[body + 4..body + 8].try_into().unwrap());
                let bits = u16::from_le_bytes(b[body + 14..body + 16].try_into().unwrap());
                if tag != 3 || bits != 32 {
                    return Err(bad("只支持 32 位浮点 WAV"));
                }
                fmt = Some((ch, rate));
            }
            b"data" => {
                let (channels, rate) = fmt.ok_or_else(|| bad("data 出现在 fmt 之前"))?;
                // 采集被强杀时头部长度可能没回填，按文件实际长度取
                let end = if size == 0 || body + size > b.len() { b.len() } else { body + size };
                let samples = b[body..end].chunks_exact(4).map(|c| f32::from_le_bytes([c[0], c[1], c[2], c[3]])).collect();
                return Ok(Wav { channels, rate, samples });
            }
            _ => {}
        }
        pos = body + size + (size & 1);
    }
    Err(bad("没有 data 块"))
}

//! 时间源比较（设计文档 5.5）：同一路设备的包，用“设备给的 QPC 时间戳”和“到达时间 − 包时长”
//! 各算一遍相对理想等间隔的残差，比较抖动与漂移，决定每一路用哪一种。

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Rec {
    pub device_ms: f64,
    pub arrival_ms: f64,
    pub frames: u32,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct SourceStats {
    /// 相邻包残差差分的标准差（毫秒），越小越稳。
    pub jitter_ms: f64,
    /// 残差随时间的斜率（百万分率）：相对 QPC 的时钟漂移。
    pub drift_ppm: f64,
}

#[derive(Debug, Clone, PartialEq)]
pub struct PacketStats {
    pub packets: usize,
    pub segments: usize,
    pub device: SourceStats,
    pub arrival: SourceStats,
}

/// 残差跳变超过这个值（毫秒）认为是断点（空闲、设备切换），在这里切段，每段单独算。
const BREAK_MS: f64 = 50.0;

pub fn analyze(recs: &[Rec], rate: u32) -> Option<PacketStats> {
    if recs.len() < 20 {
        return None;
    }
    let mut ideal = 0.0f64;
    let mut dev_res = Vec::with_capacity(recs.len());
    let mut arr_res = Vec::with_capacity(recs.len());
    for r in recs {
        let dur_ms = f64::from(r.frames) * 1000.0 / f64::from(rate);
        dev_res.push((r.device_ms - ideal, r.device_ms));
        arr_res.push((r.arrival_ms - dur_ms - ideal, r.device_ms));
        ideal += dur_ms;
    }
    let device = segmented(&dev_res);
    let arrival = segmented(&arr_res);
    Some(PacketStats { packets: recs.len(), segments: device.1.max(arrival.1), device: device.0, arrival: arrival.0 })
}

/// (时间残差, 横轴时间)：按跳变切段，取最长的一段拟合斜率，所有段的差分合起来算抖动。
fn segmented(res: &[(f64, f64)]) -> (SourceStats, usize) {
    let mut segs: Vec<&[(f64, f64)]> = Vec::new();
    let mut start = 0;
    for i in 1..res.len() {
        if (res[i].0 - res[i - 1].0).abs() > BREAK_MS {
            segs.push(&res[start..i]);
            start = i;
        }
    }
    segs.push(&res[start..]);
    let diffs: Vec<f64> = segs.iter().flat_map(|s| s.windows(2).map(|w| w[1].0 - w[0].0)).collect();
    let mean = diffs.iter().sum::<f64>() / diffs.len().max(1) as f64;
    let jitter = (diffs.iter().map(|d| (d - mean).powi(2)).sum::<f64>() / diffs.len().max(1) as f64).sqrt();
    let longest = segs.iter().max_by_key(|s| s.len()).unwrap();
    // 斜率的单位是 毫秒/毫秒，乘 1e6 即百万分率
    (SourceStats { jitter_ms: jitter, drift_ppm: slope(longest) * 1e6 }, segs.len())
}

/// 最小二乘斜率（残差毫秒 / 时间毫秒）。
fn slope(seg: &[(f64, f64)]) -> f64 {
    let n = seg.len() as f64;
    let (mx, my) = (seg.iter().map(|p| p.1).sum::<f64>() / n, seg.iter().map(|p| p.0).sum::<f64>() / n);
    let (mut sxx, mut sxy) = (0.0, 0.0);
    for &(y, x) in seg {
        sxx += (x - mx) * (x - mx);
        sxy += (x - mx) * (y - my);
    }
    if sxx == 0.0 { 0.0 } else { sxy / sxx }
}

pub fn parse_csv(text: &str) -> Vec<Rec> {
    text.lines()
        .skip(1)
        .filter_map(|l| {
            let f: Vec<&str> = l.split(',').collect();
            Some(Rec { device_ms: f.first()?.parse().ok()?, arrival_ms: f.get(1)?.parse().ok()?, frames: f.get(2)?.parse().ok()? })
        })
        .collect()
}

/// 周期性的短促正弦脉冲（两端 5 ms 淡入淡出）。每个脉冲播完时 `completed` 加一。
pub fn beep_generator(spec: BeepSpec, channels: u16, completed: Arc<AtomicU32>) -> impl FnMut(&mut [f32]) + Send + 'static {
    let mut n: u64 = 0;
    let mut in_burst = false;
    move |buf: &mut [f32]| {
        for frame in buf.chunks_exact_mut(usize::from(channels)) {
            let t = n as f64 / f64::from(RATE);
            n += 1;
            let mut v = 0.0f32;
            if t >= spec.lead_s {
                let p = (t - spec.lead_s) % spec.interval_s;
                if p < spec.burst_s {
                    let env = (p / 0.005).min(1.0).min(((spec.burst_s - p) / 0.005).min(1.0)) as f32;
                    v = spec.amp * env * (2.0 * PI * spec.freq * p).sin() as f32;
                    in_burst = true;
                } else if in_burst {
                    in_burst = false;
                    completed.fetch_add(1, Ordering::Relaxed);
                }
            }
            frame.fill(v);
        }
    }
}

    /// 返回设备时间戳相对到达时间的中位数（毫秒）。
    csv: JoinHandle<Option<f64>>,
    is_system: bool,
}

pub struct TrackOutcome {
    pub label: String,
    pub file: PathBuf,
    pub frames: u64,
    pub result: SourceResult,
    /// 设备时间戳 − 到达时间 的中位数（毫秒）。回环是播放延迟（正值，设备缓冲越大越大），麦克风是采集缓冲（负值）。
    pub lag_ms: Option<f64>,
}

pub struct CaptureOutcome {
    pub tracks: Vec<TrackOutcome>,
    pub watchdog_alerts: u32,
    pub beeps_completed: u32,
    pub events: Vec<String>,
}

fn csv_writer(path: PathBuf, rx: Receiver<PacketRecord>) -> JoinHandle<Option<f64>> {
    thread::spawn(move || {
        let mut f = fs::File::create(&path).ok()?;
        let _ = writeln!(f, "device_ms,arrival_ms,frames,flags");
        let mut lags: Vec<i64> = Vec::new();
        for r in rx {
            lags.push(r.device_qpc - r.arrival_qpc);
            let flags = u8::from(r.flags.silent) | (u8::from(r.flags.timestamp_error) << 1) | (u8::from(r.flags.discontinuity) << 2);
            let _ = writeln!(f, "{:.3},{:.3},{},{}", r.device_qpc as f64 / 10_000.0, r.arrival_qpc as f64 / 10_000.0, r.frames, flags);
        }
        lags.sort_unstable();
        lags.get(lags.len() / 2).map(|&l| l as f64 / 10_000.0)
    })
}

fn describe(e: &AudioEvent) -> String {
    match e {
        AudioEvent::Opened { label, device, .. } => format!("[{label}] 已打开：{}", device.name),
        AudioEvent::OpenFailed { label, error } => format!("[{label}] 打开失败：{error}"),
        AudioEvent::DeviceChanged { label, from, to } => format!("[{label}] 默认设备变化：{from} → {to}"),
        AudioEvent::StreamLost { label, error } => format!("[{label}] 流中断：{error}"),
        AudioEvent::Interrupted { label } => format!("[{label}] 超过 10 秒未恢复，标记中断"),
        AudioEvent::Recovered { label } => format!("[{label}] 已恢复"),
        AudioEvent::LargeGap { label, filled_ms } => format!("[{label}] 单次补静音 {filled_ms} ms（large_gap）"),
    }
}

pub fn run_capture(o: &CaptureOpts) -> Result<CaptureOutcome> {
    fs::create_dir_all(&o.out_dir).with_context(|| format!("创建目录 {}", o.out_dir.display()))?;
    let _com = ComGuard::init()?;
    let en = devices::enumerator()?;
    let qpc = Qpc::new();
    let cfg = Config::default();
    let (ev_tx, ev_rx) = unbounded::<AudioEvent>();
    let mut running: Vec<Running> = Vec::new();

    let mut start = |label: String, kind: Kind, endpoint: Endpoint, channels: u16, ts: TimeSource, keepalive: bool, is_system: bool| -> Result<()> {
        let file = o.out_dir.join(format!("{label}.wav"));
        let writer = WavWriter::create(&file, channels, RATE)?;
        let (wav_tx, wav_rx) = unbounded::<Vec<f32>>();
        let wav_join = thread::spawn(move || {
            let mut w = writer;
            for chunk in wav_rx {
                w.write(&chunk)?;
            }
            w.finish()
        });
        let (ptx, prx) = unbounded();
        let csv = csv_writer(o.out_dir.join(format!("packets_{label}.csv")), prx);
        let mut sc = SourceConfig::new(label.clone(), kind, endpoint, cfg.timeline_config(AudioFormat { rate: RATE, channels }, ts));
        sc.keepalive = keepalive;
        sc.packet_tap = Some(ptx);
        let sink_tx = wav_tx.clone();
        let src = AudioSource::start(
            sc,
            qpc,
            ev_tx.clone(),
            Box::new(move |s| {
                let _ = sink_tx.send(s.to_vec());
            }),
        )?;
        running.push(Running { label, file, wav_tx, wav_join, src, csv, is_system });
        Ok(())
    };

    match &o.system {
        SystemSel::None => {}
        SystemSel::Default(role) => start("system".into(), Kind::Loopback, Endpoint::Default(*role), 2, o.system_time, o.keepalive, true)?,
        SystemSel::Id(id) => start("system".into(), Kind::Loopback, Endpoint::Id(id.clone()), 2, o.system_time, o.keepalive, true)?,
        SystemSel::All => {
            for (n, d) in devices::active_endpoints(&en, Flow::Render)?.iter().enumerate() {
                let i = devices::info(d)?;
                println!("回环 #{n}：{}", i.name);
                start(format!("system_{n}"), Kind::Loopback, Endpoint::Id(i.id), 2, o.system_time, o.keepalive, true)?;
            }
        }
    }
    match &o.mic {
        MicSel::None => {}
        MicSel::Default(role) => start("mic".into(), Kind::Mic, Endpoint::Default(*role), 1, o.mic_time, false, false)?,
        MicSel::Id(id) => start("mic".into(), Kind::Mic, Endpoint::Id(id.clone()), 1, o.mic_time, false, false)?,
    }
    if running.is_empty() {
        bail!("没有选择任何采集源");
    }

    let meters = RenderMeters::open_all(&en)?;
    let mut wd = SilenceWatchdog::new(WatchdogConfig::default());
    let mut events: Vec<String> = Vec::new();
    let mut alerts = 0u32;
    let completed = Arc::new(AtomicU32::new(0));
    let mut player: Option<RenderPlayer> = None;
    let drain = |events: &mut Vec<String>| {
        while let Ok(e) = ev_rx.try_recv() {
            let s = describe(&e);
            println!("  {s}");
            events.push(s);
        }
    };

    // 先采集 1 秒再开始播放，保证每个脉冲都落在采集窗口里
    thread::sleep(Duration::from_secs(1));
    if let Some(spec) = o.play {
        player = Some(RenderPlayer::start(None, Role::Console, RATE, 2, beep_generator(spec, 2, Arc::clone(&completed))).map_err(anyhow::Error::msg)?);
    }
    for sec in 1..=o.secs {
        thread::sleep(Duration::from_secs(1));
        let sys_peak = running.iter().filter(|r| r.is_system).map(|r| r.src.live().take_peak()).fold(0.0f32, f32::max);
        let mic_peak = running.iter().filter(|r| !r.is_system).map(|r| r.src.live().take_peak()).fold(0.0f32, f32::max);
        let meter = meters.max_peak();
        if let Some(ev) = wd.tick(meter, sys_peak, true) {
            let who = meters.loudest().map(|(n, p)| format!("{n}（电平 {p:.2}）")).unwrap_or_default();
            let line = match ev {
                WatchdogEvent::Alert => {
                    alerts += 1;
                    format!("！静默失效告警：播放设备有声而系统音轨连续静音 —— {who}")
                }
                WatchdogEvent::Recovered => "静默失效已恢复".to_string(),
            };
            println!("  [{sec:>3}s] {line}");
            events.push(line);
        }
        if o.verbose {
            println!("  [{sec:>3}s] 端点电平 {:.3}  系统音轨 {sys_peak:.3}  麦克风轨 {mic_peak:.3}", meter.unwrap_or(-1.0));
        }
        drain(&mut events);
    }
    if let Some(p) = player.take() {
        p.stop();
    }
    thread::sleep(Duration::from_secs(1));

    let mut tracks = Vec::new();
    for r in running {
        let result = r.src.stop(); // 采集线程结束后，它持有的发送端随之释放
        drop(r.wav_tx); // 关掉最后一个发送端，写盘线程收尾
        let frames = r.wav_join.join().map_err(|_| anyhow::anyhow!("WAV 写盘线程崩溃"))??;
        let lag_ms = r.csv.join().ok().flatten();
        tracks.push(TrackOutcome { label: r.label, file: r.file, frames, result, lag_ms });
    }
    drain(&mut events);
    Ok(CaptureOutcome { tracks, watchdog_alerts: alerts, beeps_completed: completed.load(Ordering::Relaxed), events })
}

pub fn outcome_json(o: &CaptureOutcome) -> serde_json::Value {
    serde_json::json!({
        "watchdog_alerts": o.watchdog_alerts,
        "beeps_completed": o.beeps_completed,
        "events": o.events,
        "tracks": o.tracks.iter().map(|t| serde_json::json!({
            "label": t.label,
            "file": t.file.display().to_string(),
            "frames": t.frames,
            "seconds": t.frames as f64 / f64::from(RATE),
            "anchor_ms": t.result.anchor as f64 / 10_000.0,

            "device_changes": t.result.device_changes,
            "reconnects": t.result.reconnects,
            "timeline": t.result.stats,
        })).collect::<Vec<_>>(),
    })
}

pub fn opts_from_args(a: &Args) -> Result<CaptureOpts> {
    let system = match a.get("system").unwrap_or("console") {

pub struct BeepAnalysis {
    pub bursts: Vec<Burst>,
    pub spacing: Option<Spacing>,
    pub seconds: f64,
    pub peak: f32,
    /// 测试音开始前，同一频率上已有的环境声音电平。接近检测阈值时，检测结果不可信。
    pub baseline: f64,
}

/// 采集比测试音早 1 秒开始，测试音的第一个脉冲在开始播放后 `lead_s` 秒：这之前的内容都是环境声音。
pub fn analyze_file(path: &Path, spec: &BeepSpec) -> Result<BeepAnalysis> {
    let w = wav::read(path)?;
    let mono = w.mono();
    let peak = mono.iter().fold(0.0f32, |m, s| m.max(s.abs()));
    let threshold = f64::from(spec.amp) * 0.5;
    let quiet_end = ((1.0 + spec.lead_s - 0.2) * f64::from(w.rate)) as usize;
    let win = (w.rate / 100) as usize;
    let baseline = (0..quiet_end.min(mono.len()).saturating_sub(win)).step_by(win).map(|i| record_core::dsp::tone_level(&mono[i..i + win], spec.freq, w.rate)).fold(0.0, f64::max);
    let bursts = detect_bursts(&mono, w.rate, spec.freq, threshold);
    Ok(BeepAnalysis { spacing: spacing(&bursts, spec.interval_s), bursts, seconds: w.frames() as f64 / f64::from(w.rate), peak, baseline })
}

/// 逐 100 ms 打印指定频率上的最大电平，用来直接看一条录音里测试音到底在不在。
pub fn levels_cmd(a: &Args) -> Result<()> {
    let file = a.pos.get(2).context("用法：s1 levels <wav 文件> [--freq 16000] [--from 0] [--to 8]")?;
    let freq: f64 = a.num("freq", BeepSpec::default().freq)?;
    let w = wav::read(Path::new(file))?;
    let mono = w.mono();
    let win = (w.rate / 100) as usize;
    let (from, to): (f64, f64) = (a.num("from", 0.0)?, a.num("to", mono.len() as f64 / f64::from(w.rate))?);
    let step = (w.rate / 10) as usize;
    let mut t = from;
    while t < to {
        let start = (t * f64::from(w.rate)) as usize;
        let end = (start + step).min(mono.len());
        let level = (start..end.saturating_sub(win)).step_by(win / 2).map(|i| record_core::dsp::tone_level(&mono[i..i + win], freq, w.rate)).fold(0.0, f64::max);
        let peak = mono[start.min(mono.len())..end].iter().fold(0.0f32, |m, s| m.max(s.abs()));
        println!("{t:>6.1}s  {freq:.0} Hz 电平 {level:.4}  采样峰值 {peak:.3}");
        t += 0.1;
    }
    Ok(())
}

pub fn analyze_cmd(a: &Args) -> Result<()> {
    let file = a.pos.get(2).context("用法：s1 analyze <wav 文件> [--interval 1.0] [--freq 16000]")?;

    let r = analyze_file(Path::new(file), &spec)?;

    }
    Ok(())
}

            s.packets, s.segments, s.device.jitter_ms, s.device.drift_ppm, s.arrival.jitter_ms, s.arrival.drift_ppm

    }

}

//! 回环链路的频率响应检查：播放一个已知的测试音，用回环采回来，比较电平。
//!
//! 为什么需要它：录下来的系统声音如果在高频被悄悄砍掉，会议录音会发闷，而脉冲计数、时间线统计都发现不了。
//! 本检查还能把播放流和采集流各自是否经过重采样隔离开（`--play-rate` / `--cap-rate` 设成设备混音格式的采样率就不重采样），
//! 并能验证“同时打开麦克风是否改变播放端点”（`--with-mic`）：某些 USB/蓝牙耳麦一开麦克风就切到窄带通话模式。

use crate::args::Args;
use crate::s1::{BeepSpec, beep_generator};
use anyhow::{Context, Result, bail};
use crossbeam_channel::unbounded;
use record_capture::audio::{AudioEvent, AudioSource, Endpoint, Kind, SourceConfig};
use record_capture::com::ComGuard;
use record_capture::devices::{self, Flow, MixFormat, Role};
use record_capture::qpc::Qpc;
use record_capture::render::RenderPlayer;
use record_core::config::Config;
use record_core::dsp::tone_level;
use record_core::timeline::{AudioFormat, TimeSource};
use std::f64::consts::PI;
use std::sync::atomic::AtomicU32;
use std::sync::{Arc, Mutex};
use std::thread;
use std::time::Duration;

pub struct Setup {
    pub freq: f64,
    pub play_rate: u32,
    pub cap_rate: u32,
    pub amp: f32,
    /// 用自检同款的脉冲，而不是连续音。
    pub burst: bool,
    /// 同时打开默认通信麦克风。
    pub with_mic: bool,
}

pub struct Measured {
    /// 测得的最大振幅（0..1）。回环取数字信号，与音箱音量无关。
    pub level: f64,
    /// 测量时默认播放端点的混音格式。
    pub render_mix: MixFormat,
}

/// 在默认播放设备上播放 `freq` Hz 的测试音，用回环流采回来。
pub fn measure(s: &Setup) -> Result<Measured> {
    let qpc = Qpc::new();
    let cfg = Config::default();
    let (ev_tx, ev_rx) = unbounded::<AudioEvent>();
    let samples = Arc::new(Mutex::new(Vec::<f32>::new()));

    let mic = if s.with_mic {
        let sc = SourceConfig::new("mic", Kind::Mic, Endpoint::Default(Role::Communications), cfg.timeline_config(AudioFormat { rate: 48_000, channels: 1 }, TimeSource::DeviceQpc));
        Some(AudioSource::start(sc, qpc, ev_tx.clone(), Box::new(|_| {}))?)
    } else {
        None
    };

    let mut sc = SourceConfig::new("response", Kind::Loopback, Endpoint::Default(Role::Console), cfg.timeline_config(AudioFormat { rate: s.cap_rate, channels: 2 }, TimeSource::DeviceQpc));
    sc.keepalive = true; // 保证没有声音的间隙里也持续出包
    let sink = Arc::clone(&samples);
    let src = AudioSource::start(sc, qpc, ev_tx, Box::new(move |d| sink.lock().unwrap().extend_from_slice(d)))?;

    // 等流打开（打开失败会作为事件报告）
    thread::sleep(Duration::from_millis(1_000));
    if let Some(AudioEvent::OpenFailed { label, error }) = ev_rx.try_iter().find(|e| matches!(e, AudioEvent::OpenFailed { .. })) {
        src.stop();
        bail!("[{label}] 打开失败：{error}");
    }
    let render_mix = {
        let en = devices::enumerator()?;
        devices::mix_format(&devices::default_endpoint(&en, Flow::Render, Role::Console)?)?
    };

    let (freq, amp, play_rate) = (s.freq, s.amp, s.play_rate);
    let player = if s.burst {
        let spec = BeepSpec { freq, amp, ..Default::default() };
        RenderPlayer::start(None, Role::Console, play_rate, 2, beep_generator(spec, 2, Arc::new(AtomicU32::new(0))))
    } else {
        let mut n = 0u64;
        RenderPlayer::start(None, Role::Console, play_rate, 2, move |buf: &mut [f32]| {
            for frame in buf.chunks_exact_mut(2) {
                frame.fill(amp * (2.0 * PI * freq * n as f64 / f64::from(play_rate)).sin() as f32);
                n += 1;
            }
        })
    }
    .map_err(anyhow::Error::msg)?;
    thread::sleep(Duration::from_millis(if s.burst { 3_000 } else { 1_500 }));
    player.stop();
    thread::sleep(Duration::from_millis(200));
    src.stop();
    if let Some(m) = mic {
        m.stop();
    }

    let all = samples.lock().unwrap();
    let mono: Vec<f32> = all.chunks_exact(2).map(|f| (f[0] + f[1]) * 0.5).collect();
    let win = (s.cap_rate / 100) as usize;
    let level = mono.chunks_exact(win).map(|w| tone_level(w, freq, s.cap_rate)).fold(0.0, f64::max);
    Ok(Measured { level, render_mix })
}

pub fn response_cmd(a: &Args) -> Result<()> {

    let _com = ComGuard::init()?;
    println!(
        "播放 {} Hz → 回环采集 {} Hz（振幅 {}，{}，{}麦克风）",
        base.play_rate,
        base.cap_rate,
        base.amp,
        if base.burst { "脉冲" } else { "连续音" },
        if base.with_mic { "同时开" } else { "不开" }
    );
    for f in freqs {
        let m = measure(&Setup { freq: f, ..base })?;
        let db = 20.0 * (m.level / f64::from(base.amp)).max(1e-6).log10();
        println!("  {f:>7.0} Hz：电平 {:.4}  相对播放振幅 {db:+.1} dB   （播放端点混音格式 {} Hz {} 声道）", m.level, m.render_mix.rate, m.render_mix.channels);
    }
    Ok(())
}

//!
//! 三个场景（`--only` 选其一）：
//! - `plain`：只录回环，不开保活流、不开麦克风。回环没有声音时不出包，考验空闲补齐；
//! - `keepalive`：只录回环，开保活流；
//! - `with-mic`：保活流 + 默认通信麦克风同时录——这才是真实的会议场景。
//!
//! 测试音：前两个场景用 16 kHz（几乎听不见，环境声音也很少在这个频段）。但有的耳麦一开麦克风就把播放带宽压到
//! 8 kHz 以下（本机实测：8 kHz −26 dB，16 kHz 消失，API 却报告端点格式没变），所以 `with-mic` 场景用 6 kHz（开麦克风时 5 kHz +0.1 dB、6 kHz −1.2 dB、7 kHz −3.8 dB；`--mic-freq` 调整）。

use crate::args::Args;
use crate::s1::{BeepSpec, CaptureOpts, MicSel, RATE, SystemSel, analyze_file, beep_spec, check_beep_bandwidth, default_out_dir, outcome_json, run_capture};
use crate::wav;
use anyhow::{Context, Result, bail};
use record_capture::devices::Role;
use record_core::timeline::{TimeSource, TimelineStats};
use std::fs;
use std::path::PathBuf;

/// 从开始采集到首次启动成功的耗时上限。设计目标是热键到开始写入不超过 1 秒；只对一开始就该出包的轨检查（保活流开着，或者是麦克风）。
const MAX_LEAD_IN_S: f64 = 1.0;
/// 异常补静音（包间空档、中断）在单条轨上累计超过这个时长，或次数超过 `MAX_ANOMALY_EVENTS`，就认为是系统性问题。
/// 在它们以内只警告：桌面机器上偶发的几十毫秒卡顿，时间线本来就是为它们准备的。
const MAX_ANOMALY_S: f64 = 2.0;
const MAX_ANOMALY_EVENTS: u64 = 5;

struct Scenario {
    name: &'static str,
    keepalive: bool,
    mic: bool,
    freq: f64,
}

fn secs_of(frames: u64) -> f64 {
    frames as f64 / f64::from(RATE)
}

fn describe_timeline(st: &TimelineStats) -> String {
    format!(
        "{} 个包；首包前 {:.2} 秒；延迟增大 {:.2} 秒；空闲 {:.2} 秒（{} 段）；包间空档 {} 次共 {:.2} 秒；中断 {:.2} 秒；收尾 {:.3} 秒；丢弃 {} 帧；large_gap {}；时间戳回退 {}；包间隙 {} / 重叠 {}；不连续标志 {}",
        st.packets,
        secs_of(st.lead_in_frames),
        secs_of(st.latency_shift_frames),
        secs_of(st.idle_filled_frames),
        st.idle_episodes,
        st.fill_events,
        secs_of(st.gap_filled_frames),
        secs_of(st.outage_filled_frames),
        secs_of(st.tail_frames),
        st.dropped_frames,
        st.large_gaps,
        st.timestamp_fallbacks,
        st.pts_gaps,
        st.pts_overlaps,
        st.discontinuities
    )
}

/// 一条轨上的异常补静音帧数：包间空档 + 中断；麦克风不该停止出包，所以它的空闲也算异常。
fn anomaly_frames(label: &str, st: &TimelineStats) -> u64 {
    st.gap_filled_frames + st.outage_filled_frames + if label == "mic" { st.idle_filled_frames } else { 0 }
}

pub fn selftest_cmd(a: &Args) -> Result<()> {
    let secs = a.num("secs", 20u64)?;
    let spec = beep_spec(a)?;
    let mic_freq: f64 = a.num("mic-freq", 6_000.0)?;
    let mic_time = match a.get("mic-time").unwrap_or("device") {
        "device" => TimeSource::DeviceQpc,
        "arrival" => TimeSource::ArrivalMinusDuration,
        o => bail!("--mic-time 只能是 device 或 arrival，收到“{o}”"),
    };
    let all = [
        Scenario { name: "plain", keepalive: false, mic: false, freq: spec.freq },
        Scenario { name: "keepalive", keepalive: true, mic: false, freq: spec.freq },
        Scenario { name: "with-mic", keepalive: true, mic: true, freq: mic_freq },
    ];
    let chosen: Vec<&Scenario> = match a.get("only") {
        None => all.iter().collect(),
        Some(n) => vec![all.iter().find(|s| s.name == n).with_context(|| format!("--only 只能是 plain、keepalive 或 with-mic，收到“{n}”"))?],
    };
    for s in &chosen {
        check_beep_bandwidth(s.freq)?;
    }
    let base = a.get("out").map(PathBuf::from).unwrap_or_else(default_out_dir);
    let mut failed = Vec::new();

    for sc in chosen {
        let name = sc.name;
        let spec = BeepSpec { freq: sc.freq, ..spec };
        println!("\n=== 回环自检：{name}（保活流{}，麦克风{}，测试音 {:.0} Hz，{secs} 秒）===", if sc.keepalive { "开" } else { "关" }, if sc.mic { "开" } else { "关" }, sc.freq);
        let o = CaptureOpts {
            secs,
            out_dir: base.join(name),
            system: SystemSel::Default(Role::Console),
            mic: if sc.mic { MicSel::Default(Role::Communications) } else { MicSel::None },
            keepalive: sc.keepalive,
            system_time: TimeSource::DeviceQpc,
            mic_time,
            play: Some(spec),
            verbose: a.flag("verbose"),
        };
        let out = run_capture(&o)?;
        let sys = out.tracks.iter().find(|t| t.label == "system").context("没有系统音轨")?;
        let r = analyze_file(&sys.file, &spec)?;
        println!("系统音轨 {:.2} 秒（期望约 {} 秒），播放了 {} 个脉冲，检测到 {} 个，测试音频率上的环境电平 {:.4}", r.seconds, secs + 2, out.beeps_completed, r.bursts.len(), r.baseline);
        if r.baseline > f64::from(spec.amp) * 0.25 {
            failed.push(format!("{name}：环境声音在测试音频率上的电平 {:.4} 过高，检测结果不可信，请暂停其他播放后重试", r.baseline));
        }
        if let Some(s) = r.spacing {
            println!("脉冲间隔 {:.4} 秒，最大偏差 {:.1} ms，漂移 {:+.0} ppm", s.mean_interval_s, s.max_dev_ms, s.drift_ppm);
        }

        for t in &out.tracks {
            let st = &t.result.stats;
            println!("时间线[{}]：{}", t.label, describe_timeline(st));
            if let Some(lag) = t.lag_ms {
                println!("  设备时间戳 − 到达时间 = {lag:+.1} ms（回环是播放延迟，麦克风是采集缓冲）");
            }
            let anomaly = anomaly_frames(&t.label, st);
            let events = st.fill_events + st.outage_filled_frames.min(1);
            if secs_of(anomaly) > MAX_ANOMALY_S || events > MAX_ANOMALY_EVENTS {
                failed.push(format!("{name}：{} 轨异常补静音共 {:.2} 秒（{} 次），是系统性问题", t.label, secs_of(anomaly), events));
            } else if anomaly > 0 {
                println!(
                    "警告：{} 轨有 {:.2} 秒异常补静音（包间空档 {} 次，中断 {:.2} 秒），时间线已补齐，但说明设备或系统出现过卡顿",
                    t.label,
                    secs_of(anomaly),
                    st.fill_events,
                    secs_of(st.outage_filled_frames)
                );
            }
            // 没开保活流时，回环要等到有声音才出第一个包：“首包前”量到的是测试音自己的开始时间加上播放延迟，不是启动耗时，不在这里卡
            let packets_expected_at_once = sc.keepalive || t.label == "mic";
            if packets_expected_at_once && secs_of(st.lead_in_frames) > MAX_LEAD_IN_S {
                failed.push(format!("{name}：{} 轨从开始采集到首次启动成功用了 {:.2} 秒，超过 {MAX_LEAD_IN_S} 秒", t.label, secs_of(st.lead_in_frames)));
            }
        }
        if let Some(m) = out.tracks.iter().find(|t| t.label == "mic") {
            let mr = wav::read(&m.file)?;
            let peak = mr.samples.iter().fold(0.0f32, |a, s| a.max(s.abs()));
            println!("麦克风轨 {:.2} 秒，峰值 {:.4}（只验证能打开并持续出数据）", secs_of(m.frames), peak);
            if m.frames < (secs + 1) * u64::from(RATE) {
                failed.push(format!("{name}：麦克风轨过短"));
            }
        }

        match (r.bursts.len() as u32).cmp(&out.beeps_completed) {
            std::cmp::Ordering::Less => failed.push(format!("{name}：播放 {} 个脉冲，只检测到 {} 个（漏录）", out.beeps_completed, r.bursts.len())),
            std::cmp::Ordering::Greater => {
                failed.push(format!("{name}：播放 {} 个脉冲，却检测到 {} 个：测试音频率上混入了环境声音，结果不可信，请暂停其他播放后重试", out.beeps_completed, r.bursts.len()))
            }
            std::cmp::Ordering::Equal => {}
        }
        match r.spacing {
            Some(s) if s.max_dev_ms > 25.0 => failed.push(format!("{name}：脉冲间隔最大偏差 {:.1} ms 超过 25 ms（时间线有空档或压缩）", s.max_dev_ms)),
            None => failed.push(format!("{name}：脉冲太少，无法评估间隔")),
            _ => {}
        }
        // 回环包的设备时间戳是播放时刻，比读到它的时刻晚一个播放延迟，所以轨比采集时长长出这么多是正常的
        let latency_s = sys.lag_ms.unwrap_or(0.0).max(0.0) / 1000.0;
        let expected = (secs + 2) as f64;
        if r.seconds < expected - 0.3 || r.seconds > expected + latency_s + 0.3 {
            failed.push(format!("{name}：系统音轨时长 {:.2} 秒，应在 {:.2}–{:.2} 秒之间（采集 {expected} 秒，播放延迟 {latency_s:.2} 秒）", r.seconds, expected - 0.3, expected + latency_s + 0.3));
        }
        if out.watchdog_alerts > 0 {
            failed.push(format!("{name}：静默失效监测误报 {} 次", out.watchdog_alerts));
        }
        fs::write(o.out_dir.join("report.json"), serde_json::to_string_pretty(&outcome_json(&out))?)?;
    }

    if failed.is_empty() {
        println!("\n自检通过。");
        Ok(())
    } else {
        for f in &failed {
            println!("未通过：{f}");
        }
        bail!("自检未通过（{} 项）", failed.len())
    }
}

//! NV12 帧的取样与分析：区域平均色、亮条定位。纯计算，S2/S3 的分析器共用。

use record_core::geometry::Rect;

/// 一帧 NV12：`w*h` 字节的 Y 平面，紧接着 `w*h/2` 字节的交错 UV 平面。
#[derive(Clone, Copy)]
pub struct Nv12<'a> {
    pub data: &'a [u8],
    pub w: usize,
    pub h: usize,
}

impl<'a> Nv12<'a> {
    pub fn new(data: &'a [u8], w: u32, h: u32) -> Self {
        let (w, h) = (w as usize, h as usize);
        assert_eq!(data.len(), w * h * 3 / 2, "NV12 帧大小与尺寸不符");
        Self { data, w, h }
    }

    pub fn y(&self, x: usize, y: usize) -> u8 {
        self.data[y * self.w + x]
    }

    pub fn uv(&self, x: usize, y: usize) -> (u8, u8) {
        let off = self.w * self.h + (y / 2) * self.w + (x / 2) * 2;
        (self.data[off], self.data[off + 1])
    }

    /// 矩形内的平均 Y、U、V。Y 逐像素取平均，U/V 按 2×2 采样的色度取平均。
    pub fn mean_yuv(&self, r: Rect) -> [f64; 3] {
        let (x1, y1) = ((r.right() as usize).min(self.w), (r.bottom() as usize).min(self.h));
        let (x0, y0) = ((r.x as usize).min(x1), (r.y as usize).min(y1));
        let (mut sy, mut ny) = (0u64, 0u64);
        for y in y0..y1 {
            for x in x0..x1 {
                sy += u64::from(self.y(x, y));
                ny += 1;
            }
        }
        let (mut su, mut sv, mut nc) = (0u64, 0u64, 0u64);
        for y in (y0 & !1..y1).step_by(2) {
            for x in (x0 & !1..x1).step_by(2) {
                let (u, v) = self.uv(x, y);
                su += u64::from(u);
                sv += u64::from(v);
                nc += 1;
            }
        }
        let avg = |s: u64, n: u64| if n == 0 { f64::NAN } else { s as f64 / n as f64 };
        [avg(sy, ny), avg(su, nc), avg(sv, nc)]
    }

    /// 裁出一块区域（位置和大小都取偶数），仍是紧凑的 NV12。
    pub fn crop(&self, r: Rect) -> (Vec<u8>, u32, u32) {
        let (x, y) = ((r.x as usize & !1).min(self.w), (r.y as usize & !1).min(self.h));
        let (w, h) = ((r.w as usize).min(self.w - x) & !1, (r.h as usize).min(self.h - y) & !1);
        let mut out = Vec::with_capacity(w * h * 3 / 2);
        for row in y..y + h {
            out.extend_from_slice(&self.data[row * self.w + x..row * self.w + x + w]);
        }
        for row in y / 2..(y + h) / 2 {
            let base = self.w * self.h + row * self.w + x;
            out.extend_from_slice(&self.data[base..base + w]);
        }
        (out, w as u32, h as u32)
    }

    /// 在条带的中间一行里找亮条：Y 超过 `threshold` 的最长连续段，返回 `(左边缘, 右边缘)`（右边缘不含）。
    pub fn find_bright_run(&self, strip: Rect, threshold: u8) -> Option<(usize, usize)> {
        let row = (strip.y + strip.h / 2) as usize;
        if row >= self.h {
            return None;
        }
        let (x0, x1) = (strip.x as usize, (strip.right() as usize).min(self.w));
        let (mut best, mut start): (Option<(usize, usize)>, Option<usize>) = (None, None);
        for x in x0..=x1 {
            let bright = x < x1 && self.y(x, row) > threshold;
            match (bright, start) {
                (true, None) => start = Some(x),
                (false, Some(s)) => {
                    if best.is_none_or(|(a, b)| x - s > b - a) {
                        best = Some((s, x));
                    }
                    start = None;
                }
                _ => {}
            }
        }
        best.filter(|(a, b)| b - a >= 2)
    }
}

/// 把矩形向内收缩 `fraction`（0..0.5）的边距，取样时避开边缘的缩放过渡。
pub fn shrink(r: Rect, fraction: f64) -> Rect {
    let (dx, dy) = ((f64::from(r.w) * fraction) as u32, (f64::from(r.h) * fraction) as u32);
    Rect { x: r.x + dx, y: r.y + dy, w: r.w.saturating_sub(2 * dx).max(1), h: r.h.saturating_sub(2 * dy).max(1) }
}
```

impl Probe {
    fn new(mon: &MonitorInfo, win: Rect, out: (u32, u32), t_ref: Hns, t0: Hns, fps: u32, animate: bool) -> Self {
        let layout = letterbox(mon.width, mon.height, out.0, out.1);
        let to_out = |r: Rect| map_to_output(r, mon.width, mon.height, layout);
        let at_window = |r: Rect| Rect { x: win.x + r.x, y: win.y + r.y, w: r.w, h: r.h };
        Self {
            win,
            quads_out: quadrants(win.w, win.h).map(|q| shrink(to_out(at_window(q)), 0.25)),
            strip_out: to_out(at_window(strip(win.w, win.h))),
            bars_out: bars(layout, out.0, out.1).into_iter().map(|r| shrink(r, 0.2)).collect(),
            pacer: FramePacer::new(fps, t0),
            t_ref,
            animate,
        }
    }

    fn measure(&self, f: &Nv12<'_>, index: u64) -> Measurement {
        let yuv = self.quads_out.map(|r| f.mean_yuv(r));
        let bars = self.bars_out.iter().map(|&r| f.mean_yuv(r)).collect();
        let mut m = Measurement { yuv, bars, bar_left: None, stale_ms: None };
        if self.animate
            && let Some((l, r)) = f.find_bright_run(self.strip_out, 128)
        {
            // 输出坐标 → 窗口坐标
            let scale = f64::from(self.strip_out.w) / f64::from(self.win.w);
            let center = ((l + r) as f64 / 2.0 - f64::from(self.strip_out.x)) / scale;
            let left = center - f64::from(bar_width(self.win.w)) / 2.0;
            let near = self.pacer.time_of(index);
            let drawn = time_of_phase(phase_of_bar(left, self.win.w), self.t_ref, near);
            m.bar_left = Some(left);
            m.stale_ms = Some((near - drawn) as f64 / 10_000.0);
        }
        m
    }
}

fn format_name(f: i32) -> &'static str {
    match f {
        87 => "B8G8R8A8_UNORM",
        88 => "B8G8R8X8_UNORM",
        28 => "R8G8B8A8_UNORM",
        24 => "R10G10B10A2_UNORM",
        10 => "R16G16B16A16_FLOAT",
        _ => "其它格式",
    }
}

fn percentile(sorted: &[f64], p: f64) -> f64 {
    sorted[(((sorted.len() - 1) as f64) * p).round() as usize]
}

fn default_dir(name: &str) -> std::path::PathBuf {
    std::env::temp_dir().join(name)
}

/// 排查用：对照“GDI 读到的屏幕实际颜色”和“桌面复制采到的颜色”，并把只含测试窗口的裁剪区域导出成 PNG。

    let (win_w, win_h) = parse_size(a.get("size").unwrap_or("960x540"))?;

    let mon = pick_from_args(a, &list)?;

    std::thread::sleep(Duration::from_millis(500));

    let (actual, dpi) = window.actual_rect();
    println!("窗口：期望 ({}, {}) {}×{}；实际 ({}, {}) {}×{}；窗口 DPI {}（96 = 100%）", mon.left + win.x as i32, mon.top + win.y as i32, win_w, win_h, actual.0, actual.1, actual.2, actual.3, dpi);

    // GDI 参照：各分区中心的实际颜色
    let mut gdi_ok = true;
    for (q, rect) in quadrants(win_w, win_h).into_iter().enumerate() {
        let (cx, cy) = rect.center();
        let got = record_capture::testwin::screen_pixel(mon.left + (win.x + cx) as i32, mon.top + (win.y + cy) as i32);
        let want = QUADRANT_RGB[q];
        let ok = got.iter().zip(want).all(|(g, w)| (i32::from(*g) - i32::from(w)).abs() <= 2);
        gdi_ok &= ok;
        println!("  GDI 分区 {q}：期望 RGB{want:?}，读到 RGB{got:?} {}", if ok { "✔" } else { "✘" });
    }

    // 采几帧
    let t0 = qpc.now_hns();
    let (event_tx, event_rx) = unbounded();
    let last = std::sync::Arc::new(std::sync::Mutex::new(None::<std::sync::Arc<[u8]>>));
    let sink_last = std::sync::Arc::clone(&last);
    let source = VideoSource::start(
        VideoConfig { monitor: mon.clone(), fps, out_w: out.0, out_h: out.1, t0, rebuild_interval: Duration::from_secs(1) },
        qpc,
        event_tx,
        Box::new(move |_, data, kind| {
            if kind == FrameKind::Fresh {
                *sink_last.lock().unwrap() = Some(data);
            }
        }),
    )?;
    std::thread::sleep(Duration::from_millis(1500));
    let result = source.stop();
    window.close();
    for e in event_rx.try_iter() {
        println!("  事件：{e:?}");
    }
    println!("桌面复制纹理格式：{}", result.src_format.map_or("未取到".to_string(), |f| format!("{}（{f}）", format_name(f))));
    let frame = last.lock().unwrap().take().context("没有采到新画面")?;

    let probe = Probe::new(&mon, win, out, 0, t0, fps, false);
    let nv = Nv12::new(&frame, out.0, out.1);
    let m = probe.measure(&nv, 0);
    for (q, rgb) in QUADRANT_RGB.iter().enumerate() {
        let want = expected_yuv(*rgb);
        println!("  采集 分区 {q}：期望 Y{:.0} U{:.0} V{:.0}；实测 Y{:.1} U{:.1} V{:.1}", want[0], want[1], want[2], m.yuv[q][0], m.yuv[q][1], m.yuv[q][2]);
    }

    if !gdi_ok {
        println!("GDI 没有在预期位置读到测试窗口的颜色，不导出裁剪图（避免写出用户屏幕上的其它内容）。");
        return Ok(());
    }
    let layout = letterbox(mon.width, mon.height, out.0, out.1);
    let region = map_to_output(win, mon.width, mon.height, layout);
    let (crop, cw, ch) = nv.crop(region);
    let raw = dir.join("crop.nv12");
    let png = dir.join("crop.png");
    std::fs::write(&raw, &crop)?;
    let ffmpeg = record_mux::locate::find_ffmpeg()?;
    let status = std::process::Command::new(&ffmpeg)
        .args(["-hide_banner", "-loglevel", "error", "-y", "-f", "rawvideo", "-pix_fmt", "nv12", "-s", &format!("{cw}x{ch}"), "-i"])
        .arg(&raw)
        .args(["-frames:v", "1"])
        .arg(&png)
        .status()?;
    let _ = std::fs::remove_file(&raw);
    if !status.success() {
        bail!("ffmpeg 转 PNG 失败：{status}");
    }
    println!("裁剪图（仅测试窗口区域 {cw}×{ch}）：{}", png.display());
    Ok(())
}

pub fn selftest_cmd(a: &Args) -> Result<()> {
    ensure_dpi_aware();
    let secs: u64 = a.num("secs", 8)?;
    let fps: u32 = a.num("fps", 15)?;
    let (win_w, win_h) = parse_size(a.get("size").unwrap_or("960x540"))?;
    let animate = !a.flag("static");
    let tolerance: f64 = a.num("tolerance", 6.0)?;

    let list = list_monitors()?;
    let mon = pick_from_args(a, &list)?;
    // 默认按显示器比例算输出尺寸；`--out WxH` 指定一个别的比例，用来验证黑边布局
    let out = match a.get("out") {
        Some(text) => {
            let (w, h) = parse_size(text)?;
            if w < 2 || h < 2 || w % 2 != 0 || h % 2 != 0 {
                bail!("--out 的宽高必须是不小于 2 的偶数，得到 {w}x{h}");
            }
            (w, h)
        }
        None => output_size(mon.width, mon.height, 1920, 1080),
    };
    println!("显示器：{}", mon.describe());
    println!("输出：{}×{}，{} fps，测试窗口 {}×{}（{}），时长 {} 秒", out.0, out.1, fps, win_w, win_h, if animate { "亮条移动" } else { "静止" }, secs);
    if win_w > mon.width || win_h > mon.height {
        bail!("测试窗口 {win_w}×{win_h} 比显示器 {}×{} 还大", mon.width, mon.height);
    }

    let qpc = Qpc::new();
    let win = Rect { x: (mon.width - win_w) / 2, y: (mon.height - win_h) / 2, w: win_w, h: win_h };
    let window = TestWindow::open(TestWindowSpec { left: mon.left + win.x as i32, top: mon.top + win.y as i32, width: win_w, height: win_h, animate }, qpc)
        .map_err(anyhow::Error::msg)
        .context("创建测试窗口")?;
    std::thread::sleep(Duration::from_millis(400)); // 让窗口先画出来、桌面稳定下来

    let t0 = qpc.now_hns();
    let probe = Probe::new(&mon, win, out, window.t_ref, t0, fps, animate);
    let (frame_tx, frame_rx) = unbounded::<(u64, FrameKind, Option<std::sync::Arc<[u8]>>)>();
    let (event_tx, event_rx) = unbounded();
    let (out_w, out_h) = out;
    println!("\n── 事件（时刻相对采集启动）──");
    let started = std::time::Instant::now();
    let printer = std::thread::spawn(move || {
        for e in event_rx {
            println!("  [+{:.2}s] {e:?}", started.elapsed().as_secs_f64());
        }
    });
    let analyzer = std::thread::spawn(move || {
        let (mut seen, mut measures) = (Vec::new(), Vec::new());
        for (index, kind, data) in frame_rx {
            seen.push((index, kind));
            if let Some(data) = data {
                measures.push(probe.measure(&Nv12::new(&data, out_w, out_h), index));
            }
        }
        (seen, measures)
    });
    let source = VideoSource::start(
        VideoConfig { monitor: mon.clone(), fps, out_w: out.0, out_h: out.1, t0, rebuild_interval: Duration::from_secs(1) },
        qpc,
        event_tx,
        Box::new(move |index, data, kind| {
            let _ = frame_tx.send((index, kind, (kind == FrameKind::Fresh).then_some(data)));
        }),
    )
    .context("启动画面采集")?;

    std::thread::sleep(Duration::from_secs(secs));
    let result = source.stop();
    window.close();
    let (seen, measures) = analyzer.join().expect("分析线程");
    printer.join().expect("事件打印线程");

    let mut problems: Vec<String> = Vec::new();
    let st = &result.stats;
    println!("\n── 帧统计 ──");
    println!("桌面复制给出的纹理格式：{}", result.src_format.map_or("未取到".to_string(), |f| format!("{}（{f}）", format_name(f))));
    println!(
        "共交付 {} 帧：新画面 {}；无变化重复 {}；安全桌面 {}；重建中 {}；重建失败 {}；落后补帧 {}",
        seen.len(),
        st.fresh,
        st.repeat_no_change,
        st.repeat_secure_desktop,
        st.repeat_duplication_rebuild,
        st.repeat_duplication_failed,
        st.catch_up
    );
    println!(
        "首帧 {} ms；失效 {} 次；重建 {} 次；断开累计 {} ms；取帧耗时（含 GPU 转换与回读）p50 {:.1} ms，p95 {:.1} ms，p99 {:.1} ms，最大 {:.1} ms（{} 次）",
        result.first_frame_ms.map_or("无".to_string(), |v| v.to_string()),
        result.lost,
        result.rebuilds,
        result.down_ms,
        f64::from(result.grab.p50_us) / 1000.0,
        f64::from(result.grab.p95_us) / 1000.0,
        f64::from(result.grab.p99_us) / 1000.0,
        f64::from(result.grab.max_us) / 1000.0,
        result.grab.count
    );
    if seen.is_empty() {
        bail!("没有采集到任何帧");
    }

    // 帧序号必须连续，每个到期的帧恰好交付一次
    let (first, last) = (seen.first().unwrap().0, seen.last().unwrap().0);
    let ordered = seen.windows(2).all(|w| w[1].0 == w[0].0 + 1);
    println!("帧序号 {first}..={last}，{}", if ordered { "连续，无空缺无重复" } else { "不连续" });
    if !ordered {
        problems.push("帧序号不连续".into());
    }
    let expected = (secs * u64::from(fps)) as f64;
    if (seen.len() as f64) < expected * 0.9 {
        problems.push(format!("交付 {} 帧，少于期望的 {expected} 帧的 90%", seen.len()));
    }
    if animate && (st.fresh as f64) < seen.len() as f64 * 0.8 {
        problems.push(format!("亮条一直在动，新画面却只有 {}/{} 帧", st.fresh, seen.len()));
    }
    if result.first_frame_ms.is_none_or(|v| v > 1000) {
        problems.push(format!("首帧过慢或没有：{:?} ms", result.first_frame_ms));
    }
    if result.lost > 0 || result.down_ms > 0 {
        problems.push(format!("录制中管线断开过：失效 {} 次，累计 {} ms", result.lost, result.down_ms));
    }

    println!("\n── 颜色（BT.709 有限范围，容差 ±{tolerance}）──");
    if measures.is_empty() {
        problems.push("没有可分析的新画面".into());
    } else {
        let names = ["左上 红", "右上 绿", "左下 蓝", "右下 白"];
        let mut worst_all = 0.0f64;
        for q in 0..4 {
            let want = expected_yuv(QUADRANT_RGB[q]);
            let mut worst = [0.0f64; 3];
            for m in &measures {
                for c in 0..3 {
                    worst[c] = worst[c].max((m.yuv[q][c] - want[c]).abs());
                }
            }
            let got = &measures[measures.len() / 2].yuv[q];
            println!(
                "  {}：期望 Y{:.0} U{:.0} V{:.0}；实测 Y{:.1} U{:.1} V{:.1}；全部 {} 帧最大偏差 Y{:.1} U{:.1} V{:.1}",
                names[q],
                want[0],
                want[1],
                want[2],
                got[0],
                got[1],
                got[2],
                measures.len(),
                worst[0],
                worst[1],
                worst[2]
            );
            worst_all = worst_all.max(worst.into_iter().fold(0.0, f64::max));
        }
        if worst_all > tolerance {
            problems.push(format!("颜色最大偏差 {worst_all:.1} 超过容差 {tolerance}"));
        }
    }

    if let Some(first) = measures.first().filter(|m| !m.bars.is_empty()) {
        let black = expected_yuv([0, 0, 0]);
        println!("\n── 黑边（{} 块，期望纯黑 Y{:.0} U{:.0} V{:.0}）──", first.bars.len(), black[0], black[1], black[2]);
        let mut worst = 0.0f64;
        for m in &measures {
            for b in &m.bars {
                for c in 0..3 {
                    worst = worst.max((b[c] - black[c]).abs());
                }
            }
        }
        println!("  全部 {} 帧最大偏差 {worst:.1}", measures.len());
        if worst > tolerance {
            problems.push(format!("黑边不是纯黑，最大偏差 {worst:.1} 超过容差 {tolerance}"));
        }
    }

    if animate {
        println!("\n── 画面陈旧程度（帧名义时刻 − 内容绘制时刻）──");
        let mut stale: Vec<f64> = measures.iter().filter_map(|m| m.stale_ms).collect();
        let found = stale.len();
        if found == 0 {
            problems.push("没有在任何一帧里找到亮条".into());
        } else {
            stale.sort_by(f64::total_cmp);
            println!(
                "  {found}/{} 帧找到亮条：最小 {:.0} ms，p50 {:.0} ms，p95 {:.0} ms，最大 {:.0} ms",
                measures.len(),
                stale[0],
                percentile(&stale, 0.5),
                percentile(&stale, 0.95),
                stale[found - 1]
            );
            if (found as f64) < measures.len() as f64 * 0.9 {
                problems.push(format!("只有 {found}/{} 帧找到亮条", measures.len()));
            }
        }
    }

    if problems.is_empty() {
        println!("\n画面自检通过。");
        Ok(())
    } else {
        for p in &problems {
            println!("✘ {p}");
        }
        bail!("画面自检未通过（{} 项）", problems.len())
    }
}
